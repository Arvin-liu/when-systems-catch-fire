# 跨轨道来源依赖与独立性总审

本文件不把来源数量当作证据数量。它记录哪些材料属于同一研究链、哪些只是二次传播、哪些是竞争证据，以及共同方法会怎样限制“独立复制”的说法。

## 八项依赖图

### 004 清洁电力

Ember 当前 CSV、Ember 报告和 Ember 的方法说明属于同一机构数据链；OWID 依赖 Ember，AP/其他媒体是传播而非原始数据。IEA 图表是另一机构链，可以作为方向竞争证据，但不是同一变量、同一版本的独立重复。结论只把 Ember 与 IEA 作为两条机构口径交叉核对，不把新闻或 OWID 另计一票。

### 006 AI 编程

METR 论文、arXiv、官方 GitHub 仓库、CSV 和研究网页共享同一实验与数据，不能计为多次复制；METR 数据与 CMU 镜像的相同哈希进一步确认了这一点。Microsoft 三项企业实验属于不同现场数据链，测量 weekly PR/commit/build，不等于 METR 的总 issue 时间；GitHub 是另一项标准化任务且条件化于完成者。跨研究差异应称为不同 estimand，而不是平均出一个“AI 生产率”。

### 005 GLP-1

SELECT 主文、ClinicalTrials.gov、FDA 标签/公告、NICE 指南、同队列体重或 HbA1c 论文和包含 SELECT 的系统综述，主要是同一随机试验的监管、衍生或二级再叙述。它们可以互相校对设计、计数和适用边界，但不是独立随机复制。其他 GLP-1 心血管结局试验只用于类效应和人群边界的竞争审查，不能把 SELECT 结果外推成普遍类效应。

### 003 高温行动计划

Urban 论文、Europe PMC 页面、Zenodo 记录和 GitHub 代码包是同一 102 地点研究链；它们不是四份独立结果。WHO 2026 是实施框架，不是效果估计。德国 DID 是不同数据和设计的竞争证据，仍需记录有限作者重叠；Dwyer 等方法综述是独立的证据质量地图，不是对 Urban 的直接复制。故模型内 25.2% 和德国 DID 不能平均。

### 002 手写与键盘

Mueller 原始实验、Urry 直接复现、Shin EEG 实验属于不同样本/任务，但不共享同一单一估计量。Flanigan 元分析和 Lau 论文综合可能重叠底层研究，不能视为两次独立人群复制。EEG 过程差异、笔记数量、即时成绩和延迟成绩是不同结果族；把同一论文的多种结果相加会制造虚假的证据数量。

### 001 AI 天气

Zhang 主论文、补充材料、代码和 WeatherBench2 公开数据支持同一 benchmark 链；公开粗网格复算不是原论文 headline 的独立复现。Olivetti–Messori 的分位数尾部研究和 Pasche 的事件研究使用不同模型、极端定义、区域和 lead，是竞争 benchmark。FastNet 属于物理引导 proof-of-principle，不能与运营系统验证并列。

### 007 电动车火灾

丹麦 BRS 的丹麦、瑞典、挪威数字来自同一事实表/发布链，不能合并成三项独立国家复制；BRS 也明确提醒登记和火灾定义不同。瑞典 MCF/MSB 是另一官方数据链，但自由文本事件筛选、蓄意纵火排除和比较组定义不同。NIST 美国估计没有共同 ICE 分母，只能说明捕获—再捕获和漏报问题；RISE 实验研究火灾后果，不是车队点火频率。

### 008 微塑料

S1 是唯一的前瞻临床事件队列；S2 是针对 S1 的方法学通信，不是独立样本。S3、S6、S7 是不同人类组织/配对样本，支持组织存在或富集方向，但多使用 Py-GC/MS 家族，且 S6/S7 本轮全文受限。S4 是独立方法验证，提供 PE/PVC 基质干扰的反方证据而不是临床复制。S5 是范围综述，纳入并重述原始研究，不能计为独立复制。

## 跨主题的共同依赖

- 公共图表、摘要、机构新闻稿和媒体报道常常只是同一论文或数据集的不同入口；必须追到原始数据/论文后才允许承重。
- 同一研究的论文、代码、镜像、注册页和新闻稿可以用于版本和方法交叉核对，但不能增加样本量或复制次数。
- 同一方法家族也会共享盲点：Py-GC/MS 的聚合物热解信号、ERA5/reanalysis benchmark 的真值边界、问卷/机构目录的政策代理和同一随机试验的衍生终点都不能因“来源不同”而自动独立。
- 独立性必须按样本、研究团队、数据生成过程、测量方法和估计对象分别判断；“不同网页”不是独立性。

## 总裁定

八项研究都保留了来源依赖记录。R2 的支持性结论只在指定研究、数据版本、方法和结果族内成立；任何跨来源合成都必须先通过同源链、共同方法和 estimand 审查。本文件不把这些候选结论升级为正式知识。
