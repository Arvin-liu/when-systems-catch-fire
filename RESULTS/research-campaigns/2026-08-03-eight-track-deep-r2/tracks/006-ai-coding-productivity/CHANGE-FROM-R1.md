# 006 从 R1 到 R2 的变化

R1 来源位于精确 tip `232299483f701e8304265c1484b5b50e5dcf2799`，身份为 `UNVERIFIED_RAPID_EVIDENCE_SCANS`。R1 的原报告在约两分钟内把 METR 约 19% 减速、Microsoft 26.08% 任务数增加和 GitHub 55.8% 速度优势并列为竞争证据，报告 SHA-256 为 `ab44ad641bbb0ed0f92d66c69187dca13e6b6d189a7ce86b70a895fc781a3dca`，没有重新运行 METR 输入或固定数据／代码哈希。

R2 不把这三项百分比继续当作同一“生产率”量：

- METR 已锁定公开仓库 commit、CSV、官方脚本、Python 环境并真实复算；新增敏感性、开发者固定效应、平衡检查和异质性交互。
- Microsoft 已从摘要升级到 38 页正文和 15 页公开附录，区分三个企业设计、ITT、W-IV、LATE、控制污染和质量代理；原始数据入口的协议门槛被记录为有凭据阻断，不再写成已复算。
- GitHub 已从 55.8% 摘要数字升级为 95 人随机、70 名完成者、单一 JavaScript 任务、12 项测试和未测质量的条件主张。
- R2 单独审查了论文—CSV 的 27/16 post-review 计数差异和一个外部资源字段越界值，并将其保留到最终限制，不用统一叙事消除。
- 最终裁定从 R1 的总体 `CONTESTED` 改为两层：METR 窄主张 `SUPPORTED_WITH_SCOPE_AFTER_DEEP_REVIEW`；跨研究合成 `CONTEXT_DEPENDENT_COMPETING_ESTIMANDS`。二者都不升级为正式知识。
