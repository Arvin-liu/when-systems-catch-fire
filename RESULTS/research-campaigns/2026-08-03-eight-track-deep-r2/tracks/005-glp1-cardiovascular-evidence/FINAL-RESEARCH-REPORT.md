# 005 GLP-1：高风险临床证据审查

## 最终裁定

**SELECT 窄主张：`SUPPORTED_WITH_SCOPE_AFTER_DEEP_REVIEW`。** 在无糖尿病、年龄至少 45 岁、BMI 至少 27、已有动脉粥样硬化性心血管疾病的成年人中，随机分配到每周 semaglutide 逐步加量至 2.4 mg 的治疗策略，与安慰剂加标准治疗相比，首次三点主要不良心血管事件（心血管死亡、非致死性心肌梗死、非致死性卒中）较少。这个裁定只适用于 SELECT 的剂量、入组条件、复合终点和试验观察窗，仍是待 GPT 外部审定的研究候选。

**宽主张：不成立或证据不足。** 本轮不支持把结果写成“所有 GLP-1 药物普遍护心”、一级预防同样有效、BMI 小于 27 也适用，或减重以外的独立心血管机制已经被证明。

## 核心证据和复算

SELECT 是 17,604 人、41 个国家、804 个地点的双盲随机试验。受试者有既往心肌梗死、卒中或有症状外周动脉疾病，BMI 至少 27，排除了糖尿病；治疗组按计划逐步达到每周 2.4 mg。主要终点按随机分组的 ITT/全分析集评价。

首次 MACE 在 semaglutide 组为 569/8,803（6.46%），安慰剂组为 701/8,801（7.97%），HR 0.80（95% CI 0.72–0.90）。本轮用公开事件计数和组分母独立复算，风险差约 1.50 个百分点，倒数约 66.6，即约 67；脚本和输出在 `reproducibility/`。这不是固定五年或终生 NNT，也不是用个体时间到事件资料得到的精确固定时间 NNT，因为试验随访长度和删失不能从公开总计数中还原。

复合终点的组成项不能被抹平：非致死性心肌梗死 HR 0.72（0.61–0.85），非致死性卒中 HR 0.93（0.74–1.15），心血管死亡 HR 0.85（0.71–1.01，p=0.07）。层级检验在心血管死亡处停止，所以“复合 MACE 降低”是可保留的窄表述，“三项都已分别确认获益”不是。全因死亡和心衰复合终点属于支持性而非该层级下确认的证据。

## 治疗现实和安全边界

平均随访约 39.8 个月；约两年时约 77% 的 semaglutide 受试者达到 2.4 mg。因不良事件永久停药约 16.6% 对 8.2%，胃肠道停药约 10.0% 对 2.0%；严重不良事件约 33.4% 对 36.4%。因此主结果是“分配到逐步加量治疗策略”的 ITT 效果，不是每位患者服满 2.4 mg 的 per-protocol 药效。FDA 标签还列出胰腺炎、胆囊病、脱水相关急性肾损伤、严重胃肠道反应、过敏反应、视网膜病变、心率和麻醉误吸等警告。SELECT 的排除条件和人群选择意味着不能由试验内净结果保证一般人群或个体的净获益。

## 外推裁定

| 命题 | 裁定 |
|---|---|
| SELECT 原有人群、semaglutide 2.4 mg、首次三点 MACE | `SUPPORTED_WITH_SCOPE_AFTER_DEEP_REVIEW` |
| 公开计数的约 1.5 个百分点 ARR、约 67 的粗略 in-trial NNT | `SUPPORTED_WITH_EXPLICIT_LIMITATION` |
| 一级预防或没有已确立 CVD | `INSUFFICIENT_EVIDENCE` |
| BMI 小于 27 | `NOT_SUPPORTED` |
| 糖尿病人群由 SELECT 直接外推 | `INSUFFICIENT_EVIDENCE_FOR_SELECT_EXTRAPOLATION` |
| 其他 GLP-1/双重激动剂的普遍类效应 | `NOT_SUPPORTED_AS_CLASS_CLAIM` |
| “减重以外护心机制已证实” | `CONTESTED` |

NICE 的最终指南同样把适用对象限制在已有 CVD 且 BMI 至少 27 的成年人；其对糖尿病的有限讨论使用了不同剂量、途径和入组条件的其他心血管试验，不能把 SELECT 变成一级预防证据。体重/腰围和 HbA1c 论文来自同一 SELECT 队列，且使用随机化之后的变量，只能生成机制假说，不能证明中介因果链。

## 来源依赖和未完成读取

期刊主文、ClinicalTrials.gov、FDA 标签和 FDA 公告可以交叉核对 SELECT 的设计、计数和监管边界，但不是独立随机复制；安全性、HbA1c、体脂变化论文也是同一队列的衍生分析。独立系统综述纳入 29 项试验、37,348 人，SELECT 约占样本近半，汇总 MACE 约 0.80 不能被解释为新的 SELECT 复制。NEJM appendix/protocol 直接地址本轮返回 HTTP 403，未将未读补充材料写成已核验事实；该限制和所有来源哈希记录在 `SOURCE-AUDIT.jsonl` 与 `ACCESS-AND-HASH-MANIFEST.json`。
