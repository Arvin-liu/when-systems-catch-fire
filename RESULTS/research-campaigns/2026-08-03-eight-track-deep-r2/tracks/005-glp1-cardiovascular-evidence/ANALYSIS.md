# 005 GLP-1 心血管证据：分析阶段

## 研究对象和可回答的问题

本项研究的身份是 `HIGH_STAKES_CLINICAL_EVIDENCE_REVIEW`。冻结的问题不是“GLP-1 是否普遍护心”，而是：在无糖尿病、年龄至少 45 岁、BMI 至少 27、已有动脉粥样硬化性心血管疾病的成年人中，semaglutide 2.4 mg 每周一次加标准治疗，是否降低首次三点主要不良心血管事件（心血管死亡、非致死性心肌梗死或非致死性卒中）；这一结果能否外推到一级预防、BMI 小于 27、糖尿病人群、其他 GLP-1 药物或双重激动剂。

结论上限固定为该剂量、该人群、该复合终点和试验观察窗。它不是个人治疗建议，也不是对药物机制或整个药物类别的裁定。

## SELECT 主结果

SELECT 是一项双盲、随机、安慰剂对照试验，17,604 名受试者来自 41 个国家的 804 个地点。受试者都有既往心肌梗死、卒中或有症状外周动脉疾病，BMI 至少 27，且排除了糖尿病；试验将每周皮下注射 semaglutide 逐步加量至 2.4 mg，与标准治疗比较。主要分析按随机分组的全分析集进行，不是只分析实际持续用药者。期刊正文 pp. 2–7、ClinicalTrials.gov 结果页和 FDA 标签 Study 1（pp. 26–28）给出了相同的主计数。

首次 MACE 发生在 semaglutide 组 569/8,803（6.46%）和安慰剂组 701/8,801（7.97%），风险比 0.80，95% CI 0.72–0.90。按公开分母作透明的粗略计数复算，绝对风险差为 1.50 个百分点，1/ARR 约为 66.6，即约 67；脚本、输入计数和完整输出在 `reproducibility/`。这个数字是把不等长的试验观察期压成组内事件比例的近似 NNT，不是固定五年、终生或个人 NNT，也不是用个体时间到事件资料计算的 Aalen–Johansen 估计。

复合终点内部并不等价：非致死性心肌梗死 HR 0.72（0.61–0.85），非致死性卒中 HR 0.93（0.74–1.15），心血管死亡 HR 0.85（0.71–1.01，p=0.07）。层级检验在心血管死亡处停止，因此不能把每个组成项都写成已确认的独立显著保护。全因死亡 HR 0.81（0.71–0.93）和心衰复合终点 HR 0.82（0.71–0.96）在正文中属于未按该层级确认的结果；它们可以作为支持性信息，不能替代预设主要终点。

## 剂量、依从性与安全性

平均随访约 39.8 个月（FDA 标签报告中位随访 41.8 个月）；约 77% 的 semaglutide 受试者在两年时达到 2.4 mg。永久停药并非罕见：正文为 26.7% 对 23.6%，FDA 标签按其安全性汇总口径报告约 31% 对 27%。因此 ITT 结果回答的是“分配到这一治疗策略”的效果，不是每位患者完整服满 2.4 mg 的药效。

严重不良事件为 33.4% 对 36.4%；因不良事件永久停药为 16.6% 对 8.2%，其中胃肠道原因约 10.0% 对 2.0%。胆囊事件约 2.8% 对 2.3%，安全性论文报告严重不良事件停药、胆囊炎以及自杀或自伤相关事件没有显示出与安慰剂相同的简单优势。FDA 标签另列有胰腺炎、胆囊病、脱水相关急性肾损伤、严重胃肠道不良反应、过敏反应、视网膜病变、心率和麻醉误吸等警告。SELECT 的受试者排除了部分高风险病史，安全性也不能无条件转移到一般人群。

## 外推边界

| 外推目标 | 本轮判定 | 原因 |
|---|---|---|
| 无糖尿病、BMI≥27、已有 CVD、semaglutide 2.4 mg | `SUPPORTED_WITH_SCOPE` | SELECT 的随机主终点，主方向和计数在原文、注册结果和监管标签间一致 |
| 一级预防或没有已确立 CVD | `INSUFFICIENT_EVIDENCE` | SELECT 以既有 CVD 为入组条件；不能用二级预防风险比直接推导低基线风险人群的绝对获益 |
| BMI<27 | `NOT_SUPPORTED` | 不在 SELECT 入组范围；NICE 也明确没有足够证据支持这一体重范围的相同使用结论 |
| 糖尿病 | `INSUFFICIENT_EVIDENCE_FOR_SELECT_EXTRAPOLATION` | 其他 CVOT 可提供类内背景，但剂量、给药途径、入组条件和 CVD/BMI 组合不同，不能说由 SELECT 直接证明 |
| 其他 GLP-1 或双重激动剂 | `NOT_SUPPORTED_AS_CLASS_CLAIM` | 系统综述中的药物、试验长度和人群不同，且 SELECT 对硬终点贡献很大；没有同等直接的类效应复制 |
| “减重所以护心”或独立的心血管机制 | `CONTESTED` | 体重/腰围的事后变化分析和生物学解释可生成假说，但暴露是随机化后的变量，受依从性、疾病状态和共同治疗影响，不能建立中介因果链 |

NICE 2026 最终指南把使用对象同样限制为已有 CVD 且 BMI 至少 27 的成年人；委员会允许有限的糖尿病外推，是基于其他不同设计的心血管试验和模型判断，不是把 SELECT 变成一级预防或整个 GLP-1 类证据。NICE 经济模型还依赖长期外推和停药后假设，故不应将成本效果结论当作试验中的临床效果。

## 竞争证据和来源依赖

独立系统综述纳入 29 项随机试验、37,348 人，汇总 MACE RR 约 0.80；但其中包含多种药物、短期减重试验和不同人群，且去除 SELECT 后异质性和可解释性都会变化。它是跨试验的边界检查，不是 SELECT 的独立重复。SELECT 期刊论文、FDA 标签、FDA 新闻稿和 NICE 评估都最终依赖同一核心试验及其申办方材料；不能按“多个文件”计为多个独立阳性证据。安全性论文、HbA1c 论文和体脂变化论文也是同一 SELECT 队列的衍生分析。

本轮尝试打开 NEJM appendix 和 protocol 的直接地址时收到 HTTP 403，因此没有把未读补充材料写成已核验事实；目前对方法的核心定位来自正文、注册平台、FDA 标签及 NICE 公开材料。这个访问缺口留到 challenge，不改变主结果已经在多份公开一级/监管记录中交叉出现的事实。

## 分阶段分析裁定

- 窄主张（SELECT 人群、semaglutide 2.4 mg、首次三点 MACE）：`SUPPORTED_WITH_SCOPE`。
- “约 67”作为透明的粗略组内 ARR/NNT 近似：`SUPPORTED_WITH_EXPLICIT_LIMITATION`，不可改写为固定时间或个人 NNT。
- 各组成项均独立获益、心血管死亡已被确认：`NOT_SUPPORTED`。
- 一级预防、BMI<27、全 GLP-1 类或双重激动剂普遍护心：`INSUFFICIENT_EVIDENCE` 或 `NOT_SUPPORTED_AS_CLASS_CLAIM`。
- 减重中介已经证明独立机制：`CONTESTED`。

下一阶段将专门攻击停药与 ITT 解释、事件时间窗、复合终点层级、补充材料访问缺口、外推和同源来源依赖，只有经该反方审查后才生成最终研究报告。
