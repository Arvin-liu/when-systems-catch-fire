# 005 GLP-1 心血管证据：反方审查

本文件独立于 `ANALYSIS.md` 进行，目标是寻找会把主结果降级、推翻或缩窄的证据。挑战对象是三个不同层级的命题：SELECT 窄主张、约 67 的粗略 ARR/NNT、以及从 SELECT 推到一级预防或整个 GLP-1 类的宽主张。

## 1. 事件计数能否直接变成 NNT

**反方问题：** 569/8,803 和 701/8,801 是否可以当作同一固定时间点的风险，从而报告 NNT=67？

**检查结果：** 不能把它当作严格固定时间 NNT。SELECT 是时间到首次事件试验，受试者进入和退出时间不同，主要证据是 HR 0.80 及其置信区间。公开资料没有个体级事件时间表，故只能用总事件数除以随机组分母重算一个透明的组内观察期近似。该近似的 ARR 为 1.50 个百分点、倒数约 66.6；它没有校正删失、竞争风险或统一随访长度，也不能回答五年或终生问题。

**裁定：** NNT 数字保留，但必须改名为“公开计数的粗略 in-trial NNT 近似”，不能用来制造精确临床决策感。它没有推翻 SELECT 的相对风险主结果。

## 2. 复合终点是否掩盖了组成项不一致

**反方问题：** MACE 的总体 HR 是否被非致死性心肌梗死一项主导，却被写成三项都受到同样保护？

**检查结果：** 这是成立的降级理由。非致死性心肌梗死 HR 0.72（0.61–0.85）较明确，非致死性卒中 HR 0.93（0.74–1.15），心血管死亡 HR 0.85（0.71–1.01）且层级检验未确认。因而只能说预设复合终点降低，不能说心血管死亡或卒中已经分别获证。FDA 标签和期刊正文的层级结果支持同一限制。

**裁定：** 窄主张由 `SUPPORTED_WITH_SCOPE` 降为“复合终点支持、组成项不均一”；“降低所有严重心血管结局”不支持。

## 3. ITT、停药和实际剂量

**反方问题：** 大量永久停药和未达到 2.4 mg 是否使结果无法归因于 semaglutide 2.4 mg？

**检查结果：** 永久早停和胃肠道停药在 semaglutide 组更高，约两年时约 77% 达到 2.4 mg。主分析按随机分配，保留了停药后随访，因此估计的是“分配到逐步加量的治疗策略”的 ITT 效果。它既不是完整依从者的药效，也不是把停药后风险删除的 per-protocol 效果。把主结果改写成“每位服满 2.4 mg 的效果”会越过证据。

**裁定：** ITT 主结果保留；剂量和停药必须进入主报告的结果解释，不作有利或不利方向的额外因果推断。

## 4. 外推审查

**反方问题：** 糖尿病、没有已确立 CVD、BMI 小于 27，或其他 GLP-1/双重激动剂能否由一项阳性试验外推？

**检查结果：** 不能直接外推。SELECT 的入组门槛同时限定了年龄、体重、无糖尿病和已确立 CVD；这些条件共同决定了基线绝对风险和治疗耐受性。NICE 的糖尿病讨论依赖不同剂量、途径、入组条件的其他心血管试验；它是有限的跨试验综合，不是 SELECT 在糖尿病人群中的随机证据。一级预防尤其缺少同等风险基线下的事件和安全性权衡。

**裁定：** 一级预防和 BMI<27 为 `INSUFFICIENT_EVIDENCE`/`NOT_SUPPORTED`；“GLP-1 类普遍护心”不支持。不能把 FDA/NICE 对特定适应证的文本扩大为类效应。

## 5. 安全性和选择性

**反方问题：** 试验是否足以证明一般人群的整体获益大于风险？

**检查结果：** 该试验提供了有用的随机安全性比较：严重不良事件约 33.4% 对 36.4%，但因不良事件停药约 16.6% 对 8.2%，胃肠道停药约 10.0% 对 2.0%。罕见事件的精度仍有限；同时，SELECT 排除了若干病史和严重状态，试验对象不是所有寻求减重的人。FDA 标签的警告清单不能被“总体严重不良事件较低”覆盖。

**裁定：** 可报告试验内安全性差异，不能给出一般人群净获益或个体风险保证。安全性论文是同一队列的二次分析，不构成独立复制。

## 6. 机制和中介

**反方问题：** 体重下降、腰围下降或 HbA1c 改善是否证明了独立的“减重以外护心机制”？

**检查结果：** 体脂变化材料把随机分组后的体重/腰围变化作为中介或相关预测量；依从性、健康行为、疾病进展和共同治疗同时影响这些变量。它们不是随机化的独立处理，因此中介比例不能被读作机制的因果份额。SELECT HbA1c 分析也属于预设探索/分层描述，不能替代机制试验。

**裁定：** “机制已证实”降为 `CONTESTED`。机制材料只能帮助生成假设，不能提升临床外推的证据等级。

## 7. 补充材料和复制门槛

NEJM appendix/protocol 的直接地址在本轮返回 HTTP 403；因此没有声称逐页审读其中未公开给本轮的表格。正文、注册平台、FDA 标签和 NICE 公共材料足以交叉确认样本量、主要终点和主计数，但不能填补补充材料访问缺口。FDA 与 NICE 的文件也都不是新随机试验：前者是监管整合，后者包含公司提交材料和模型评估。该缺口是可验证的研究限制，不是把主结果自动判为无效的理由。

## 反方总裁定

最强的可保留主张是：在 SELECT 的特定二级预防人群和随机治疗策略中，semaglutide 的首次三点 MACE 复合终点较低；公开计数支持约 1.5 个百分点的粗略观察期风险差，但 NNT 只可作为近似。反方审查成功否定了三个更宽的写法：把 NNT 写成固定年限个人数字，把三项组成事件写成同样确认的保护，把 SELECT 写成一级预防或整个 GLP-1 类的普遍结论。

进入 final 时必须保留：

1. `SUPPORTED_WITH_SCOPE_AFTER_DEEP_REVIEW` 只用于 SELECT 窄主张；
2. 组成项、长期净获益、一级预防、BMI<27、类效应和机制分别降级；
3. 监管和 HTA 文档不能按独立复制计数；
4. 这份研究仍是待外部审定候选，不是正式知识或医疗建议。
