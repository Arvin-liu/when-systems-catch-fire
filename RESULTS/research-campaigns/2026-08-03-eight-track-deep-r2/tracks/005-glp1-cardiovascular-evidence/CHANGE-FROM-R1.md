# 005 从 R1 到 R2 的裁定变化

## R1 身份

R1 的统一身份是 `UNVERIFIED_RAPID_EVIDENCE_SCANS`。原始报告可以作为检索线索，但不能直接作为正式知识。R1 对 GLP-1 的叙述把 SELECT 的阳性结果放在了更宽的“GLP-1 心血管保护”语境中，没有充分拆开二级预防、人群外推、组成终点、绝对风险和安全性。

## R2 修正

1. 把研究合同改为 `HIGH_STAKES_CLINICAL_EVIDENCE_REVIEW`，以 SELECT 的精确人群、剂量、终点和观察窗为主问题。
2. 将“GLP-1 普遍护心”改成“SELECT 特定二级预防策略的首次三点 MACE 复合终点候选获益”。
3. 用 569/8,803 对 701/8,801 重算公开计数的 ARR 和约 67 的粗略 NNT，并明确它不是固定年限或个人 NNT。
4. 分开报告 MACE 组成项：心肌梗死方向较强，卒中和心血管死亡不能写成同等确认的保护。
5. 加入停药、实际达到剂量和 ITT 含义；不把随机策略效果改写成完整依从者药效。
6. 将一级预防、BMI<27、SELECT 到糖尿病的直接外推以及其他 GLP-1/双重激动剂类效应分别降级。
7. 将体重、腰围和 HbA1c 的同队列衍生分析降为机制假说，不能证明减重以外的独立机制。
8. 记录 NEJM appendix/protocol 的 HTTP 403 访问限制，并画出 FDA、NICE、系统综述和同队列论文的来源依赖图。

最终窄主张为 `SUPPORTED_WITH_SCOPE_AFTER_DEEP_REVIEW`，不是无条件的正式认识。
