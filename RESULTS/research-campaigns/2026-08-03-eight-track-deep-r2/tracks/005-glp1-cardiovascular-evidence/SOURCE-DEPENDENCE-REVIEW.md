# 005 来源依赖审查

## 依赖图

本轮实际证据不是 11 个彼此独立的阳性结果，而是一个核心随机试验及其多种再表达：

```text
SELECT 随机试验（Novo Nordisk 申办）
├── NEJM 主文与同队列安全性 / HbA1c / 体脂变化论文
├── ClinicalTrials.gov 结果记录
├── FDA 标签与 FDA 新闻稿
├── NICE 证据评估、公司提交和经济模型
└── 纳入多项试验的系统综述（SELECT 是其中最大且贡献主要硬终点的单项试验）
```

这张图说明“来源数量”不能替代独立复制。期刊正文和监管文本可提高定位、监管核对和结果一致性的可信度，但不能把同一受试者队列算成多次实验。

## 逐源独立性分类

| 来源 | 主要价值 | 独立性 | 本轮用途上限 |
|---|---|---|---|
| SELECT 主论文 | 随机设计、主终点、组件和停药 | 核心单一试验，申办方资助 | 直接回答窄主张 |
| ClinicalTrials.gov NCT03574597 | 注册设计、结果上传、完成状态 | 与试验同源的注册记录 | 核对预先定义和计数，不是复制 |
| FDA 2026 标签 | 适应证、监管安全信息、Study 1 汇总 | 监管再分析，核心数据仍来自 SELECT | 核对标签边界和警告 |
| FDA 2024 公告 | 适应证批准背景 | 监管新闻文本 | 只能作监管语境，不作新证据 |
| NICE TA1152 与委员会材料 | HTA 的适应证和外推讨论 | 独立评估过程，但使用同一试验/公司资料 | 审计人群边界和经济不确定性 |
| SELECT 安全性论文 | 预设安全性分层 | 同一 SELECT 队列 | 补充安全事件，不是复制 |
| SELECT HbA1c 论文 | 探索性分层 | 同一 SELECT 队列 | 不作机制证明 |
| 体重/腰围论文 | 中介/机制假设 | 同一 SELECT 队列，暴露为随机化后变量 | 只作机制反方材料 |
| 独立系统综述 | 跨药物、跨试验异质性 | 作者团队和检索过程相对独立 | 作为外部边界检查；不能视作 SELECT 复制 |
| R1 媒体/机构摘要 | 发现线索 | 新闻或二手材料 | 不承担科学结论 |

## 最重要的依赖后果

系统综述纳入 37,348 名受试者，SELECT 一项约占 17,604 人，接近半数样本；硬终点的权重还受到其他试验较短和终点不同的影响。综述的 pooled MACE 约 0.80 与 SELECT 的 0.80 接近，并不能说明有一项新的独立随机复制。NICE 对糖尿病的有限外推来自多个不同心血管试验，但这些试验也不能把 SELECT 的一级预防边界抹掉。

FDA 标签和 FDA 公告之间可以确认监管文字一致，NICE 与 FDA 之间可以确认适应证边界在不同制度文件中一致；它们属于制度上的交叉核对，而非独立病人样本。最终报告因此将证据层写成“一个强的核心随机试验，加上监管/HTA 复核和有限的跨试验综合”，而不是“多份独立证据均证明”。

本轮没有获得 SELECT 个体级数据，无法独立重算时间到事件模型、固定时间风险或分层中介模型。NEJM appendix/protocol 的直接下载受到 HTTP 403，未提交受限复制文件申请，也没有把未完成的补充材料阅读写成已完成。这个状态在 `SOURCE-AUDIT.jsonl` 与 `ACCESS-AND-HASH-MANIFEST.json` 中留有记录。
