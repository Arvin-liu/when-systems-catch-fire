This branch contains independent, candidate-only public-evidence research packets. Each round answers one bounded external-world question using opened sources, records both supporting and competing evidence, and is pushed as an ordinary commit. No result is accepted as a Pointfire conclusion without GPT/owner adjudication.

The campaign is isolated from Task 114, `relay/current`, `main`, pull requests, tags, lifecycle state, Foundation projections, planners, and project-wide derived surfaces.

## Reading the results

Each `round-NNN-<short-slug>/` directory contains only the minimal report, source ledger, and round metadata. `ROUND-INDEX.jsonl` is the compact campaign index. `UNRESOLVED.md` records questions that remain genuinely open.
