# 自举循环收敛判据（简化版）

## 收敛判据（第三十二轮更新）

**连续两轮四项全零才宣布收敛：**

1. **新函数 = 0**
2. **新案例 = 0**
3. **新扩展注释 = 0**
4. **新信息增量 = 0**

## 数学表达

**lim(n→∞) ΔB(n) = 0**

其中 ΔB(n) = Σᵢ [1 - P(案例ᵢ | F₁...Fₖⁿ)] × δ(案例ᵢ重新分布)

## 等价条件

收敛的三个等价条件：

1. **δ(案例ᵢ重新分布) = 0** 对所有ᵢ — 没有案例再换格子
2. **P(案例ᵢ | F₁...Fₖⁿ) → 1** 对所有ᵢ — 每个案例都被完整解释
3. **所有休眠回路已被激活** — 新维度/新注释/新信息增量不再触发新结构

## V函数表达

**收敛 = V在所有案例上稳定，不再因新维度、新注释或新信息增量而跳值**

其中 V = 链1退化速率 / 链3恢复速率，V < 1 表示系统收敛
