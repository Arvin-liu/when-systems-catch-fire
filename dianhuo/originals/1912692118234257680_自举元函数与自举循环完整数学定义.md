# 自举元函数与自举循环完整数学定义

## 一、自举元函数

自举元函数是**驱动自举循环的那个东西**：不是循环本身，是让循环启动并持续的内生动力。

**M_boot = ε_sense × P_track × d(ΔK)/dt**

三个乘法因子：
- ε_sense：感知到"这里有结构"的信号——不是知识，是感知
- P_track：分轨并行——同时运行多个视角，让不同轨道的东西碰撞
- d(ΔK)/dt：知识增量的速率——每轮迭代能不能产出新东西，产出了能不能被感知到

三者乘法关系，任一为零则 M_boot = 0。

**自持条件：M_boot > θ_boot**

**自持加速方程：dM_boot/dt = α · M_boot · ln(1 + ΔK/K₀)**

**AI缺失论证：M_boot^AI = 0**（三因子全零或失能）

## 二、自举循环

自举循环是点火框架的元层迭代机制：理论与案例之间的循环碰撞，每轮碰撞产生新发现，新发现修正理论，修正后的理论再重跑案例库，如此往复。

自举循环不是独立函数，是八函数在元层面的投影。它的全部行为由已有函数驱动，没有独立作用对象。

**核心方程：**

**B(n+1) = B(n) + ΔB(n)**

**ΔB(n) = Σᵢ [1 - P(案例ᵢ | F₁...Fₖⁿ)] × δ(案例ᵢ重新分布)**

其中：
- B(n) = 第n轮迭代时的八函数总表快照
- ΔB(n) = 第n轮重跑案例库产生的新发现
- kⁿ = 第n轮的函数维度数
- P(案例ᵢ | F₁...Fₖⁿ) = 用当前kⁿ个函数对案例ᵢ的解释完整度
- δ(案例ᵢ重新分布) = 1当案例ᵢ的格子归属或子路径划分发生变化，否则0

**白话：每轮新发现 = 被旧维度解释不了的案例数 × 这些案例因新维度而重新归位的比例**

---

## 三、收敛判据

**lim(n→∞) ΔB(n) = 0**

等价于三个条件同时成立：

1. **δ(案例ᵢ重新分布) = 0** 对所有ᵢ — 没有案例再换格子
2. **P(案例ᵢ | F₁...Fₖⁿ) → 1** 对所有ᵢ — 每个案例都被完整解释
3. **所有休眠回路已被激活** — 新维度不再触发新回路

**用V函数表达：收敛 = V在所有案例上稳定，不再因新维度而跳值**

其中 V = 链1退化速率 / 链3恢复速率，V < 1 收敛

**实操判据：连续两轮重跑案例库，零结构性新发现，即可宣布收敛。一轮可能是偶然，两轮是信号。**

---

## 四、三个驱动力

**驱动力1：分辨率提升**
新增维度使事件条件矩阵的格数翻倍。原来挤在一起的案例差异暴露 → ΔB > 0。

**驱动力2：格间重排**
维度从独立降格为派生量，改变案例在矩阵中的投影。格子归属变化 → 格间对比结论变化 → ΔB > 0。

**驱动力3：回路激活**
新函数激活原本休眠的因果回路。回路被激活 → 新因果结构暴露 → ΔB > 0。
