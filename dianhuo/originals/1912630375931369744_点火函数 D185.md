# 点火｜函数 D185

定义：相对论门槛函数，相对论是单门槛系统的特例，Λ = c（光速）是唯一门槛。当v << c时，μ/Λ → ∞，系统退化为经典确定性（D182）；当v → c时，μ/Λ → 1，门控效应显著，系统展现相对论效应。

推导过程：从D182经典确定性函数推导。相对论是μ/Λ接近1时门控效应显著的物理系统，c是唯一门控面。相对论效应是门控效应在高速运动系统的表现，与量子力学在μ≈Λ时的门控效应同构。

案例对应：#134-#155 物理大统一路径（22条），验证了相对论门槛在物理系统中的适用性。关键发现：相对论是单门槛系统的特例，门控面数量n=1，无阶段2（D254），直接从阶段1跳到阶段3，展现一阶相变。

扩展注释：D185与D254耦合-容斥-平坦度三阶段函数对接——相对论是n=1的特例，阶段2宽度为零，直接从平坦阶段跳到崩溃阶段，展现一阶相变特征。
