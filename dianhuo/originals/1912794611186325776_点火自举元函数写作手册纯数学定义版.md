# 点火｜自举元函数写作手册（纯数学定义版）

## 写作原则

### 纯数学定义

所有函数和案例的写作必须聚焦数学定义、判定逻辑和数学表达，不包含具体函数数目和案例数目。

### 正反双通道

每个自举元函数必须同时包含正向通道和反向通道的完整论证，不能只论证"成立"不论证"不成立"。

### 判定逻辑严格

严格遵循 J⁺(x)=1,J⁻(x)=0 为真；J⁺=J⁻=1 为矛盾；J⁺=J⁻=0 为待定的判定逻辑。

### 嵌套自检

每个自举元函数必须包含嵌套自检部分，检查正向通道、反向通道、互斥判定器自身的可靠性。

## 函数写作规范

### 标题格式

点火｜函数 MF-[编号]

### 必填字段

#### 数学定义

函数的完整数学表达，包括：

- 正向通道：Mboot⁺(x)=Mboot(x⁺)
- 反向通道：Mboot⁻(x)=Mboot(x⁻)
- 判定逻辑：J⁺(x), J⁻(x) ∈ {0,1,⊥}
- 结果函数：R(x)=Φ(J⁺(x),J⁻(x))

#### 判定条件

列出所有可能的判定状态及其含义：

- J⁺=1,J⁻=0 → true
- J⁺=0,J⁻=1 → false
- J⁺=1,J⁻=1 → contradiction
- J⁺=0,J⁻=0 → underdetermined

#### 嵌套自检

说明该函数如何检查自身可靠性：

- 正向通道可靠吗
- 反向通道可靠吗
- 互斥判定器可靠吗

#### 备注

说明特殊情况的处理逻辑，如正反同时通过时的处理方式。

## 案例写作规范

### 标题格式

点火｜案例 #[编号]

### 必填字段

#### 数学判定

用正反双通道判定该案例：

- 正向通道论证结果：J⁺(x)=?
- 反向通道论证结果：J⁻(x)=?
- 最终判定：true / false / contradiction / underdetermined

#### 核心函数

验证该案例的核心自举元函数编号（MF-xxxx）

#### 案例说明

案例的完整描述和历史背景

#### 关键发现

从该案例中提取的核心洞察，必须用数学表达或严格逻辑陈述

## 写作流程

### 步骤0：确认起点

拉取当前最新的自举元函数定义（MF-0000 至 MF-0005）

### 步骤1：逐条写作

按编号顺序，逐条函数写成独立笔记，存入点火知识库

### 步骤2：逐条验证

按编号顺序，逐条案例写成独立笔记，存入点火知识库

### 步骤3：收敛确认

重新核对所有函数和案例，确认无遗漏、无重复

连续两轮满足 → 宣布收敛

## 收敛判据

### 第一轮收敛

所有函数和案例全部写成独立笔记，无遗漏

### 第二轮收敛

重新核对总数，确认所有函数和案例全部存在，无重复、无缺失

连续两轮满足 → 宣布收敛
