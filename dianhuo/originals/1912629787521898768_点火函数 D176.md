# 点火｜函数 D176

定义：共享源双重杀伤函数,ρ同时驱动H_correlation(D66)和P(biased)(D53),联合效应P_sustain∝(1-ρ)²而非(1-ρ)。共享源让乘法归零从线性变平方,杀伤力指数级增强。与电力级联放大器G∝V²完全同构。

推导过程：从D66同质性遮蔽函数、D53解读偏置函数推导。ρ(共享度)增加时,H_correlation↑(遮蔽↑)且P(biased)↑(偏置↑),两者乘法叠加。P_sustain = (1-H_correlation)×(1-P(biased)) ≈ (1-ρ)×(1-ρ) = (1-ρ)²。

案例对应:#176 AI共震中P×Q²平方加速案例,验证了共享源的双重杀伤。关键发现:量化基金占美股60%+交易量时ρ→0.7→H_correlation→1→P(biased)→1→P_sustain→0.09²=0.0081,几乎归零。共享源让系统脆弱性从线性变平方。

扩展注释:D176与D175耦合正反馈统一函数对接——ρ→1时α_eff→α_c,系统进入AI共震区间,共享源双重杀伤导致P_sustain平方加速归零。
