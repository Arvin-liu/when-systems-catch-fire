# 密码学碰撞验证

## 密码学与点火框架碰撞验证报告

### 一、密码学核心概念提取

从《卓克的密码学课》和《计算机网络安全原理》中提取的核心内容：

**密码学发展七世代**：
1. 隐藏法
2. 移位法和替代法
3. 维尼吉亚加密法
4. 恩尼格玛机
5. 魔王加密系统
6. RSA加密系统
7. 量子加密

**密码学核心原理**：
- 密码编码学：对信息进行编码以实现信息隐藏
- 密码分析学：分析人员在不知道解密细节的条件下对密文进行分析，试图获取机密信息
- 加密与解密的力量此消彼长：在某些年代，任何加密法都有破解之术；而在另外的年代，有的加密法却牢不可破

**恩尼格玛机破解的关键**：
- 不是一道难解的数学题，而是一套由情报部分负责运转的复杂的机械电子设备
- 破解的最大动力是威胁下的恐惧感
- 数学工具的应用：环的数量和连接数的统计分析
- 加密与解密的千年对抗，没有永远的胜者，也不存在终极解决方案

**比特币中的密码学**：
- SHA256加密法：安全哈希算法，不论原始数据有多长，经过Hash运算后，输出的值的长度都是固定的
- 非对称钥匙系统：公钥和私钥
- 去中心化的交易系统：没有中央银行
