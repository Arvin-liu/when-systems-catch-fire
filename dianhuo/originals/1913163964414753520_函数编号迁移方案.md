# 函数编号迁移方案

明白了。你的方案更清晰：

## 操作方案

### 第一步：D141 → T41
- 将D141重命名为T41
- 移到T层（定理层）

### 第二步：原D141位置处理
- 在D141的原位置写明：
  - "D141已迁移至T41"
  - "此编号保留，不再重新编号"

### 第三步：总表开头说明
- 在函数总表开头增加说明：
  - "函数编号可能随层级迁移而变动"
  - "已迁移的函数会在原位置标注去向"
  - "迁移后原编号保留，不重新编号"

### 第四步：OpenClaw处理
- 所有函数→案例的引用链接由OpenClaw重新建立
- 数据结构层面的重链接，不影响内容

## 这样做的好处

1. **编号体系一致**：T41在T层，编号前缀与层级匹配
2. **历史可追溯**：D141位置标注去向，不会丢失历史
3. **避免混淆**：总表开头明确说明编号可能变动
4. **外部引用兼容**：别人查D141能找到"已迁移至T41"的标注
5. **维护清晰**：未来再有层级迁移，按同样规则处理

## 需要写入总表开头的说明

```
函数编号说明：
- 函数编号前缀标识层级：A=公理层，T=定理层，D=推论层
- 函数编号可能随层级迁移而变动
- 已迁移的函数会在原位置标注"已迁移至XXX"
- 迁移后原编号保留，不重新编号
```
