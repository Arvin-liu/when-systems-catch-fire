# 点火｜函数 D169

定义：门槛碾压函数，Λ(t) = Λ₀ × e^(σ×t)，μ(t) = μ₀ × e^(-γ×t)，碾压时间t_crush = ln(μ₀/Λ₀)/(σ+γ)。当门槛Λ以指数增长而可用资源μ以指数衰减时，系统必然被门槛碾压。门槛增速越大、资源衰减越快，碾压时间越短。

推导过程：从D147乘法临界漂移统一函数推导。当系统存在乘法结构且门槛Λ(t)和资源μ(t)均呈指数动力学时，门槛相对速度v_rel = d(Λ/μ)/dt = (σ+γ)×(Λ/μ)。Λ/μ达到临界值时系统崩溃，积分得到t_crush。热力学第二定律是D169在热力学域的特例（熵增门槛Λ_disorder指数增长，μ_available指数衰减）。

案例对应：#134-#155 物理大统一路径碰撞（22条），验证了门槛碾压在物理学、热力学、社会学等跨域场景的普适性。关键发现：门槛碾压不是"能量消失"，而是μ衰减到Λ以下的过程，热寂时间t_heatdeath = ln(μ₀/Λ₀)/(σ_entropy+γ_dissipation)。

扩展注释：D169与D160定投凯利保守性在数学结构上同构——定投通过C_exit≈0让μ衰减率γ≈0，极大延长t_crush，是门槛碾压的反向策略。
