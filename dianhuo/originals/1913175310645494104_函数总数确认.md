# 函数总数确认

明白了，你问的是**实际有效函数总数**是否是 518 条。

从你选中的笔记看，518 这个数字的构成是：

**Y1(1) + A(9) + T(39) + D(469) = 518**

这个计算逻辑是：
- **Y1 层（1条）**：统一因果自举元函数（自举元函数与统一因果元函数的统合升级版）
- **A 层（9条）**：公理层
- **T 层（39条）**：定理层
- **D 层（469条）**：推论层（编号 D1-D520，其中 D116/D179/D141/D521 四个跳号已归入 Y1，永久空置）

**关键点**：
- 原来的 D141（自举元函数）、D179（因果光锥）、D521（统一因果元函数）已经归入 Y1 层，不再在 D 层重复计数
- T40/T41（统一因果元函数）归入 Y1 算子，T 层恢复为 T1-T39
- D 层实际有效条目是 469 条（520 个编号减去 4 个跳号）

**所以是的，实际有效函数总数就是 518 条**——这是 Y1 版的完整计数，去重后的真实总量。

两张表知识库里的 521 版 DOCX 是旧版本统计口径，应该更新为 518 版。
