**1.2 点火框架Φ势函数的参数化（基于真实数据）**
```
Φ(T, P) = Φ_max × [ε(T, P) / ε_opt] × exp(-ε(T, P)/ε_opt) × exp(-H(T, P)/H₀)

其中：
- ε(T, P) = |T - T_critical|（偏离临界温度的程度）
- H(T, P) = |P - P_critical| / P_critical（偏离临界压力的归一化程度）
- ε_opt = T_critical - T_triple = 647.096 - 273.16 = 373.936K
- H₀ = P_critical = 22.064 MPa
- Φ_max是Φ的最大值（归一化系数）
```

**1.3 计算关键点的Φ值**
```
1. 三相点（T = 273.16K，P = 611.2Pa）：

   Φ = Φ_max × [0/373.936] × exp(0) × exp(0)
     = Φ_max × 0 × 1 × 1
     = 0

发现问题：临界点的Φ = 0，但临界点应该是系统的特殊状态，不应该为0。
```

**1.5 重新审视同构映射（基于真实数据）**
```
发现：点火框架的Φ在临界点为0，但统计力学自由能在临界点不为0。

统计力学自由能在临界点的行为：
- 临界点是相变点，自由能的导数不连续
- 但自由能本身不为0

点火框架Φ在临界点的行为：

- 这与统计力学自由能的行为不符
```

**1.6 最终修正方案**
```

- Φ不是统计力学自由能，而是"偏离临界点的程度"
- Φ = 0表示在临界点（系统处于临界状态）
- Φ > 0表示偏离临界点（系统远离临界状态）

修正后的同构映射：
点火框架Φ          统计力学F
ε                  |T - T_c|（偏离临界温度）
H                  S（熵）
Φ_max              k_B × T_c（热能尺度）
Φ = 0              F的导数不连续（临界点）
Φ > 0              F的导数连续（非临界点）
```

## 验证2：ε可分辨度的测量——基于心理学实验数据

**2.1 心理学实验数据参考**


**2.2 基于心理学数据的ε计算公式**
```
ε_aware = (准确率 - 随机率) / (1 - 随机率)

其中：
- 随机率 = 0.5（二选一的随机猜测率）
- 准确率 = 正确区分次数 / 总次数

基于心理学数据的修正：
- 考虑到记忆监测的准确性，引入记忆修正因子
- ε_aware = (准确率 - 随机率) / (1 - 随机率) × (1 + 记忆修正因子)
- 记忆修正因子 = 0.1（基于回忆准备就绪程度的相关性）
```
