## 一、层级体系定义

### 1.1 元层级（Meta Level）
- 定义框架的元规则和元操作
- 不依赖其他函数，是框架的元语言
- 用于验证和生成其他函数

### 1.2 公理层级（Axiom Level）
- 定义基础概念和数学结构
- 不依赖其他函数（除元层级）
- 是推导的起点，跨域通用

### 1.3 定理层级（Theorem Level）
- 从公理层级严格推导而来
- 具有通用性，跨域适用
- 依赖明确的公理级函数

### 1.4 推论层级（Derivation Level）
- 从公理级或定理级推导而来
- 在特定场景或维度上的扩展
- 依赖明确的上游函数

### 1.5 应用层级（Application Level）
- 定理级或推论级在具体场景的应用
- 依赖明确的定理级或推论级函数
- 案例映射或场景特化

## 四、层级标注规范

### 4.1 标注格式

```
推导层级 / Derivation Level: 
- 元层级（meta_level）：MF-0000~MF-0005
- 公理级（axiom_level）：A1-A23 + D476-D480 + T1-T4
- 定理级（theorem_level）：D220-D243 + T5-T39 + 其他
- 推论级（derivation_level）：D1-D515
- 应用级（application_level）：D141/D243/D490等
```

### 4.2 依赖关系更新

各层级函数的"依赖"（Depends on）字段需补充：
- **元层级：** 无依赖（或仅依赖其他元层级函数）
- **公理层级：** 依赖元层级函数（MF-0000~MF-0005）
- **定理层级：** 依赖公理级函数（A1-A23 + D476-D480 + T1-T4）
- **推论层级：** 依赖公理级或定理级函数
- **应用层级：** 依赖定理级或推论级函数
