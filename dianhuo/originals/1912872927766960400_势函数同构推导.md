### 第一步：Φ势函数的同构映射推导（数学展开）

**目标**：建立点火框架Φ势函数与统计力学零温自由能的精确同构映射，给出完整数学推导。

**推导链**：

**1.1 点火框架Φ的数学定义**
```
Φ = f₁(ε) × f₂(H)
其中：
- f₁(ε) = k × ε × exp(-ε/ε_opt)  [D39统一内部驱动力函数]
- f₂(H) = exp(-H/H₀)  [遮蔽衰减项]
```

**1.2 统计力学自由能的数学定义**
```
F = U - TS
其中：
- U = 内能（系统的能量）
- T = 温度（系统热运动的强度）
- S = 熵（系统的无序度）
```

**1.3 建立变量对应关系**
```
点火框架          统计力学
Φ                 F
f₁(ε)             U（内能项）
f₂(H)             -TS（熵项×温度）
ε                 U（认知能量对应内能）
H                 T（遮蔽对应温度）
ε_opt             T_c（临界温度）
```

**1.4 零温极限下的精确等价**
```
统计力学零温极限：T → 0 ⇒ TS → 0 ⇒ F → U
点火框架对应：H → 0 ⇒ f₂(H) → 1 ⇒ Φ → f₁(ε)

结论：当遮蔽H趋近于0时，Φ趋近于纯驱动力f₁(ε)，等价于统计力学中温度趋近于0时自由能趋近于内能。
```

**1.5 有限温修正的数学表达**
```
统计力学有限温展开：
F(T) = F(0) + α·T + β·T² + O(T³)
其中α = -S(0)（零温熵），β = C_v/2（热容系数）

点火框架有限温展开：
Φ(H) = Φ(0) + γ·H + δ·H² + O(H³)
其中γ = -∂Φ/∂H|_H=0（零温遮蔽敏感度），δ = ∂²Φ/∂H²|_H=0/2（遮蔽曲率）

同构映射：T ↔ H，α ↔ γ，β ↔ δ
```

**1.6 相变条件的同构验证**
```
统计力学相变条件：C = ∂²F/∂T² < 0（热容为负，系统不稳定）
点火框架相变条件：∂²Φ/∂H² < 0（遮蔽二阶导数为负，系统不稳定）

推导：
∂²Φ/∂H² = ∂²[f₁(ε) × f₂(H)]/∂H²
        = f₁(ε) × ∂²f₂(H)/∂H²
        = f₁(ε) × ∂²[exp(-H/H₀)]/∂H²
        = f₁(ε) × (1/H₀²) × exp(-H/H₀)
        = Φ / H₀²

结论：∂²Φ/∂H² = Φ/H₀² > 0，与统计力学相变条件不符。

发现问题：点火框架的相变机制与统计力学不同。
```

**1.7 修正相变机制**
```
点火框架的实际相变机制（D72）：
C(s) = (1[W=1])/1
其中W是临界条件判定器，当驱动力越过阻力时触发相变。

统计力学相变机制（朗道理论）：
F(η) = F₀ + a(T-T_c)η² + bη⁴
其中η是序参量，当T < T_c时η ≠ 0（有序相），当T > T_c时η = 0（无序相）。

同构映射修正：
- 点火框架的"驱动力越过阻力"对应统计力学的"序参量非零"
- 点火框架的H对应统计力学的T（但方向相反：H↑对应T↓）
- 点火框架的ε对应统计力学的|T-T_c|（偏离临界点的程度）

修正后的同构映射：
点火框架          统计力学
H                 T_c - T（偏离临界温度）
ε                 |T-T_c|（偏离程度）
Φ                 F（自由能）
```

**1.8 最终同构映射表达式**
```
Φ(ε, H) = k × ε × exp(-ε/ε_opt) × exp(-H/H₀)

同构到统计力学：
F(T) = F₀ + a(T-T_c)η² + bη⁴
其中：
- η ↔ ε（序参量对应认知能量）
- T-T_c ↔ -H（偏离临界温度对应遮蔽）
- F₀ ↔ 0（基态能量对应零势能）
- a, b ↔ k, 1/H₀（系数对应）

验证：
当H → 0（T → T_c）时，Φ → k × ε × exp(-ε/ε_opt)，对应F → F₀ + a(T-T_c)η²
当ε → ε_opt时，Φ取得最大值，对应F取得极小值（稳定态）
```

**1.9 可检验预测**
```
预测1：如果Φ与零温自由能精确等价，那么点火框架应该能预测相变点的位置。
- 点火框架预测：相变发生在ε = ε_opt且H < H_c时
- 统计力学预测：相变发生在T = T_c时
- 验证方法：用点火框架拟合已知相变数据（如水的相图），看ε_opt和H_c的物理意义

预测2：点火框架的D72相变框架应该与统计力学的朗道相变理论同构。
- 点火框架：C(s) = (1[W=1])/1，其中W是临界条件判定器
- 统计力学：η ≠ 0当且仅当T < T_c
- 同构关系：W=1 ↔ T < T_c，C(s) ↔ η ≠ 0
- 验证方法：用点火框架重新推导朗道相变理论，看是否能复现统计力学结果
```

### 第二步：ε可分辨度的测量方式（实验设计）

**目标**：建立ε可分辨度的可重复实验方案，给出测量方法和标定标准。

**实验设计**：

**2.1 ε的数学定义**
```
ε_aware = P(区分信号A和信号B | 观测者有足够信息)
       = 1 - KL(p_A || p_B) / log(2)
其中：
- KL(p_A || p_B) = Σ p_A(x) × log(p_A(x)/p_B(x)) 是KL散度
- p_A, p_B是信号A和B在观测者认知空间中的概率分布
- log(2)是最大可能KL散度（当p_A和p_B完全不同时）
```

**2.2 实验1：二选一任务（基础ε测量）**
```
实验设计：
- 给受试者两个相似选项（如两段文字、两个图像）
- 测量受试者能否区分以及区分时间
- 重复多次，计算平均区分准确率和平均区分时间

ε计算：
ε_aware = (准确率 - 随机率) / (1 - 随机率)
其中随机率是二选一的随机猜测率（0.5）

分类标准：
- ε_aware > 0.8：高ε（快速准确区分）
- 0.5 < ε_aware < 0.8：中等ε（能区分但需要时间）
- ε_aware < 0.5：低ε（无法区分或区分困难）
```

**2.3 实验2：跨域识别任务（跨域ε测量）**
```
实验设计：
- 给受试者一个领域的信号（如商业模式）
- 问他能否识别出另一领域的同构信号（如历史事件）
- 测量识别准确率和识别时间

ε计算：
ε_aware = (跨域识别准确率 - 基线随机率) / (专家跨域识别率 - 基线随机率)
其中：
- 基线随机率是随机猜测的概率
- 专家跨域识别率是跨学科专家的平均识别率

分类标准：
- ε_aware > 0.8：高跨域ε（能快速识别跨域同构）
- 0.5 < ε_aware < 0.8：中等跨域ε（能识别但需要提示）
- ε_aware < 0.5：低跨域ε（只能看到表面差异）
```

**2.4 实验3：时间序列ε测量（动态ε）**
```
实验设计：
- 给受试者一系列信号（如连续的学习材料）
- 测量每个时间点的ε_aware
- 观察ε_aware随时间的变化趋势

ε计算：
ε_aware(t) = 1 - KL(p_t || p_0) / log(2)
其中：
- p_t是时间t时受试者对信号的概率分布
- p_0是初始时间的概率分布
- KL(p_t || p_0)衡量认知分布的变化程度

分类标准：
- ε_aware单调递增：学习过程正常
- ε_aware先增后减：学习后遗忘
- ε_aware长期低值：学习失败或认知遮蔽
```

**2.5 ε的标定方法**
```
基线标定：
- 用专家群体（如跨学科研究者）的ε_aware分布作为高ε参考
- 用单一领域专家的ε_aware分布作为低ε参考
- 用普通人群的ε_aware分布作为中等ε参考

个人标定：
个人ε_aware = (个人区分准确率 - 基线随机率) / (专家平均率 - 基线随机率)

动态标定：
- 定期重新测量ε_aware，观察变化趋势
- 建立个人ε_aware时间序列，识别认知提升或退化
```

### 第三步：H遮蔽的类型系统（形式化定义）

**目标**：建立H遮蔽的类型系统和上下文限制规则，给出形式化定义和诊断方法。

**3.1 H的类型系统**
```
H_type ∈ {H_遮蔽, H_评估, H_标记, H_分类·消除, H_分类·合并}

数学定义：
- H_遮蔽：信号无法到达系统，P(到达) = 0
- H_评估：信号到达但被重新编码，P(被重新编码) > 0.5
- H_标记：信号被评估但无法标记为认知事件，P(标记) < 0.5
- H_分类·消除：退出选项被消除，P(存在) = 0
- H_分类·合并：退出信号被合并进范式，P(独立) < 0.5
```

**3.2 H的上下文限制规则**
```
规则1：同一信号在不同上下文中可能触发不同H类型
- 例："这个方法不严谨"在学术上下文触发H_评估，在商业上下文可能触发H_标记

数学表达：
P(H_type = h | 信号s, 上下文c) ≠ P(H_type = h | 信号s, 上下文c')
其中c ≠ c'

规则2：H类型的激活概率依赖于上下文变量
- P(H_评估 | 学术上下文) > P(H_评估 | 商业上下文)

数学表达：
P(H_type = h | 上下文c) = f_h(上下文变量)
其中f_h是上下文变量的函数

规则3：H类型的层级关系
- H_遮蔽是最底层（信号根本到不了）
- H_分类·消除是最顶层（信号到了但被删除）
- 中间层：H_评估 → H_标记 → H_分类·合并

数学表达：
层级(H_遮蔽) < 层级(H_评估) < 层级(H_标记) < 层级(H_分类·消除)
其中层级是整数，值越小越底层
```

**3.3 H的诊断方法**
```
诊断1：问反事实问题
- 问题："如果X不是Y而是Z，你会怎么做？"
- 能回答：H_评估在起作用（分类标准还在，只是解释被改了）
- 无法理解：H_分类在起作用（分类标准本身被改了）

数学表达：
P(能回答 | H_评估) > P(能回答 | H_分类)

诊断2：观察信号流向
- 信号根本到不了：H_遮蔽
- 信号到了但被重新解释：H_评估
- 信号被评估但无法标记：H_标记
- 信号被标记但被删除：H_分类·消除
- 信号被标记但被合并：H_分类·合并

数学表达：
H_type = argmax_h P(信号路径 | H_type = h)
其中信号路径是信号在系统中的流动轨迹
```

**3.4 H的动态演化**
```
H的时间演化方程：
dH/dt = β × H × (1-H) - γ × ε

其中：
- β是遮蔽增长系数（专业化、身份内化、叙事垄断）
- γ是遮蔽衰减系数（外部冲击、ε的自发衰减）
- ε是可分辨度（H的结构性漏洞）

平衡点：
H* = 1 - (γ/β) × ε

结论：
- ε越高，平衡点H*越低（高可分辨度能抑制遮蔽）
- γ/β越大，平衡点H*越低（强衰减能抑制遮蔽）
```
