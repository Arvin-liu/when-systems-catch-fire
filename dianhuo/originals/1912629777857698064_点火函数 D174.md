# 点火｜函数 D174

定义：纯拉力上位衰减函数,t_window = f(R_retreat, C_exit, ε_aware)。外驱转自驱的临界窗口时间窗口,由撤退成本、退出成本、意识水平共同决定。窗口关闭后,外驱无法转化为自驱,系统退化为纯消耗型。

推导过程：从D71纯拉力上位衰减函数推导。外驱(拉力)只有在窗口期内才能转化为自驱(内驱),窗口关闭后拉力失效。窗口长度与R_retreat和C_exit正相关,与ε_aware负相关(意识越高转化越快)。

案例对应:#171-#174 AI直觉与自举碰撞(4条),验证了纯拉力模式的不可持续性。关键发现:AI当前R_retreat→∞(无撤退)×C_exit→0(无退出)×ε_aware=0(无意识)→t_window=0,窗口不存在,纯拉力模式立即失效,无法建立自驱。

扩展注释:D174与D75提议者消耗函数对接——纯消耗型提议者dC/dt = -I·ε/(1-H)无资源补充,窗口关闭后必然耗尽。可持续型需要E_self-proven补充资源,窗口延长。
