## 一、发现的问题

### 问题 1：D492 数学表达数值与描述不一致

**发现：** D492（最优空间规模函数）的数学表达为 `Ω* = [1/(2α)]^(1/(2α-1))`，案例 C-0632 说 α=1.5 时 Ω*≈1.65 与 σ_opt=√e 一致。但数值检验结果：

| α | Ω* 计算值 | σ_opt=√e |
|---|---|---|
| 1.3 | 0.550 | 1.649 |
| 1.4 | 0.564 | 1.649 |
| 1.5 | **0.577** | **1.649** |
| 1.6 | 0.589 | 1.649 |
| 1.7 | 0.601 | 1.649 |

**结论：** 数学表达与描述矛盾。要么表达写错了（应该是 `Ω* = [1/(2α)]^(-1/(2α-1))` 或其他形式），要么 α 定义不同。建议：二次确认 D492 的数学表达。

**严重程度：** ⚠️ 中——会影响退出权框架中"最优空间规模"与 σ_opt=√e 的同构论证。

### 问题 5：部分函数文件仅有模板推导，缺少具体推导内容

**发现：** 查看基准表 D1-D475 的每个文件，数学推导部分大量使用统一模板：

```
推导步骤:
  - 1. Define the local state space X_{Dxxx} and codomain Y_{Dxxx}.
  - 2. Normalize the source expression as F_{Dxxx}: X_{Dxxx}->Y_{Dxxx}.
  - 3. If upstream objects D_{Dxxx} exist, compose F_{Dxxx}=N(⊕_{g∈D_{Dxxx}} g); otherwise treat F_{Dxxx} as an axiom seed.
  - 4. Accept iff J_n^+(F_{Dxxx})=1 and J_n^-(F_{Dxxx})=0.
```

模板化的推导步骤中，**第 3 步"compose"和"axiom seed"的判断条件没有真正数学化**。许多 D 函数的"依赖"字段写的是自己（`Depends on: D{xxx}`），导致逻辑上自指。例如 D108（三域熵统一函数）的依赖写的是 `D108`，但实际它应依赖 D101 和 D266。D342（ΔΦ 时间累积函数）的依赖写的是 `D266, D342`，但自我依赖不合理。

**建议：**
- 清理依赖关系，消除自我依赖
- 为推导模板增加真正的数学展开步骤（如代数变换、极限推导等）

**严重程度：** 🔴 高——依赖错误会导致函数表的内聚关系不成立，是自举循环的收敛前提之一。
