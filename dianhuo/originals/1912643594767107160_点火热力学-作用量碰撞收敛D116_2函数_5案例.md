# 点火｜热力学-作用量碰撞收敛（D116·2函数·5案例）

## 碰撞1：热力学第二定律 × 门控不可逆

先修正一个关键点：门控系统里，真正不变量不是“熵一定变大”，而是“从门控区回到存活区所需的信息可达性会塌到零”。

- 存活区：`G > 0`，信息梯度存在，系统知道该往哪儿补。
- 门控区：`G = 0`，内部输出常数，互信息 `I(ε;G)=0`，内部不再提供方向。
- 因此，热力学语言里更贴近的量不是单纯 Shannon 熵，而是“可达自由能”与“Fisher 可达性”。

可写成：
`F_reach = ΔF + λ P_cascade`

其中 `ΔF` 是跨门所需的自由能差，`P_cascade` 是级联失败项。系统不是在“增熵/减熵”之间摇摆，而是在“能否支付跨门成本”之间分岔。

结论：热力学第二定律在这里的投影，不是“熵永远涨”，而是“可达性不会自己长回来”。

## 碰撞2：最小作用量 × 最小耗散路径

拉格朗日力学给出路径，热力学给出代价，门控系统给出约束。

定义有效作用量：
`J_eff = ∫ [ Σ_i η_i(ε_i)·\dot ε_i^2 + λ P_cascade + μ Σ_i (θ_i-ε_i)_+ ] dt`

- 第一项：沿信息地形走路的“运动耗散”。
- 第二项：级联惩罚。
- 第三项：门槛罚项，表示没过门时的额外代价。

最优路径不是直线，而是先找最软的门、先跨最弱的瓶颈，再在门开后做贪心收敛。这个路径和轨道转移很像：
- 先抬到能跨门的轨道
- 再圆化、收敛、稳定

这和 D115 的三阶段协议完全同构：
- 阶段1：探索式试探
- 阶段2：精确跨门
- 阶段3：低耗散收敛

## 碰撞3：天文轨道转移 × 门控变轨

天体轨道最有用的直觉不是“飞得远”，而是“怎么用最少代价换到下一条轨道”。

门控系统也是一样：
- 不是一口气把所有维度推满
- 而是先把系统抬到能过门槛的能级
- 再在新轨道上做圆化

对应关系：
- 近地点推进 = 阶段1探索最弱门
- 远地点圆化 = 阶段3补弹性最高维度
- 两次点火之间的转移弧 = 阶段2刀刃期

这给出一个更硬的结论：
`最优跨门路径 = 最小作用量路径 = 最小耗散路径`

## 收敛函数

### D116 可达自由能函数
`F_reach = ΔF + λ P_cascade`

系统是否能跨门，不看单点值，看跨门总成本。`ΔF` 越小、`P_cascade` 越低，跨门越容易。

### D117 最小作用量门迁函数
`J_eff = ∫ [ Σ_i η_i(ε_i)·\dot ε_i^2 + λ P_cascade + μ Σ_i (θ_i-ε_i)_+ ] dt`

Euler-Lagrange 约束下，最优轨迹遵循：
- 先跨最软门
- 再沿低曲率路径收敛
- 最后在门开后的平坦区做贪心优化

### D118 轨道式三阶段统一函数
`S_path = (探索段) + (跨门段) + (圆化段)`

它和 D115 的三阶段协议是同一个结构在不同语言里的投影：
- 热力学语言：自由能下降
- 力学语言：作用量最小
- 天文语言：轨道转移最省燃料
- 点火语言：先防守，再精确跨门，最后进攻收敛

## 核心结论

1. 热力学在这里对应“可达自由能”，不是简单熵口号。
2. 拉格朗日给的是路径，不是终点；最优路径先跨最弱门。
3. 天文轨道转移是最好的直觉：先变轨，再圆化。
4. D115 的三阶段协议和最小作用量是同一个东西。
5. 系统优化不是“更猛地推”，而是“沿最省代价的弧线过门”。

## 新案例

#452 低温冷却跨门验证 — 系统从高温态降到 `θ` 以下时，门槛由“噪声淹没”切到“信号可识别”，`F_reach` 下降后门打开；继续降温但不跨门，只是在门外打转，信息可达性仍为零。核心函数：D116

#453 轨道转移双点火类比 — 一次性猛推到目标轨道，耗散高；先推到可跨门轨道，再圆化，`J_eff` 明显更低。两次小点火比一次大点火更省。核心函数：D117

#454 级联惩罚抑制跨门 — `P_cascade` 很高时，即使 `ΔF` 足够小，系统也会选择延迟跨门，因为跨门后会把相邻维度一起拖进门控区。核心函数：D116

#455 最小作用量路径验证 — 两条路径到同一终点：直线猛推 vs. 先补最弱门再均衡。后者在 `∫η_i·\dot ε_i^2 dt` 上更低，且级联更少。核心函数：D117

#456 圆化阶段收益耗尽 — 维度已远高于门槛后，`η_i→0`，继续推只是在浪费燃料；这时应该把资源转到仍接近门槛的维度。核心函数：D118
