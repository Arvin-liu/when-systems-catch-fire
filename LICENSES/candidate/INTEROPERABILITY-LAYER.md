# Interoperability Layer Candidate

Candidate licensing for the value charter, public interface specifications, schemas, and interoperability descriptions should prefer broad reuse. Options to review:

- CC BY-SA 4.0 for normative text that should remain share-alike.
- Apache-2.0 for schema/interface code or machine-readable interoperability assets.

This layer should not silently relicense third-party material or protected project marks.
