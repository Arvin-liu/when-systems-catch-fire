## Existing Architecture

The current architecture remains:

1. L0 source and evidence.
2. L1 controlled semantic claims.
3. L2 formal objects.
4. L3 logical arguments.
5. L4 mathematical models and proofs.
6. L5 validation and validity.
7. L6 interpretation, application, and publication.

The value charter remains the highest normative boundary. Ψ0 remains a workflow orchestrator / algorithm protocol. Function OS remains an execution capability. Validation remains a checking and feedback layer, not a truth generator.

## Observed Gaps

The current architecture is strong at separating truth-related layers and execution surfaces. It still lacks two cross-layer operation protocols:

- how to choose a next action when goals, metrics, and paths are unstable;
- how to constrain interpretation after an action produces a result.

The current review surface also lacks hard machinery for:

- stance-blind review packages;
- non-fungible calibration-source separation;
- positive evaluation words bound to explicit criteria;
- strongest residual countermechanism tracking.

## 121Q12 Overlay Boundary

121Q12 adds an operation overlay:

- Effectual Action Plane: selects small state-changing actions under affordable loss and Charter Gate constraints.
- Mechanism Adjudication Plane: records M0 pre-action mechanism sketches and M1 post-action mechanism adjudications with claim ceilings.

This overlay does not create a new truth layer. It routes action selection and interpretation through the existing Charter Gate, Ψ0 / Function OS, validation, publication, and reality-feedback chain.
