# 之元写作法故事规格

Method version: `0.3.0`
Status: `CURRENT_BACKSTAGE_TEMPLATE`

本规格用于后台生成与审计，不是前台提纲。字段顺序不是段落顺序；允许折返、留空、合并、分叉和 `UNNAMED`，不得把它变成固定层数、五段式或隐蔽分幕。

方法以之元命名以标记其心智与作品来源；模板只承载可迁移的心智层级跃迁内核，不能复制之元本人。

## 项目来源与表达目标

- 本次使用的实际点火来源（L0-L5／Q12-Q14／MCF／PSD／ARN／Atlas／Charter／current state）：
- 只作启发、不得当成证据的材料：
- 各来源版本、路径、commit 与 claim ceiling：
- 作品要让读者经历的认知运动，而不只是理解的结论：
- 不可映射残余、受损／沉默主体和不得提高的 claim：

## 同源对应审计

按实际需要记录，不要求每段或每层映射项目组件。

- 当前写作运动：
- 点火中的结构对应候选：
- 对应层／工件：
- 保持的角色、关系、时序或约束：
- 丢失、改变或不可映射的部分：
- 是否只是修辞类比：
- 此对应明确不能推出什么：
- 是否误把 design provenance 写成脑科学、形式同构或因果事实：

- 哪些证据会迫使潜题改变，而不是让材料服从预设结论：

## 动态层级记录

按真实生成需要复制、折返或合并，不预设层数。

### 工作节点 `<n>`

- 当前层观察范围／概念定义：
- 当前层不可容纳的残余：
- 下一层正在逼问什么：
- 因下一层而提前改变的当前层细节：
- 离开层／进入层：
- 跃迁接口：`双重归属铰链 / 概念递归重定义 / 未解决问题 / 相同张力 / 观察者变化 / 时间或意义连续变形 / 其他`
- 若递归重定义：同一概念的旧世界 → 新世界：
- 隐形连续性为何成立；为何不需要说明性转场：

- 回照后旧层新增意义：
- 潜题是否生长、移动、分叉、合并或反向显影：

## 潜题生长与反向显影

- 后层回链了前文哪些词、选择、张力或材料：
- 哪些开头／中段材料因此改变意义：
- 是否只是事后总结或空降宏大命题：
- 哪些部分应保持开放：

## 出版审计门

- 层级门：新层是否至少一次真正改写旧层？
- 连续门：跃迁是否有作品内部连续性，而非强制铰链词？
- 回照／潜题门：起点或旧层是否增义；潜题是否由材料生长？
- 证据门：哪些句子必须回链来源；哪些只能写成候选？
- 价值门：事实限制、个体经历、物理差异、受损／沉默主体是否保留？

## 信息增益停止

尝试的下一层是否改变：

- 问题／定义／边界／观察者：
- 机制／干预／残余：
- 潜题或此前层意义：
- 若全部为否：`STOP_NO_INFORMATION_GAIN`
- 潜题是否已经足以回照主要来路：
- 结束是否允许开放，而不强制总结：
- 停止理由（不得只写字数、幕数或“中心思想已总结”）：

## 可选高维压缩结尾

- 使用：`YES / NO / UNDECIDED`
- 若使用，可展开回哪些已生成层级：
- 是否格言化、空降宏大词或提高下层 claim：
- 若不用，作品如何自然结束：

## 返回点火记录

- 发布／试读版本、渠道、时间和受众范围：
- 要观察的误解、现实反例、遗漏主体、失败铰链、伪同构或伪压缩：
- 反馈主体、原文范围、时间、渠道和解释限制怎样记录 provenance：
- 哪些反馈可成为候选 L0 source／gap／现实反馈：
- 哪些只能作为审美、情绪或传播数据：
- 适用返回入口：`Q12 / Q13 / MCF / PSD / ARN / Atlas / iteration / other`
- 停止、修订、撤回与回滚条件：
- 禁止升级：点赞、赞美、传播和多 AI 共识不得直接升级真实性。

## 前台清除

删除字段标签、固定方法顺序、项目缩写、说明性转场、未经支持的强断言和机械模仿的作者意象。模板完成、CI、自动评分或“像之元”不得被写成文学质量证明。
