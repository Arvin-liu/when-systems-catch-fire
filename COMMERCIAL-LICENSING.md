# Commercial Licensing Candidate

This file is a candidate policy and is not an active commercial license.

Future commercial production use of BUSL-marked core software may require a separate commercial license or written reciprocal agreement. Commercial users should open a GitHub issue or discussion in this repository to describe intended production use, deployment scope, needed permissions, and proposed reciprocity.

No email address, payment account, or external approval path is created by this file. Commercial permission is effective only through an explicit written license or agreement from the rights holder.

Commercial licensing cannot purchase factual conclusions, evidence grades, merge rights, governance vetoes, privacy access, suppression of criticism, or exemption from red-team review.
