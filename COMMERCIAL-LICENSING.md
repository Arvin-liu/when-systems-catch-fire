# Commercial Licensing

Commercial production use of BUSL-covered core software beyond the Additional Use Grant requires a separate commercial license or written reciprocal agreement from the rights holder.

Commercial users should open a GitHub issue or discussion in this repository describing intended production use, deployment scope, needed permissions, and proposed reciprocity. This repository does not publish prices, payment accounts, or a company entity. Permission is effective only through an explicit written license or agreement.

Commercial licensing cannot purchase factual conclusions, evidence grades, rankings, merge rights, governance vetoes, privacy access, roadmap control, suppression of criticism, or exemption from red-team review.

Existing forks and copies obtained under the old MIT license may continue to use those old versions under MIT. Synchronizing or incorporating current and future BUSL-covered versions requires compliance with the current layered license.
