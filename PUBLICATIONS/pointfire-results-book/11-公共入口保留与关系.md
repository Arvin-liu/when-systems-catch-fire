# 公共入口保留与关系

新成果册是唯一 canonical 的总入口，但它不是删除旧公共材料的理由。现有入口按以下方式保留：

| 原有公共入口 | 处理 | 读者从哪里继续 |
|---|---|---|
| `HUMAN-READING.md` | 保留为十分钟人类阅读路线 | [人类阅读路线](../../HUMAN-READING.md) |
| `PUBLICATIONS/README.md`、第一卷、研究笔记、百轮台账 | 保留为历史出版层和旧版本来源 | [成果书架](../README.md) 与本册关系页 |
| `RESULTS/` | 保留当前结果、纠正、开放问题、裁决与研究文章 | [RESULTS 入口](../../RESULTS/README.md) |
| `KNOWLEDGE/` | 保留变化、地图、搜索、分层阅读和资产卡 | [知识入口](../../KNOWLEDGE/README.md) |
| Foundation / Function OS / MCF / PSD / ARN / language-thought | 保留各自正式文档和公开来源 | [正式仓库最新成果](09-正式仓库最新成果.md) |
| `docs/publication/` 与现有作品 | 保留原有公开文本和来源边界 | [之元写作法与公开作品](08-之元写作法与公开作品.md) |
| 独立 GitHub Pages 阅读面 | 不重新启用；当前证据显示已退出维护 | 以 repository Markdown 为持续公开权威 |

因此“唯一成果册”指唯一的总综合入口，不指唯一文件、唯一研究报告或唯一来源。旧入口仍可回答它们各自的问题；若发生冲突，以正式 main 的来源、状态字段和明确 claim ceiling 为准。
