# GetNote 主题成果：从 1329 条投影中留下什么

本篇不是 1329 条笔记的目录，也不是把 `claim_text` 逐行改成 Markdown。它使用 R1 已冻结的派生 projection、来源身份、审查状态、主题映射和 conflict-marker 工件，重新写出主题层的当前最佳命题。每个命题都同时回答：它从哪类材料反复出现、证据能到哪、什么地方冲突、最强替代解释是什么、什么变化会让它升级或降级。

## 先把数字放回正确位置

最终 projection 有 1329 行、1328 个规范化后的 distinct claim text、154 个 claim-bearing note key。全局 ceiling 是 931 `EVIDENTIALLY_SUPPORTED`、307 `SEMANTICALLY_INTERPRETED`、3 `STRUCTURALLY_VALID`、88 `NOT_ASSIGNED`；审查链有 1241 条 terminal、38 条 `ABSTAIN`、50 条未 adjudicated，6 个 note body recovery 仍 blocked；`EPISTEMICALLY_ACCEPTED=0`。

主题映射允许重叠。一个 claim 可以同时进入 AI、研究、治理和系统主题；主题命中数、note key 数和三条 source lane（`CURRENT_95`、`FULL_40`、`RECOVERED_19`）都不能直接当成独立证据数量。R2 的矩阵明确把 `independent_source_families` 记为 `NOT_ESTABLISHED_FROM_PROJECTION`，避免把同一来源的多次转述算成多项支持。

## 1. AI 与技术：能力叙述必须带评估条件

### 当前最佳命题

第一，AI 材料中最可靠的知识不是“模型已经具备某种普遍智能”，而是“某个系统、演示或报道在某个设置下声称完成了某种任务”。例如 derived claim `c04` 把宏观相关很高与回归显著性覆盖下降、接近随机的结果放在一起；它留下的可用洞见是：表面相似不能自动变成微观因果。

第二，生成能力和评估能力是两条不同的曲线。Apex Search、Epitome 等材料可以描述生成数量、模拟速度或演示流程，但如果缺少完整投稿样本、评分分布、录用结果、独立复现和失败集，它们最多支持“报道过一个能力主张”。

第三，因果世界模型、机器人、芯片和智能体材料不断把 AI 放入高价值决策场景；真正需要研究的是：当输出进入能源、制造、医药或公共决策时，谁能检查它、谁可以拒绝它、错误由谁承担。

### 来源与天花板

主题映射有 136 个 claim-row hits、60 个 note keys，显式映射中 105 条为 `EVIDENTIALLY_SUPPORTED`、15 条为 `SEMANTICALLY_INTERPRETED`，11 条有候选冲突标记。这里的“supported”是对来源投影或报告内容的支持，不是独立实测能力，也不是全局 epistemic acceptance。

### 冲突与替代解释

演示速度可以来自数据选择、提示工程或离线准备；公司指标可能是自报、最优场景或定义不透明；模型在平均指标上提升，可能同时在关键少数群体上退化。最强反例不是另一个漂亮 demo，而是预先定义的失败样本、盲测和外部复现。

### 升级、降级与研究问题

- 升级条件：原始评估数据、完整样本、协议、基线、负例、独立复现和错误责任链全部可回链。
- 降级条件：来源只剩标题/转述；样本、分母、评分分布、外部验证缺失；或后续反例显示能力只在展示环境成立。
- 研究问题：AI 生成速度何时超过人工审查容量？评估资源是否应成为能力声明的组成部分？

## 2. 研究与证据：速度不能替代可识别性

### 当前最佳命题

研究主题留下的是一条自我约束：相关、平均值、报道数字、模型模拟和单一指标都可能有信息，但它们不能自动回答“改变什么会导致什么”。`c04` 所代表的宏观相关/微观回归落差，是一个具体的警报，而不是一个可套用到所有研究的定律。

第二，证据链的价值不在于让每个结论都变强，而在于让读者看见它为什么不能更强：缺分母、缺基线、缺不确定性、缺原始数据或只知道演讲者声称，都应该成为正文状态。

第三，研究线与点火框架的共同问题是“解释是否抢跑”：框架先提出一个有吸引力的机制，研究者随后只寻找能够填入机制的材料。反向核验的目的就是保留不适配和 `NOT_IDENTIFIABLE`。

### 来源与天花板

主题映射为 185 个 projection hits、83 个 note keys，显式映射有 148 条 `EVIDENTIALLY_SUPPORTED`、15 条 `SEMANTICALLY_INTERPRETED` 和 24 个候选冲突标记。它们说明研究/证据话题密集，不说明有 83 个独立研究。

### 冲突与替代解释

同一数字可能被不同报道复述，来源看似增多但没有新增证据；高相关可能来自共同趋势、定义重叠或选择样本；失败结果也可能是测量工具失效而非命题错误。研究者应让替代模型、负结果和资源限制进入同一页，而不是只展示最佳路径。

### 升级、降级与研究问题

升级需要原始论文/数据、预先定义的分析、完整样本、独立复现和可定位的争议。降级触发包括只剩摘要、无分母、无基线、外部来源无法重取或冲突无法定位。研究问题是：在何种证据组合下，点火框架的变量比普通组织/政治经济解释增加了可预测信息？

## 3. 治理、责任与权利：留下审查链和介入权

### 当前最佳命题

治理材料反复指向一个具体要求：AI 进入科研或公共决策时，不能只保存最终答案和“一键确认”。研究问题、数据字典、分析脚本、运行记录、审查意见和人工裁决共同构成可追责链；主体需要介入、纠偏、解释和拒绝的路径。

这与点火的退出权形成一个结构桥：流程可运行只是协作层，主体是否能理解、质疑、退出和改变流程才触及认同与责任层。桥是分析相似，不是“治理已经解决退出权”。

### 来源与天花板

主题映射有 37 个 hits、26 个 note keys，显式 30 条 `EVIDENTIALLY_SUPPORTED`、4 条 `SEMANTICALLY_INTERPRETED`，3 个候选冲突标记。派生层支持“某种治理要求被提出或记录”，不支持这些要求在现实机构中已经有效。

### 冲突与替代解释

合规表格可能只是形式劳动；有审查意见不等于意见能改变决策；有申诉按钮不等于主体能够承受申诉成本。最强替代解释是组织仍把责任向下转移，只把可审计性当作免责材料。

### 升级、降级与研究问题

升级需要真实决策案例中的介入记录、错误纠偏、责任归属和主体可用性。降级触发包括只见政策文本、未见执行证据或退出路径实际上不可用。研究问题是：什么样的审查链能真正改变系统走向，而不是只在事后生成回执？

## 4. 经济与企业：激励不等于认领

### 当前最佳命题

企业材料最适合用来拆开三件事：企业自报能力、经济激励和成员认领。35 家企业、15000 小时、若干业务场景或预警准确率等数字，若来源只是公司披露，就只能说明“公司这样报告”；它们不能单独证明安全、可靠、员工认同或因果收益。

点火语言在这里提供一个可用但危险的提问：员工为什么留下？是薪酬、身份、共同目标、沉没成本、缺少替代工作，还是确实拥有改进方案的权利？这些解释必须并列，不能把留任率当认领度。

### 来源与天花板

主题映射有 107 个 hits、54 个 note keys，显式 80 条 `EVIDENTIALLY_SUPPORTED`、19 条 `SEMANTICALLY_INTERPRETED`，12 个候选冲突标记。该主题与 AI、系统、治理重叠很大，不能把总量相加。

### 冲突与替代解释

资本周期、补贴、市场垄断、组织选择效应和幸存者偏差都可以制造“成功企业已被认领”的外观。公司文化文本还可能把服从写成认同，把离职写成个人不适配，把失败写成市场原因。

### 升级、降级与研究问题

升级需要审计数据、对照、失败样本、员工/用户行动和实际退出路径。降级触发包括只有新闻稿、精选案例、无分母或无法独立重取的现场披露。研究问题是：激励、退出成本和共同目标如何分别解释组织成员的长期参与？

## 5. 历史与文化：长时段叙述不能压平差异

### 当前最佳命题

历史与文化材料真正提供的是长时段的比较入口：身份、制度、传播、战争、宗教、文本和组织可能跨越多个时间窗口。它们帮助点火框架提出“转身是否由多轮修订组成”的问题，但不能把一段讲述压成一个文明性格或单一转折。

文化协议先于制度硬件、外部锚定、提议者绑定等概念可以作为检索问题：谁在写、谁在接续、谁被排除、哪个阶段发生了制度化？如果缺一手史料、反方史料和时间序列，就应保持 `SEMANTICALLY_INTERPRETED` 或 `NOT_ASSESSED`。

### 来源与天花板

主题映射有 52 个 hits、35 个 note keys，显式 43 条 `EVIDENTIALLY_SUPPORTED`、3 条 `SEMANTICALLY_INTERPRETED`，5 个候选冲突标记。这里的 supported 多数对应某段材料/报道确实这样说，不等于历史因果成立。

### 冲突与替代解释

民族性格、文明基因和“几百年完成转身”的叙述很容易把内部差异、偶然冲击和制度争议抹平。战争、财政、技术、人口和外部国际秩序往往可以提供同等甚至更强的替代解释。

### 升级、降级与研究问题

升级需要原始档案、学术争议、时间序列和不同主体的材料。降级触发包括把作者评价、历史事实和项目解释写在同一个句子里。研究问题是：在不预设文明主体同质的情况下，如何比较多次小规模应约与一次宏大转身？

## 6. 写作与叙事：让结构可感，但不让作品替证据背书

### 当前最佳命题

叙事能把抽象机制变成可感的局部：一个退却动作、一个制度细节、一次停顿可能让读者看到退出、认领和时间差。但作品的说服力不是事实核验，试听反馈不是市场测评，作者自评不是文学共识。

这条主题与之元写作法相遇：多轨结构可以隐藏在故事中，把解释权交给读者；但“隐藏结构”不能隐藏证据缺口。历史、科学和公共人物材料进入叙事时，事实层和文学层仍需分栏。

### 来源与天花板

主题映射有 66 个 hits、30 个 note keys，显式 61 条 `EVIDENTIALLY_SUPPORTED`、3 条 `SEMANTICALLY_INTERPRETED`，8 个候选冲突标记。它支持“某作者/某报道提出了某种叙述或作品动作”，不自动支持作品质量和其中的事实句。

### 冲突与替代解释

少量主观试听、风格标签和读者赞美可能来自样本选择、熟人关系或情境效应。历史叙事的完整性可能只是编辑技巧，不能倒过来证明史实因果。

### 升级、降级与研究问题

升级需要可恢复用户文本、版本 provenance、编辑过程和明确的读者反馈设计。降级触发包括把第三方观点当原创、把缺失段落补写出来、或把跨域比喻写成科学同一。研究问题是：怎样让叙事保留读者的否定权，同时不牺牲事实来源的可追溯性？

## 7. 个人与心理：主体性是问题，不是现成测量

### 当前最佳命题

身体、环境、他者和历史被提出为“深度扎根智能”的组成条件；睡眠、情绪、人格、认知和主体性材料则展示了人们如何讲述体验。它们可以为点火的“心理退出”和“感知退出权”提供问题入口，但不能把一句演讲、一个产品流程或个案体验写成心理诊断。

### 来源与天花板

主题映射有 39 个 hits、28 个 note keys，显式 36 条 `EVIDENTIALLY_SUPPORTED`、2 条 `SEMANTICALLY_INTERPRETED`，7 个候选冲突标记。证据层能支持“某位讲者/产品/报道这样描述”，不能支持构念已经被测量。

### 冲突与替代解释

身体信号可能是相关指标而非原因，主观体验可能受记忆、期待和叙事影响；“心理退出”也可能与疲劳、健康、经济压力或组织冲突混合。若把不可见的内心状态当成框架变量的直接值，就会制造不可证伪的解释。

### 升级、降级与研究问题

升级需要明确定义构念、量表、时间窗口、主体同意、伦理保护和反事实。降级触发包括用心理词替代行为指标，或从单一体验推断群体状态。研究问题是：能否在保护隐私的前提下，用可观察行动和自愿报告区分心理退出与一般不满意？

## 8. 系统与工程：自动化必须配审查容量

### 当前最佳命题

系统主题的实质洞见是资源约束：自动化可以扩大生成、检索、模拟和传播，但如果审查、复现、隐私和人工接管能力不随之增长，速度会把错误扩散得更快。Apex Search 的论文生成披露、Epitome 的社会模拟演示和因果平台的产品描述，都更适合作为“系统声称能做什么”的输入，而不是自动化现实能力的证明。

这与私有控制—执行—证据—恢复—出版闭环的公开边界相遇：状态文件、来源哈希、独立角色、失败夹具和 clean publication 能证明流程边界；它们不能证明流程在所有环境、所有用户和所有外部系统中可靠。

### 来源与天花板

主题映射有 84 个 hits、51 个 note keys，显式 72 条 `EVIDENTIALLY_SUPPORTED`、3 条 `SEMANTICALLY_INTERPRETED`，5 个候选冲突标记。它与 AI/研究主题重叠，不能相加为“系统成果数量”。

### 冲突与替代解释

绿色流水线、回执齐全和演示成功，可能只是测试集、单机、单次或人为介入的结果。没有错误样本、恢复记录、用户影响和资源成本，就不能从工程状态推出现实可靠性。

### 升级、降级与研究问题

升级需要真实运行、错误复现、人工接管、权限边界和外部影响的独立记录。降级触发包括只有脚本/报告、没有失败路径，或把流程成功写成社会影响。研究问题是：审查容量、人工退出权和自动化规模是否存在可观测的安全阈值？

## 9. 跨主题桥：有相遇，也有不能推出的东西

### 证据 ↔ 治理

二者都要求保留来源、过程、反向核验和责任路径。共同点是“结果不能脱离生成链”；不同点是证据可追溯不等于主体真的拥有权利。研究问题是哪些记录能改变决定，而不只是让决定更容易免责。

### AI 能力 ↔ 评估能力

AI 主题的生成速度与研究主题的可识别性相遇：当生成数量增长，评估容量如果不变，未审查结果会成为系统新输入。这里是资源/治理问题，不是一个“AI 越强越危险”的普遍定律。

### 组织 ↔ 退出 ↔ 发声

企业激励、治理申诉和个人心理材料共同提示：留下、发声、离开和改进不是同一变量。桥可以指导案例卡设计，却不能从员工离职率推断所有成员的认同。

### 写作 ↔ 解释权

叙事可以把复杂结构交给读者，治理要求则要求主体能够质疑和纠偏。两者共享“不要把读者/主体锁死在唯一解释里”的方向，但文学开放性不等于制度退出权，必须保留边界。

## 10. 被明确保留的未决材料

- 88 条 `NOT_ASSIGNED` 不被主题 prose 悄悄吸收；它们仍需来源、语义或 owner 决定。
- 38 条 adjudication `ABSTAIN` 和 50 条未 adjudicated 保持原状态；“主题看起来相关”不是补审授权。
- 6 个 note body recovery blocked 不通过猜测、摘要或 API 幻想补齐。
- 外部验证状态仍不是全局完成；`EVIDENTIALLY_SUPPORTED` 在这里指派生层的来源支持上限，不是现实知识接受。
- candidate conflict marker 只是候选词法标记，尚未自动裁决矛盾；真正冲突要回到来源、范围、否定、时间和数字语义。

## 11. 下一轮研究问题

1. 如何从重复笔记中识别真正独立的 source family，而不是只按 note key 计数？
2. 如何把宏观相关/微观因果的警报做成跨主题可复用的审查模板？
3. 何种人工介入记录足以证明治理链实际改变了决策？
4. 如何把企业自报指标、失败样本和成员退出放进同一比较卡？
5. 如何在不公开私人正文的情况下，让用户原创作品保留足够的可读性与版本忠实度？
