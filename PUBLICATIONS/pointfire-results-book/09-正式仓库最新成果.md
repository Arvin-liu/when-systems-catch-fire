# 正式仓库最新成果：不能被旧综合覆盖的公共层

本页把正式公开仓库在 R2 之后已经形成的结果接回成果册。它们不是私有 R2 的附属物；它们拥有自己的公开来源、版本和证据上限，本书只做关系化综合。

## 认识论治理内核与联邦平面 R1

[Epistemic Governance Kernel and Federated Planes](../../docs/architecture/epistemic-governance-kernel-and-federated-planes.md) 把来源、命题、形式对象、证据、审查、public ceiling、合法悬置、降级、替代和撤回之间已经存在的接口首次整体显式化。它不是新的 L7/L−1，也不是“比元协议更真”的超公理：它只在治理范围上包含元协议本身，并限制其 identity、evidence ceiling、公开措辞与 revision lineage。

本 R1 的项目/架构状态为 `OWNER_ACCEPTED_WITH_EXPLICIT_RESIDUALS`。这表示 Owner 接受了项目内架构边界与正式公开发布资格，不表示外部真理、`FORMAL_KNOWLEDGE`、同行评审、普适有效性或 claim-level `EPISTEMICALLY_ACCEPTED`。四维成熟度固定为：operational `PHASE_MATURE_INTERNAL`；conceptual `FEDERATED_MODEL_SUPPORTED`；explicit_architecture `OWNER_ACCEPTED_WITH_EXPLICIT_RESIDUALS`；external_validity `NOT_ESTABLISHED`。

独立反统一裁决只支持 `FEDERATED_ARCHITECTURE_ONLY`。因此本结果单元的正面结论有明确上限：点火仓库内部已运行一组阶段成熟的治理平面，并可由一个 `REFERENTIAL_ONLY` kernel 索引共享禁升规则和 typed handoff；没有证据证明一个共享状态机、统一真值 authority、外部普适性或完成认识论。

[GetNote 1329 条内部压力测试映射](../../docs/architecture/getnote-1329-epistemic-governance-pressure-test.md)说明了这套 federation 如何保留 931/307/3/88 多种 ceiling、38 `ABSTAIN`、50 未裁决、6 个 source-recovery block 和 `EPISTEMICALLY_ACCEPTED=0`。它支持 fail-closed 内部运行的有界判断，不把 1329 行变成 1329 个真知识，也不把笔记键或重复转述当作独立 source family。

## Foundation 与断言治理

[Foundation 文档](../../docs/foundation/README.md)把函数、断言、关系、评分、隐喻、来源、证据、证明义务、反例和处置分开记账。历史函数资产的公开治理口径是 5,663 个 canonical identity cards；全语料非函数断言是 17,333 个 canonical claims。两组数字都只表示登记、分类和处置范围，不表示对象已经定义良好、完成证明或获得外部支持。

[函数深度裁决](../../docs/foundation/historical-function-deep-adjudication-20260729.md)和[非函数断言证据谱系闭合](../../reports/foundation-architecture/100-nonfunction-claim-evidence-lineage-closure.md)保留 quarantine、pending 和 open obligations。成果册把它们与私有 R2 的 516 条旧函数整理区分：516 是一条旧函数谱系的可读二次炼化，5,663 是正式公开 Foundation 的治理口径，不能相加或互相替代。

## Function OS：有界能力，不是普遍操作系统

正式仓库的 [Function OS v0.2](../../function-os-candidate/v0.2/README.md)及其[有界 benchmark 文章](../../docs/editorial/articles/007-bounded-trust-function-os-v02-capability-benchmark.md)保留两次结果：原始目标是 `PARTIALLY_SUPPORTED_WITH_IDENTIFIED_FAILURES`，25 个 false reject 暴露了 N2 嵌套相等提取缺陷；修复后在声明版本、样本、oracle 和有限符号确定性输入域内达到 `SUPPORTED_WITHIN_BOUNDED_DOMAIN`。这不声称完整沙箱化、生产就绪、概率/神经/分布式能力或普遍正确。

## MCF、PSD、ARN 与系统图

- [MCF](../../docs/architecture/multiscale-causal-fabric.md)可表示多尺度边界、路径、反馈、残差和因果候选；路径和 cone 不是现实因果证明。
- [PSD](../../docs/architecture/probabilistic-system-dynamics.md)在表示层区分观察概率与干预概率；写出 `do(X)` 不等于完成现实识别。
- [ARN](../../docs/architecture/adaptive-relational-network.md)表示时间路径、高阶关系和拓扑变化；邻接、中心性、相似度和社区不自动成为原因。
- [语言—思维逻辑平面](../../docs/architecture/language-thought-logic-plane.md)横穿 L0—L6，保存框架差异、来源语言和翻译残余，但不增加 L7 或新的真值层。
- [仓库原生系统图](../../docs/architecture/interactive-system-map.md)是 registry、typed propagation topology 和 layout 的确定性导航投影；不证明现实同构或理论完整性。

## Evidence Program 与失败门禁

[Crossref 试点](../../evidence-program/runs/IGNITION-EVIDENCE-PILOT-R1-CROSSREF-DOI-VERIFICATION/RESULT.md)在预注册协议内回收 117 条 DOI 的题名/年份元数据；[OpenAlex 试点](../../evidence-program/runs/IGNITION-EVIDENCE-PILOT-R1-OPENALEX-DOI-REPLICATION-20260801/RESULT.md)保留 supported、partial 和 null。它们是书目元数据结果，不是论文内容或点火理论被验证。

[苹果案例证据门禁](../../docs/editorial/articles/010-failure-case-evidence-gate-and-apple-case-adjudication.md)把历史 provenance、executable target、formalization 和 reproduction 分开；当前材料停在 `EVIDENCE_PARTIAL_OR_DISPUTED` 与 target absent，不把流行叙事写成唯一历史因果。
