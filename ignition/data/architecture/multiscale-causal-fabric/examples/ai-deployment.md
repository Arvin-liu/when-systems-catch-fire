# AI Deployment Fabric

Machine file: `ai-deployment.json`

This example separates an AI deployment decision, a persistent workflow state, individual model outputs, error propagation risk, review burden, supplier dependence, and longer institutional effects.

The important result is that successful output generation and downstream truth are different objects. AI output is not independent evidence; it is an artifact that must be checked against sources, repository state, tests, human judgment, and external feedback.

Boundary: this does not claim AI deployment is good or bad in general. It represents candidate channels and residues so that claims can be stopped at the right ceiling.
