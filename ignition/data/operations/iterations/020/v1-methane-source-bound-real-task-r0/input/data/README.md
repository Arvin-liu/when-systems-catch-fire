# Included GONGGA NetCDF inputs

These three original NetCDF files were used in the bounded annual integration:

- `2019_GONGGA-CH4_Flux_CAMS_TRO.nc`
- `2023_GONGGA-CH4_Flux_CAMS_TRO.nc`
- `2024_GONGGA-CH4_Flux_CAMS_TRO.nc`

Source: Zhao, Min; Wang, Yilong; Tian, Xiangjun (2026), *Global CH4 emissions (2019–2024) estimated by the GONGGA-CH4 inversion system*, Figshare dataset version 2, [doi:10.6084/m9.figshare.31939146.v2](https://doi.org/10.6084/m9.figshare.31939146.v2). License: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

The evidence package's `gongga-input-file-integrity.json` records the byte count, MD5, SHA-256, source URL, and package path for each file. The remaining 2020–2022 dataset files were not used here and are not included.
