# 当一个系统学会维护自己，它怎样避免把全部精力都用来维护自己？

> 之元写法 · Task 109 配套可读文章
> 这是一篇关于"如何决定下一步做什么"的文章，不是关于物理本身的文章。

## 核心问题

当一个研究系统已经学会维护自己——它会自查、自证、自纠、自传播、自审计——它最危险的倾向不是停步，而是把全部精力都用来**维护维护这件事本身**。新的清单、新的看板、新的协议、新的治理层，会像藤蔓一样爬满真正的研究，直到没人记得最初要回答的是什么。

Task 109 要建立的，不是一个更聪明的"自我维护系统"，而是一个有边界的、可被审查的**决策支持机制**：把仓库里真实存在的未决项、待定/隔离资产、证据义务、缺陷、陈旧面、能力缺口，变成一个**有排名、可解释、可审查的 backlog**，并只推荐下一步做什么——它不给自己授权去执行下一步。

## 排名不是真理

排名是一个**投影**，不是真理。它把许多难以比较的维度压成一个数字，是为了让人能做决定，不是为了假装数字本身公正。

我们的优先级模型用了十一个因子：犯错的后果、依赖中心性、可证伪性、数据与预言机的可得性、预期信息增益、实施与证据成本、可逆性与风险、成熟度缺口、与所有者的相关度、重复或既往失败、以及"这是实质工作还是又一层元工作"。每个因子都标了方向、权重和缺失时的中性先验。

但关键是：**没有任何一个标量可以抹掉否决权**。如果一件事的权威缺失、前置依赖未解、或风险不可接受，它的分数再高也会被强制置为"阻塞"。排名可以排序，但不能赦免。

## 证据成本为什么要紧

最诱人的错误，是把"重要"和"现在就能做"混为一谈。一个关于四种基本相互作用统一的宏大问题，显然重要；但它可证伪性低、数据与预言机几乎不存在、证据成本极高。如果排名只看"重要性"，它会被高高挂起，然后年复一年占据视线却不产生任何证据。

相反，一个被隔离的、边界清晰的可证伪试点——比如"117 条标记为 crossref_verified 的记录是否真能在 Crossref API 上解析到匹配的 DOI"——有直接的预言机、高可证伪性、低证据成本。它产出的不是宏大叙事，而是一个明确的通过/不通过。证据成本，就是"为了知道一件事，你实际要付出多少"。一个健康的系统会优先买那些**便宜且能真正确证**的答案。

## 宏大的问题怎样输给有界的测试

在这次的真实排名里，四种基本相互作用统一（OQ）得分 54.14，而有界的 crossref 完整性试点（C-01）得分 73.20。宏大的物理问题**没有**因为 rhetoric 而压过有界的、可证伪的试点。这正是我们要守住的：排名不能被叙事的体面绑架。

但这不意味着宏大问题被丢弃。它们仍在 backlog 里，带着自己的缺口与降级条件，清清楚楚。它们只是不被错误地提前排到队列顶端。

## 被阻塞的工作仍然可见

一个常见的腐败，是把"做不了的事"悄悄移出视野，假装它不存在。我们的 backlog 反其道而行：被阻塞、被隔离、被否决的项——quarantine 里的 A0…A08、DO_NOT_SCHEDULE 的资产、等待所有者决策的项——都**保留在清单里**，只是被排到低位并标注原因。可见，不等于被选中；可见，是为了不让系统对自己撒谎。

## 元工作的天花板

我们对"又一层治理"设了天花板：如果一个候选项的主要产出是另一个规划器、登记册、看板、协议或治理层，它必须证明存在一个现有系统无法解决的、具体的、未决的失败；否则它的"实质 vs 元"因子被压到 0.20 以下。结果，迭代增量、叙事溯源、项目吸引子这类元治理缺口，在排名里稳稳地坐在实质工作之下（51.50），而不是爬到顶端。近十日内候选的实质工作比达到 1.0，远高于 0.70 的门槛。

## 最终的权威仍属于所有者

这篇排名文章的全部意义，是给所有者一个**可审查的建议**，而不是替所有者做决定。推荐项 C-01 只是一个被审查的提案——它不会被自动创建为 task 110，不会被自动执行。系统可以维护自己，但"下一步做什么"这件事，必须留在人手里。

当一个系统学会维护自己，它避免被维护本身吞噬的方式，不是停止维护，而是**把维护的精力，用来购买便宜而确证的证据，并把"决定下一步"的权柄，留给真正负责的人**。
