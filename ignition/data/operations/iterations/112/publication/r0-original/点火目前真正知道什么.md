> 阅读方式：每一项都把一句结论和一句边界放在一起；“知道”表示在声明的来源、版本、输入或模型范围内可以支持，不表示永远正确或已经完成外部科学证明。

## 一、20 项当前能够支持的认识

1. **跨域相似性可以生成研究问题。** 边界：相似感、共同词汇和候选对应不等于严格同构、共享机制或因果。
2. **一个研究系统需要允许 pending、失败、降级和撤回。** 边界：保留不确定性不会自动解决被保留的问题。
3. **v0.2 的核心转向是从生成结构转向限制自己。** 边界：方法上的自我限制不是各领域的外部证据。
4. **数学、物理、历史、工程、法律和艺术需要不同的证据制度。** 边界：证据制度不同不表示不能协作，也不构成一条统一真理刻度。
5. **claim ceiling 能把一句话的可说高度贴近它的证据。** 边界：状态枚举是表达护栏，不是自动判真器。
6. **形式化工具可以在声明模型内产生证明、反例、化简或不可满足性结果。** 边界：有限对象、样本和符号化简不能证明现实中的普遍命题。
7. **Foundation 可以把函数、断言、关系、评分、隐喻和候选分开记账。** 边界：身份、类型和处置闭合不等于对象真实、新颖或有用。
8. **注册表可以保存对象的来源、状态、数学成熟度和 disposition。** 边界：注册表会计不是同行评议、复制或外部真理。
9. **quarantine 是一种保护当前公共表面的研究状态。** 边界：隔离不能永久替代定义、裁决或下一步证据。
10. **MCF 可以表示多尺度边界、路径、反馈、残差和因果候选。** 边界：路径、网络和 cone 不是现实因果证明。
11. **PSD 可以在表示层区分观察概率与干预概率。** 边界：声明这种区别不等于已经识别真实干预或建立现实动力学。
12. **ARN 可以表示时间路径、高阶关系和拓扑变化。** 边界：邻接、中心性、相似度和社区不是真理、本体或原因。
13. **Function OS 在符号、确定性、顺序组合和有限输入域内有可运行的候选管线。** 边界：它不是完整操作系统、通用解释器、神经/概率平台或生产安全系统。
14. **Function OS 的原始 benchmark 暴露了真实 parser 缺陷。** 边界：25 个 false reject 说明局部实现失败，不说明整个函数研究路线无效。
15. **修复后的 Function OS 在声明的 bounded benchmark 内达到支持结果。** 边界：修复后的 1.0 只适用于该版本、样本、oracle 和输入域，不能外推到所有函数。
16. **Crossref 试验能在固定协议内回收 117 条 DOI 的题名/年份并发现字段修正。** 边界：117/117 是元数据工程结果，不是 117 篇论文内容被核验。
17. **OpenAlex 试验能暴露 DOI 匹配的 supported、partial 和 null。** 边界：101/116 supported 是元数据匹配，不是论文主张或机制得到支持。
18. **后来的历史回忆来源把牛顿观察落苹果与思考重力联系起来。** 边界：这只支持 bounded memoir association，不支持唯一直接触发、瞬间完整理论或全部流行细节。
19. **苹果案例的 executable target absent 是有证据的工程结论。** 边界：没有 target 不是程序运行失败，也不是历史故事已被证伪。
20. **人类作品、机器索引、来源链、纠正和证据附录可以共同构成出版层。** 边界：可读性和可追溯性提高，不会自动提高任何现实命题的真值。

## 二、20 项已纠正、撤回或降级的认识

1. **“点火证明四种相互作用不可能统一”已撤回。** 边界：撤回总不可能性不等于证明真实统一可行；只保留声明有限模型内的结果。
2. **“零门让所有状态和信息消失”已改写。** 边界：当前只保留 carrier-scoped product readout，不能外推到所有载体和系统。
3. **用 Gödel、Hodge 或跨域类比直接构成现实 no-go 已阻止。** 边界：数学定理仍在原对象和假设内有效，不能靠词汇迁移。
4. **历史 D127 与形式化 T2 已分开。** 边界：两者可以同属问题谱系，但不能共享定理身份或证明高度。
5. **D260 的旧物理绑定已改为 p/(1-p) bias sensitivity score。** 边界：可计算对象被保留，现实物理保证被撤回。
6. **“图边/地图/路径就是因果”已纠正。** 边界：关系表示可以生成机制候选，但因果需要干预、识别和领域证据。
7. **“测试通过就是外部真理”已纠正。** 边界：绿灯只支持声明环境、输入、版本和 oracle 内的行为。
8. **“Pages 是权威事实层”已纠正。** 边界：页面是展示面；权威需回到来源、提交、运行产物和人类审查。
9. **“registry closure 就是所有对象为真”已纠正。** 边界：closure 只代表登记、分类、处置和谱系会计。
10. **“Crossref 117/117 说明 117 篇研究已验证”已降级。** 边界：只保留题名、年份和协议范围内的元数据回收。
11. **`INJECTED_VERIFIED` 来源状态已降为 metadata-only。** 边界：未读全文、未核验主张的来源不能继续使用 verified 的大词。
12. **“OpenAlex supported 说明论文内容支持理论”已降级。** 边界：101/116、8 partial、7 null 都停在 DOI/书目匹配层。
13. **“Function OS 18/18 coverage”已拆分纠正。** 边界：来源、全文、主张和 validator 必须分开，不能用一个覆盖率代替。
14. **Function OS 修复后的 1.0 不能删除原始 false reject。** 边界：修复版本与原始版本回答不同问题，失败必须保留。
15. **“Function OS 能覆盖所有函数”已收回。** 边界：当前 scope 只承诺有限符号确定性顺序函数域。
16. **“苹果是唯一直接触发重力理论的事实”已降级。** 边界：现有来源只支持有限关联，不能支持唯一性、反事实或瞬间完整理论。
17. **“苹果是可执行 implementation defect”未被提升。** 边界：因 target、I/O、trace、oracle、重复和回归门缺失，只能做历史/叙事审计。
18. **固定基线中的任务 111 研究证据不等于正式生命周期完成。** 边界：本全景只引用 bounded evidence，不代替正式状态裁决，也不把后续未终态恢复写成完成。
19. **“百轮就是一百次独立支持”已纠正。** 边界：百轮是混合的长期迭代史，不能替代外部独立复制和对照。
20. **“文件数、函数卡数和案例数就是研究成果数”已纠正。** 边界：它们是资产规模或索引口径，必须拆成研究、纠正、实验、基础设施、维护和混合成果。

## 三、20 项尚未解决的问题

1. **真实物理统一、量子引力、暗物质、暗能量和测量问题仍未解决。** 边界：点火目前只能整理问题和有限模型，不能提供物理答案。
2. **跨域结构何时构成严格对应或同构仍未解决。** 边界：共同词汇、图边和视觉相似不够，需要对象、映射、结构保持和反例。
3. **哪些候选机制能被真实干预区分仍未解决。** 边界：内部一致性和历史叙事不能替代干预、反事实和外部复制。
4. **MCF 的跨尺度桥接和残差如何对应现实测量仍未解决。** 边界：当前资产主要是表示和 validator，不是现实因果引擎。
5. **PSD 的观察/干预区分如何在真实系统被识别仍未解决。** 边界：schema 中声明 do(X) 不等于现实中完成因果识别。
6. **ARN 的关系投影何时具有领域语义仍未解决。** 边界：时间路径和拓扑验证不能自动获得本体或因果意义。
7. **Function OS 如何支持概率、连续、神经和分布式函数仍未解决。** 边界：不能把未来扩展写成当前能力，也不能只增加 parser。
8. **如何为复杂函数建立独立、可解释的 oracle 仍未解决。** 边界：没有 oracle 就不能把输出判为正确或错误。
9. **外部文献如何从 metadata-only 进入全文与 claim-level support 仍未解决。** 边界：找到 DOI、读到摘要和读过全文是不同状态。
10. **OpenAlex 的 7 个 null、8 个 partial 的真实原因仍未逐项核验。** 边界：null 不能直接解释成来源不存在或理论错误。
11. **苹果故事如何获得不冒充历史复原的 executable target 仍未解决。** 边界：没有 target 只能停在来源与主张审计。
12. **回忆来源、同时代记录、传播史和后见之明如何共同建模仍未解决。** 边界：memoir association 不能替代事件因果证明。
13. **公开函数计数 5,663 与机器 canonical 7,051 的口径差异仍未统一。** 边界：出版层只能并列快照，不能擅自选权威数。
14. **公开断言计数 17,333 与机器 canonical 17,626 的口径差异仍未统一。** 边界：quarantine/pending 的定义和生成范围也需要解释。
15. **传播图如何发现不在 seeds 中的未知依赖仍未解决。** 边界：一次 zero residue 只覆盖声明的局部运行。
16. **如何让领域专家真正改变对象、状态或正文仍未解决。** 边界：专家姓名、链接和意见列表不等于 adjudication。
17. **如何评价读者理解改善而不循环证明研究命题仍未解决。** 边界：读者共鸣、AI 重复输出和文章流畅性不是独立事实证据。
18. **如何建立跨轮真正独立的外部复制仍未解决。** 边界：任务数量和内部重复不能提供独立样本量。
19. **纠正如何稳定传播到旧文章、公共页面和机器索引仍未解决。** 边界：本包记录缺口，不执行正式远端维护或生命周期事件。
20. **点火能否在外部反驳中产生新的机制知识仍未解决。** 边界：如果所有反驳都被内部叙事重新解释为支持，研究仍是封闭的。

## 四、10 项最重要的后续研究方向

1. **设计真实系统的干预与反事实实验。** 边界：有干预字段不等于已经识别因果，必须写出替代机制和失败标准。
2. **建立严格的跨域映射和反例协议。** 边界：映射必须说明保持与丢失的结构，不能靠共同名词完成。
3. **为非符号 Function OS 先定义语义和 oracle。** 边界：扩展方向不是当前模块，也不能由 bounded benchmark 预支结果。
4. **开展全文和 claim-level 外部来源 adjudication。** 边界：全文读取仍需方法、样本、支持段和反方限制，不能只摘支持句。
5. **建立真实案例的 target presence 与失败接口。** 边界：target schema 只能让案例可执行，不会自动让历史模拟成为历史事实。
6. **统一 Foundation 的公共数字、快照和迁移谱系。** 边界：正式权威口径须由维护流程决定，本包只记录冲突。
7. **研究传播图的未知依赖和负向测试。** 边界：扩大 graph 不等于证明未知依赖为零，必须评估图的盲区。
8. **建立可改变结论的领域专家和反方审查机制。** 边界：审查参与应有来源、理由和影响记录，不能是装饰性的名单。
9. **评估写作与读者反馈的理解效果。** 边界：表达有效、读者理解和研究命题正确必须保持三条不同的评价线。
10. **把开放物理、历史和组织问题交还给真实研究共同体。** 边界：点火可以提供问题、来源和协作接口，不能替代实验室、档案研究、理论工作或同行评议。
