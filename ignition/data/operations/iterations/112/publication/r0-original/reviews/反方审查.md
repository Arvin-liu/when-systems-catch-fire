# 第一卷初稿：反方与过度主张审查

## 审查角色与范围

本审查把初稿当作一个可能说服读者的对手文本，主动寻找它如何借用数字、工程秩序、叙事流畅或“真正知道”的书名越过证据边界。这里不要求所有句子变成冷冰冰的报告，而要求每个文学性转折都不能暗中增加事实、因果或普遍性。

## 反方意见

|ID|定位|反方挑战|风险|必须采取的动作|
|---|---|---|---|---|
|A-01|书名“一个跨域研究系统真正知道了什么”|系统能否“知道”现实世界，还是只有仓库状态？|书名可能预先许诺外部知识|副标题或序中明确“知道”指当前可支持/可定位，不是世界真理；尾声重复一次|
|A-02|序“两组数字”|并列数字本身会让读者以为 7,051 比 5,663 更最终|大数字效应|在数字后先写统计对象和快照差异，禁止在同一段使用“最终/真实总数”|
|A-03|第一章“跨域观察”|是否把作者个人观察推广成普遍的人类经验？|起源故事变成普遍心理学|把“我们”改成“研究者/作者在材料中反复感觉到”，不声称普遍认知事实|
|A-04|第一章“候选生成能力”|候选很多是否真的增加认识？|用资产规模偷换研究成果|增加一句：没有新反例/测量/来源的候选只增加材料，不增加证据|
|A-05|第二章“好的解释”|文本认为解释能帮助选择测量，但仓库有没有真实预测成功？|把方法潜能写成已验证能力|改为“可以帮助设计下一步”，不写成已产生外部预测|
|A-06|第二章“点火发展出 claim ceiling”|是系统发现了方法，还是本书作者根据多个报告做的概括？|出版层结论伪装成仓库事实|标明这是跨报告的出版综合，来源是 ITERATION/操作报告|
|A-07|第三章“系统学会撤回”|系统真的能自主撤回，还是人维护者写入了撤回状态？|拟人化和自动治理过强|改为“研究者在系统中建立了撤回/降级路径”|
|A-08|第三章“物理不可能性被撤回”|撤回是否只代表当前作者不再主张，而不是数学/物理共同体裁决？|把内部撤回写成外部事实改判|加“在本项目的当前主张中撤回”，明确不代表领域结论已被裁决|
|A-09|第四章“Foundation 发现了身份不清”|机器分类如何知道身份不清？|生成分类被当成人类语义发现|写成“审计把一批对象标记为 identity unresolved”，避免把机器字段拟人化|
|A-10|第四章“账本保护研究者免于把材料当作世界”|账本是否真的能保护？旧句子仍会回流且数字冲突存在|把防护能力写成保证|改为“账本提供一种防止/发现的机会”，保留盲区例子|
|A-11|第五章“真实 parser 缺陷”|测试 oracle 和失败记录来自同一项目，是否称“真实”过强？|内部失败被误读为生产级缺陷|改为“可重放的实现缺陷/候选 runner 缺陷”，并说明真实指可在声明环境重现|
|A-12|第五章“成功变小了”|修辞漂亮，但读者可能记住 1.0 而忘记 domain|成功数字的记忆优势|把 bounded 条件放在 1.0 同句前半，附录不承担唯一限制|
|A-13|第六章“外部世界不会因为链接进入仓库”|Crossref/OpenAlex 本身就是外部接口，是否把“外部世界”写得太拟人？|制造内部/外部二元戏剧|改为“外部来源不会因为链接自动变成已核验内容”|
|A-14|第六章“第二次敲门带回未知”|API null 是研究未知，还是索引工程缺口？|把服务缺失提升为世界未知|改成“来源索引层的未知/缺口”，不写成论文内容的未知|
|A-15|第七章“苹果故事没有被点火证明”|“点火证明”这个说法是否暗示系统原本负责证明历史？|反方会认为设置了稻草人|改成“苹果没有被当前工程证据变成可执行历史事实”|
|A-16|第七章“目标缺失是最硬的工程结论”|没有 target 只是审计发现，为什么叫结论？|把缺失字段强行正面化|改为“审计最确定的结果是 target 尚不存在于当前材料”|
|A-17|第八章“点火不知道”|系统会不会其实知道更多，只是本书为了谨慎统一降级？|过度谦逊导致事实低估|每个未知都给具体缺失来源，避免泛泛说不知道|
|A-18|第八章“外部世界是否会认领这些问题”|认领是机构愿景，不是研究证据|机构化叙事自我封闭|改成问题而非预期结果，删除“会”字|
|A-19|第九章“研究基础设施的雏形”|Q24/Q25/Q32 是仓库内报告，是否足以称“基础设施”？|把报告描述提升成运行能力|说明“在仓库内形成的候选/局部操作基础设施”|
|A-20|第九章“研究机构第一条宪法”|一条宪法式句子可能制造新的宏大中心|出版物重新变成宣言|标题改为“一个最低工作原则”，并保留可被修订|
|A-21|第十章“最重要的十个方向”|排序依据是什么？是否只是作者偏好？|方向列表冒充战略共识|加“按当前证据缺口和潜在信息增量的本卷判断”|
|A-22|中场“一页全景”|全景列 70 项是否仍是另一个列表，而非真正全局？|数量替代理解|保留四块，但加一段总关系图：当前认识由哪些失败/纠正产生|
|A-23|中场“读者不是观众”|读者指出问题是否一定有价值？|把任意反馈升级为研究反馈|加“需能定位句子/来源/边界，且不能替代领域证据”|
|A-24|尾声“点火真正知道”|即便有边界，拟人化总结仍可能被摘成宣传语|结尾被脱离上下文引用|把尾声第一句改成“固定基线和本卷证据能够支持的，是……”|

## 反方结论

初稿没有回到早期的宏大理论，但仍有三种潜在过度主张：把内部治理拟人化为系统能力，把局部工程结果拟人化为现实知识，把出版层的综合判断写成仓库自身的发现。第二稿必须系统替换这三类语气，并在每个数字和方向前写清范围和依据。
