# R0 实质审读裁决

## 总裁决

`PARTIAL_REUSE_MAJOR_REWRITE_REQUIRED`

R0 不是不可验证的材料，也不是可以因产量直接通过的出版作品。它提供了一个有用的研究综合、80 条候选台账、10 个 binder 和一组独立性较好的笔记；但它在固定基线之后没有吸收正式 111 recovery-1 当前真相，且二稿在入口数字、来源 scope、台账分类和后半部重复上仍需要实质重写。R0 自带三重审查只能作为历史编辑材料，不能代替 112 的独立出版审查。

## 按交付物的决定

| R0 材料 | 112 决定 | 理由 |
| --- | --- | --- |
| 80 条台账 | 保留记录、重写字段和状态 | 记录覆盖有价值，但不是逐轮完整史，分类重叠，需加 output class 与 claim ceiling |
| 10 个 evidence binder | 作为证据索引和附录来源 | binder 可以定位材料，不能直接当作外部研究结果 |
| 第一卷二稿 | 主要重写后吸收 | 骨架和很多边界句可用，但需要改变入口、节奏、当前状态和章节转折 |
| 60 条研究笔记 | 55 条直接保留，5 条目标性重写 | 五字段齐全、无重复标题、无与二稿整段复制；N42/N47/N48/N49/N50 需更新来源/状态 |
| 70 项全景 | 保留四块结构，逐项复核 | 20/20/20/10 结构有效；纠正区和 111 状态必须同步正式当前真相 |
| R0 三份审查 | 只作历史输入 | 它们审查的是 R0 初稿，不是 112 的最终精确版本，也由同一前置工程产生 |
| R0 修订清单 | 作为问题发现材料 | `DONE` 不能直接视为 112 已修复，需要对最终稿重新验收 |

## 必须拒绝的 R0 读法

- 不能把 30,568 个汉字、80 条记录、60 条笔记或 72 条意见当作研究成果数量。
- 不能把“百轮”当作 100 个独立实验样本。
- 不能把 Foundation、Function OS、CI、tag 或终态化完整性写成科学正确。
- 不能把 Crossref/OpenAlex 元数据匹配写成论文内容支持。
- 不能把苹果 target absent 写成历史故事已被证伪，或写成一次可执行失败实验。
- 不能把 R0 固定基线下的 111 边界覆盖正式远端当前的 111 recovery-1 终态。

## 112 的实质改写标准

最终卷必须让一个陌生读者在不打开 JSON、任务文件或 PR 的情况下看见：问题从哪里来、哪些认识是窄而可靠的、哪一些强说法被撤回、哪些实验只有局部支持、苹果案例为什么停在 target absent、点火仍不知道什么，以及出版为何是研究责任而不是展示装饰。工程路径和提交只在来源附录与审计包中承担定位作用。
