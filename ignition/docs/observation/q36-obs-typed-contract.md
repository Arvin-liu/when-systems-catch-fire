# Q36-OBS Typed Contract — Observation–Prediction Calibration

> Schema: `schemas/observation/observation-prediction-contract.schema.json`
> Validator: `tools/observation/validate_observation_prediction_gate.py` (P1)
> Style: follows Q34 (`commitment-claim.schema.json`) and Q35 (`responsibility-contract.schema.json`) — draft 2020-12, `additionalProperties: false`, stable id patterns, fail-closed enums.

## Objects

### 1. `observation_spec`

Records what was measured. Key anti-leakage invariant: `observed_at` (event time) is separated from `available_at` (when the data became available to the predictor). Predictions must declare an `input_cutoff_time` that never crosses the outcome's `available_at`.

Required: stable id, construct/variable/unit/scale, target population/system/scope, measurement method + Q33-gated `source_ref`, sampling window, missingness policy, noise/uncertainty, provenance refs, `observed_at` + `available_at`, exact-head/artifact digest, quality status + exclusions.

### 2. `prediction_commitment`

Frozen **before** outcome reveal. Immutable `issued_at`. Post-reveal edits are forbidden; corrections are new supersession records that preserve the original (`superseded_by` link, `status: superseded`).

Required: stable id, normalized target, forecast horizon + evaluation window, typed prediction value (point / interval / distribution / class with legality constraints — probabilities and interval confidence in `[0,1]`), resolvable `model_rule_version`, `input_snapshot_digest` + `input_cutoff_time`, training/evidence refs, uncertainty, applicability scope, claim ceiling, Q34 claim ref + Q35 actor/grant/trajectory digest, exact-head digest, immutable `issued_at`, supersession policy, status.

### 3. `outcome_binding`

Binds a frozen prediction to an independent outcome observation. Records the deterministic `matching_rule` (target/window/scope/unit), `inclusion_status` (`included` / `excluded_with_reason` / `abstained` / `deferred` / `missing`), mandatory `exclusion_reason` when excluded, evaluator, and `independent_evidence_status`. An outcome whose sole evidence is generated by the same object that produced the prediction is `self_generated_forbidden` and fails closed.

### 4. `evaluation_calibration`

Deterministic metrics only: absolute/squared error, interval coverage/width, Brier/log score (legal probability ranges), calibration bins, residual sign/magnitude, baseline comparison, missing/abstained counts. **Mandatory**: `sample_size`, `scope_summary`, `baseline_comparison`, `computation_method`. A single metric never auto-declares universal validity.

### 5. `residual_anomaly`

Preserves failures and negative results. `do_not_infer_cause` is a hard `const: true`. Records residual type (including `missing_outcome`, `deferred_outcome`, `abstained_prediction`, `unresolved_anomaly`), magnitude/direction, expected vs unexpected, known data-quality explanation, escalation target (`q36_int` / `q39_failure_memory` / `none`), claim ceiling. This is the read-only interface toward Q36-INT and Q39; F15/D1/D2 are NOT materialized in this iteration.

## Invariants enforced by the validator (P1)

1. Schema + required fields (fail closed).
2. `prediction.issued_at < outcome.available_at` for every included binding.
3. `prediction.input_cutoff_time <= outcome.available_at` (no future information).
4. Prediction target/window/scope/unit matches outcome construct per `matching_rule`.
5. Model/version/input snapshot/exact head resolvable (digest formats, 40-hex heads).
6. Q34 claim state allows the prediction to be declared a project conclusion (`committed_current`).
7. Q35 actor/grant/trajectory references are present and well-formed (the Q35 gate itself decides legality; Q36-OBS calls it, does not duplicate it).
8. Q33 rights/publication gate is not bypassed for observation sources.
9. Probabilities, intervals, units legal.
10. Outcome must not be self-generated by the predictor as sole evidence.
11. No silent post-reveal prediction modification (digest pinning + supersession-only).
12. Excluded/abstained/missing outcomes are preserved, never deleted to beautify performance.
13. Target/definition drift must be explicitly versioned (new normalized_target = new prediction family).
14. Claim ceiling must not expand finite-scope performance into universal predictive capability.
15. Correlation/fit/accuracy must not be upgraded to causal mechanism.
16. Calibration summaries bind sample size, scope and computation method.
17. Failures and negative results are preserved as residual records.
