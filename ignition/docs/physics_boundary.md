# 点火框架与物理学问题的边界

## 核心定位

点火框架不是物理学理论，不替代标准模型、广义相对论、量子场论、粒子物理或宇宙学。

它能做的是：在结构层面分析物理理论中的统一、门控、耦合、相变、收敛、约束和存在性条件。

它不能直接给出：

- 统一规范群；
- 拉格朗日量；
- 哈密顿量；
- 具体粒子谱；
- 耦合常数数值；
- RG 流精确结果；
- 实验可测数值；
- 替代标准模型的完整理论。

## 关于“物理大一统不可能”

“物理学已经证明大一统不可能”现已正式撤回。它不能仅改名为“结构性边界推论”“框架判定”或“元层机制”后保留同一结论。

当前只允许写：

> 点火现有门控乘积模型没有完成四力统一；四力统一问题本身保持开放。

哥德尔不完备性、霍奇猜想类比、不同能标、不同函数族和当前模型失败都不是物理学 no-go theorem。未来若提出新的有界数学命题，必须重新定义模型类、统一、假设、量词、反例域和证明工件；它不能继承已撤回断言的结论权限。

## 关于“四种基本力统一”

点火框架可以将基本力统一画成“门控面在高能尺度上的合并”这一结构类比。

但这不是粒子物理意义上的四力统一理论。

要成为物理学意义上的统一候选理论，至少需要给出：

1. 统一规范群；
2. 场内容与表示；
3. 对称性破缺链；
4. 低能极限如何恢复标准模型与广义相对论；
5. 耦合常数的 RG 流；
6. 异常消除；
7. 质子衰变、LHC、宇宙学或其他实验约束；
8. 可检验的新预言。

在这些条件满足前，项目中的“四力统一”应表述为：

> 四种基本力统一的待验证结构类比：门控面合并；它尚不是物理机制。

而不是：

> 四种基本力已经被点火框架统一。

## 关于“七团乌云”

点火框架中的“七团乌云”应被明确为项目自定义的跨域同构瓶颈，而不是物理学史或现代物理中公认的固定问题列表。

如果要继续使用这个说法，需要创建明确清单：

1. 每一团乌云是什么；
2. 它对应哪个学科问题；
3. 主流定义是什么；
4. 点火框架给出的结构性解释是什么；
5. 哪些证据支持；
6. 哪些条件下失败；
7. 当前状态是 `true / false / contradiction / pending` 中的哪一种。

## 推荐表述

推荐使用：

- “结构性推论”
- “候选机制”
- “框架内判定”
- “待验证命题”
- `pending`
- “门控面合并机制”
- “跨域同构瓶颈”

避免使用：

- “已经证明”
- “已经解决”
- “已经统一四种力”
- “物理学大一统已被否定”
- “现代物理七大难题已解决”
