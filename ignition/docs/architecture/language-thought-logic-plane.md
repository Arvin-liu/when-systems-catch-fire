# 语言—思维逻辑平面

English: **Language–Thought Logic Plane**

Version: `0.1.0`

Status: `CURRENT_CROSS_LAYER_CONTROL_PLANE`

## 架构裁定

点火把“语言条件化的思维组织”实现为一张横穿 L0—L6 的正交控制平面，不增加 L7，也不把它降格为 L6 的中文润色器。

这里的“逻辑”不是另一套真假规则。它指人在准备说出、抽取或翻译一个意思时，语言反复要求或倾向要求他怎样安排话题与主语、显露行为者、划定事件边界、标记知识来源、恢复省略成分、连接分句和组织已知／新信息。数学命题和经验证据不会因为换一种语言而改变真值；语言形式本身也不能提高任何 claim ceiling。

```text
                    语言—思维逻辑平面
           来源形式 ⇄ 框架差异 ⇄ 残余 ⇄ 目标语言实现
                              │
        L0 来源 → L1 命题 → L2 对象 → L3 论证 → L4 机制 → L5 验证 → L6 表达
```

这个位置经过三种方案的比较：

| 方案 | 裁定 | 原因 |
|---|---|---|
| 只放在 L6 | 拒绝 | 行为者、证据来源、事件边界和连接关系可能在 L1—L4 已经被改写；末端润色看不见上游损失。 |
| 增加 L7 | 拒绝 | 语言不是更高的真值等级；新增层会错误暗示表达形式拥有认识论加权。 |
| 横穿 L0—L6 的正交平面 | 接受 | 每层保留同一组有限维度的框架变化，L6 再执行具体目标语言实现闸门。 |

## 权限边界

这张平面可以：

- 记录来源语言、语体、版本、翻译者或模型与转换链；
- 发现行为者、体貌、证据来源、话题焦点、连接词等发生了什么变化；
- 要求把未能带入目标语言的部分留下，而不是悄悄消失；
- 在结构化记录可判定时失败关闭，并把自然度、文学标记性等判断交给人类审查；
- 让同一套维度服务中文、英文及有边界的对照语言配置。

它不能：

- 从一种语言推导民族性格、文明本质或个人思想能力；
- 把语言倾向当成历史机制、科学证据或必然因果；
- 假装存在完全中性的“语言背后真义”；
- 仅凭回译相似、规则通过或自动评分证明意思完全保真；
- 把文学感染力变成事实、因果或价值主张的证据。

## 有限维度而非无限算法

权威维度表位于 [`data/language-thought/dimensions.json`](../../data/language-thought/dimensions.json)，人类说明见[维度基底](../language-thought/dimensional-basis.md)。语言配置只描述这些维度上的语法义务、常见倾向、可选空间、标记形式、反例和未决问题。它不是每种语言一套互不相通的算法，也不是给每位使用者贴固定标签。

当前完整配置为现代普通话书面中文与当代标准书面英语。日语和土耳其语是有边界的对照试点：前者压力测试话题、省略、视角和敬语，后者压力测试 SOV 信息结构、黏着形态与语法化证据来源。选择它们是为了覆盖维度，不是为了代表国家或文明。

## 结构化转换契约

每条受语言影响的正式转换至少保存：

`source_form → source_language_profile → normalized_meaning_candidate → target_form → target_language_profile`

并同时保存 `framing_deltas`、`unmapped_residue`、`claim_ceiling`、provenance 与 version。所谓 `normalized_meaning_candidate` 只是便于比较的候选投影，不是脱离语言的真实意义。只要一个认识相关维度发生了变化而记录中没有声明，验证器就失败关闭。

## 与 L0—L6 的关系

各层责任见[跨层合同](../language-thought/cross-layer-contract.md)。简要说：L0 保存语言来源与转换链；L1 审计命题框架；L2 保留对象／事件包装的备选；L3 审计篇章和论证连接；L4 检查机制主体、终点、视角与反事实；L5 保存对照、残余和人工裁定；L6 通过目标语言配置直接成文。

之元写作法是这张平面的一个 L6 使用者，不是它的容器。中文作品应先让事件、关系和信息顺序按中文真正发生，再考虑句子的文学压力；不能先搭一个潜在英语结构，再替换成中文词语。

## 系统图解释

系统图把本平面投影成独立 overlay，并用声明性的仓库同步关系连接 L0—L6 与之元写作法。图上的连线只表示版本和审计义务，不表示语言造成认知结果的现实因果，也不改变 `layers` 组严格只有 L0—L6 的约束。

## 当前限制

- 自动门只验证显式框架标注的一致性，不能从任意散文中可靠推断全部意义。
- 中文与英文配置有完整维度覆盖，但仍限定于当前书面语范围，不代表所有方言、时代和语类。
- 日语与土耳其语配置是初步试点；需由相应语言的专业使用者继续裁定具体成品。
- 韵律、自然度、语体和有意反常句法必须经过人工朗读与编辑审查。
- 研究文献同时包含正效应、空效应与条件效应；本架构不把任何单项实验扩大成强语言决定论。
