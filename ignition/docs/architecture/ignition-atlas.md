# Ignition Atlas

Status: `121Q14_MAP_PROJECTION_OVERLAY`

The Ignition Atlas is a set of versioned derived maps. It is not a new source of truth.

Registries, matrices, schemas, source records, tests, and repository artifacts remain the authority. A map is a projection from those sources for a declared observer, decision question, value recipient, time, and coordinate system.

## What A Map Adds

A matrix says which objects relate. A graph says what connects. A map additionally declares:

- who is looking;
- which decision is being supported;
- who receives value or bears cost;
- what the axes or layout mean;
- which objects are closer to the declared value recipient;
- which dependencies matter for navigation;
- which components are genesis, custom-built, product/rental, or commodity/utility;
- which action is build, buy, rent, outsource, automate, preserve, freeze, stop, or pending;
- which residue remains unmapped.

## Boundaries

Map position is not proof. Visual proximity is not isomorphism. Evolution stage is not a natural law. Dependency is not causality. Sourcing decisions do not transfer Charter Gate responsibility.

There is no permanent total map of 点火. Each map is versioned by `as_of_commit` and by its declared observer and decision question.

## Map Modes

`WARDLEY_STYLE_EVOLUTION` maps use value visibility and dependency chain against evolution stage. They are allowed for resource and operation decisions.

`STRUCTURAL_LANDSCAPE` maps use explicit structural or workflow relations when Wardley-style axes would mislead.
