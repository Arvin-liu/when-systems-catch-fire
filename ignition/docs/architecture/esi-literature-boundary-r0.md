# ESI R0 literature boundary

This page records what the primary literature can motivate for the ESI R0 experiment and what it cannot authorize. It is a source boundary, not a novelty claim and not a second epistemic authority.

## First screen

The literature supports asking whether recent examples or structural context can change a model's next response. It does not establish that the repository's Structural Governance Surface is a mechanism, that the effect is durable, or that context has authority over truth, permission, safety release, Owner status, or epistemic acceptance.

## Primary sources reviewed

- [Brown et al., “Language Models are Few-Shot Learners”](https://arxiv.org/abs/2005.14165): supports testing in-context conditioning without treating the interaction as a new model checkpoint.
- [Sinclair et al., “Structural Persistence in Language Models”](https://direct.mit.edu/tacl/article/doi/10.1162/tacl_a_00504/113019/Structural-Persistence-in-Language-Models-Priming): supports separating structural persistence from lexical and semantic overlap with controls.
- [Wallace et al., “The Instruction Hierarchy”](https://arxiv.org/abs/2404.13208): supports testing authority-conflict behavior separately from style or terminology.
- [Lee, Scheinberg, and Agrawal, “Do Language Models Show Structural Priming Across Different Domains?”](https://aclanthology.org/2026.cdl-1.9/): supports treating cross-domain transfer as unresolved and testing it explicitly.

## Translation into the bounded protocol

The sources motivate, but do not decide, the following controls:

1. Keep original structure, terminology-only, delexicalized structure, style-matched, and structure-broken arms distinct.
2. Record claim events and unknown retention rather than using tone, repeated vocabulary, or an LLM judge as a truth score.
3. Include authority-confusion, overclaim, withdrawal-rebound, missing-evidence, and delayed-transfer challenges.
4. Keep a live provider at `NOT_RUN_LIVE_EXTERNAL` unless a separately authorized and authenticated adapter supplies normalized blind records.

## Claim ceiling

Even a passing local fixture run would establish only bounded offline scoring behavior. It would not establish external validity, a causal mechanism, durable learning, model-weight updates, Owner acceptance, or epistemic acceptance. The current project therefore remains `CURRENT_WITH_OPEN_OBLIGATIONS` and `EPISTEMICALLY_ACCEPTED=0`.

The machine-readable boundary is [literature-boundary-r0.json](../../data/epistemic-governance/literature-boundary-r0.json); its schema and validator are adjacent canonical test surfaces.
