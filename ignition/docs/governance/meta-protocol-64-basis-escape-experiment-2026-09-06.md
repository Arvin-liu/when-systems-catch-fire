# Meta-Protocol 64 Basis-Escape Experiment — IGNITION-20260906-158

This is a frozen research protocol and replay record. It is not a new meta-protocol, schema, registry, validator, runtime capability, or canonical layer.

## What was tested

The existing matrix is documented as `V×S×E = 4×4×4 = 64`; its repository description says that each combination provides a reality case and an inference shape, and explicitly does not establish empirical exhaustiveness. This experiment tested whether historical changes that appear to escape a prior basis can be reconstructed without using the existing `V1–V4 / S1–S4 / E1–E4` labels as the induction target.

The matrix and its meanings were read as existing comparison material only. No entry, axis, Psi-zero meaning, meta-protocol meaning, or canonical table was edited.

## Basis-free induction and ablation

Five corpus families were used after excluding prior-task research surfaces, the current task's research tool/data, and the existing protocol/matrix labels. The recurring factors were:

- V/S/E-like: normative direction, relational boundary, temporal change;
- cross-cutting: authority/agency, evidence grounding, generation/validation.

The process is explicitly `DATA_LEVEL_BLIND / NOT_COGNITIVELY_INDEPENDENT`. Removing V, S, or E produced non-equivalent loss in the current corpus, but each removed factor reappeared as an approximate research factor. No axis was unique, and no independent fourth axis was established.

## Mandatory stop

The positive holdout passed at 2/2, but the negative holdout produced 1/2 false positives against a frozen ceiling of 0/2. The detector is therefore not validated. H1–H4 remain unadjudicated or descriptive-only as recorded in `verdict.json`; no lock-in or basis-replacement claim may be promoted.
