# Human Surface 编辑契约

状态：`CURRENT_WITH_OPEN_OBLIGATIONS`  ·  版本：`1.0.0`  ·  写作方法：[`之元写作法 0.5.0`](../publication/zhiyuan-writing-method.md)

本契约把“所有 Human Surface 必须经过之元写作法”变成长期制度。它不是第二套写作方法，也不是事实、证明、外部证据或 Owner 授权。它只规定：机器记录如何被翻译成面向人的入口，以及这次翻译必须留下哪些边界。

## 适用范围

凡是面向人的项目入口、结果页、成果册、文章、案例、研究报告摘要、函数资产、非函数资产、写作片段、失败说明、负结果和公共回应，均属于 Human Surface。机器 JSON/JSONL、schema、测试日志和内部收据可以保持精确字段，但只要它们被转成面向人的页面，就必须经过本契约。

## 每页必须回答的五件事

1. **它是什么、为什么出现。** 用目标读者能直接理解的语言说明对象、来源类型和阅读目的。
2. **它可以做什么。** 只写当前登记允许的用途，例如继续阅读、比较、复核、提出下一步问题或运行仓库内的受限流程。
3. **它不能推出什么。** 把登记、内部测试、工程完成、相似性、Agent 共识和文章感染力与证明、因果、外部事实、普遍有效性分开。
4. **还缺什么、下一步是什么。** 把开放义务、失败、反例、未核来源、撤回、降级、隔离和继续追的问题写出来；没有下一步时明确写“未登记”。
5. **如何回到精确记录。** 在次级技术记录中保留 machine ID、canonical 路径、M/E、claim ceiling、状态、来源路径、来源 hash 和机器记录 hash。

自然语言是主阅读通道；枚举、ID、M/E 和 registry 字段不能直接充当段落。它们应先被翻译成普通话，再放入维护者可展开的技术记录。人话页的陈述不得改变 canonical 状态，也不得把摘要重新变成来源。

## 信息架构

Human Surface 采用三层结构：

- 第一层是人类入口：说明普通读者从哪里开始、为什么值得看、机器记录规模与范围；数量是登记规模，不是“发现数量”。
- 第二层是主题、家族和处置：按问题、对象类型、历史/撤回、待决义务和材料性质导航，不以 `page-001` 或自动分页作为主要入口。
- 第三层是有 materiality 的对象说明：每条说明使用上述五件事；剩余批量记录在机器侧保留，并用一页 bulk 说明解释它们为什么没有被伪装成文章。

materiality policy 是覆盖政策，不是质量评分。重要、边界敏感、撤回敏感、对普通读者有解释价值的对象优先获得独立说明；其余对象仍可通过机器 registry、搜索、来源锚点和迁移 manifest 复核。

## 来源、状态与新鲜度

每条人话说明必须同时保存：

- machine record hash；
- source hash。来源已退役时，使用迁移 manifest 中的原文 hash，并链接 manifest，而不是制造一个失效旧路径；
- canonical machine ID 与机器源；
- 生成所用的 `之元写作法 0.5.0`。

源 hash 或机器记录 hash 变化时，生成器必须报告 stale；禁止手改生成页来遮盖漂移。人话层可以说明状态，但状态 authority 始终属于 canonical registry、Git 历史和治理收据。

## 机器可检查的最小门禁

结构校验器可以检查：

- 每个 Human Surface 是否有“是什么/为什么、可以怎么用、不能推出什么、还缺什么/下一步”入口；
- 是否存在 raw JSON/JSONL 或 enum-first 的机器倾倒；
- 是否把 `page-001`、分页或 `browser` 当成主 IA；
- 是否有摘要、边界和继续阅读链接；
- 是否有 machine ID、M/E、claim ceiling、source hash 与 machine-record hash；
- 每个当前 canonical 目标、迁移 manifest、函数资产和非函数资产路径是否可达且无断链；
- 唯一总架构图是否是透明、关系驱动的单一 SVG，并且没有退役 PNG/旧双图入口；SVG href 仅作为 source link metadata，不把客户端渲染能力写成首页承诺。

这些检查只判断结构、完整性、可达性和是否明显把机器字段直接倒给读者；它们**不判断文学质量、事实真伪、证明是否成立、现实因果、外部新颖性或某个作者是否“写得好”**。这部分仍需人类审阅、来源核查和各自的 M/E、K13、9 轴与 claim ceiling。

## 例外与失败处理

如果某对象没有足够来源、无法安全翻译、包含隐私/版权限制、处于撤回或隔离状态，Human Surface 必须明确说出缺口，并退回机器记录、来源或开放问题；不得用顺滑的文章语气掩盖不确定性。失败、混合价值、负结果和未完成义务保持可见，不得为了让页面好看而升级结论。
