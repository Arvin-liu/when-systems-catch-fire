# S1 规范性审核 - 封闭边界协议 (Closed-Boundary Protocol)

## 1. 原定义

系统在封闭或强边界内演化，外部输入/退出/迁移受限。

## 2. 主要问题

- '封闭'程度未分级，易被用作永久封锁的借口（歧义/适用边界）。
- 可退化为排斥异己、信息垄断、资源囤积（滥用风险）。
- 与 S2 互补但缺少清晰选择条件，易误用为默认（与其他协议重叠）。
- 原定义无'必须有退出权'的硬约束（缺少停止条件）。
- 未说明封闭的正当用途清单（歧义）。

## 3. 生命共同体价值投影

价值：隔离风险、保护脆弱系统、守护隐私、孵化新结构、防止污染或入侵，是有价值的情境工具。条件：仅当目标正当（隔离风险/保护脆弱/隐私/孵化/防污染）且设有时限与退出权时才有价值。伤害：当变成永久封锁、排斥异己、信息垄断、资源囤积或无退出权时，会伤害共同体。不可缺少的约束：正当用途限定、必须有退出权、不得信息垄断、设有时限与复核。

## 4. 推荐修订定义

在限定、可复核、保留退出权的前提下，以封闭或强边界隔离风险、保护脆弱系统、守护隐私、孵化新结构或防止污染与入侵；不得退化为永久封锁、排斥异己、信息垄断、资源囤积或无退出权。

## 5. 硬约束

- 仅用于隔离风险/保护脆弱/隐私/孵化/防污染入侵等正当用途
- 必须保留成员退出权
- 禁止信息垄断与资源囤积
- 边界须设时限并可复核、可解除
- 不得用于排斥异己或固化特权
- 封闭不得造成对外部共同体的不可逆污染

## 6. 停止条件

- 封闭退化为永久封锁且无解除机制
- 封闭被用于排斥异己或信息垄断
- 成员丧失真实退出权
- 封闭造成外部不可逆污染或入侵风险外溢

## 7. 事实 pending

- '脆弱系统'与'必要封闭'的判定标准待案例验证
- 退出权在封闭结构中的可操作保障待建模
- 封闭/开放的成本收益跨域实证待补充
