# V2 规范性审核 - 效率性协议 (Efficiency Protocol)

> 外部治理记录 · IGNITION-20260709-043
> 依据：《生命共同体价值宪章》（docs/governance/life-community-value-charter.md）

> 审核日期：2026-07-11

## 1. 原定义

选择产出/投入效率最大（单位资源产出最高）的行动。

## 2. 主要问题

- 未定义成本的边界，默认只算直接投入，容易把生命、生态、代际与主体性代价排除在外（歧义）。
- 适用边界不清：把效率当成无条件的好，未区分局部效率与共同体净收益（适用边界）。
- 可被用来把伤害转嫁给弱势成员或外部系统，以局部提速冒充整体增益（滥用风险）。
- 与 V1/V4 重叠：效率优化常与延续、可持续目标混同，缺少优先级约定（与其他协议重叠）。
- 缺少硬停止条件：何时因外部化成本而必须放弃效率提升，原定义未给（缺少停止条件）。

## 3. 生命共同体价值投影

价值：在资源有限的生命共同体中，减少浪费、释放注意力与未来选择空间，是有价值的工具性优化。条件：仅当它服务于共同体认可的目标，且不把成本外部化时才有价值。伤害：当它以效率为由压缩退出权、牺牲主体尊严、转嫁生态或代际代价时，会伤害共同体。不可缺少的约束：全成本口径、可逆优先、不得压缩退出权与主体尊严、以 V4 为硬边界。

## 4. 推荐修订定义

在不外部化生命、生态、代际和主体性成本的前提下，以较少资源实现共同体认可目标；效率提升必须保留纠错、退出与恢复能力，且净收益在多时间尺度上为正。

## 5. 硬约束

- 禁止把伤害转嫁给弱势成员或外部系统
- 全成本口径：生态、代际、主体性成本计入
- 禁止以效率为由压缩退出权与主体尊严
- 短期速度不得替代长期净收益
- V4（可持续/再生）为硬边界，冲突时效率让位
- 效率提升必须可停止、可逆转

## 6. 停止条件

- 效率方案显著外部化不可逆生命/生态代价
- 效率提升以牺牲主体尊严或退出权为代价
- 局部效率导致更大共同体净损失
- 效率优化不可逆且丧失纠错空间

## 7. 事实 pending

- 全成本效率度量的跨域可操作指标（经济学/生态/伦理）仍需外部验证
- 效率与 V4 再生能力冲突时的量化权衡函数待实证
- 压缩退出权的阈值与可测信号待案例验证
