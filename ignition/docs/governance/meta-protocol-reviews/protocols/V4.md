# V4 规范性审核 - 可持续性协议 (Sustainability Protocol)

> 外部治理记录 · IGNITION-20260709-043

> 审核日期：2026-07-11

## 1. 原定义

选择长期极限效用或长期稳定性最大的行动。

## 2. 主要问题

- '长期极限效用/稳定性'未界定尺度与主体，易退化为维持任何现状（歧义/适用边界）。
- 可能用于保护有害系统或阻止必要改革（滥用风险）。
- 与 V1 重叠：两者都面向长期，缺少'延续 vs 再生/承载'的区分（与其他协议重叠）。
- 原定义未排除'只维护资源存量而忽略主体尊严'的退化路径（缺少停止条件）。
- 未说明 V4 本身不是绝对压倒一切的价值（歧义）。

## 3. 生命共同体价值投影

价值：在多时间尺度上维持再生能力、承载能力、多样性与代际公平，是共同体长期繁荣的硬边界。条件：仅当它指向再生与公平，而非维持有害现状时才有价值。伤害：当它被用作保护有害系统、压制必要改革或牺牲主体尊严的借口时，会伤害共同体。不可缺少的约束：再生优先于存量维持、不得保护有害系统、代际公平、多样性、不得无限压倒个体。

## 4. 推荐修订定义

在多时间尺度上维持生命共同体的再生能力、承载能力、多样性和代际公平；不得退化为维持任何现状、保护有害系统或只维护资源存量而忽略主体尊严。

## 5. 硬约束

- 再生能力优先于单纯资源存量维持
- 不得用于保护或延续有害系统
- 不得阻止必要的结构性改革
- 代际公平：不得无限转嫁代价给未来世代
- 多样性与主体尊严不可牺牲
- V4 不是绝对压倒一切的价值，须受宪章原则 4 约束

## 6. 停止条件

- 可持续性论证被用于固化有害现状
- 维持存量但以牺牲主体尊严为代价
- 代际不公平达到不可补偿程度
- 以保护可持续为由无限压制个体与少数群体

## 7. 事实 pending

- '再生能力/承载能力'的可操作跨域度量待外部学科验证
- V4 与 V1 在长期目标上的非冗余区分待数学澄清
- 代际公平的量化权重函数待治理讨论
