# S2 规范性审核 - 开放边界协议 (Open-Boundary Protocol)

> 外部治理记录 · IGNITION-20260709-043

> 审核日期：2026-07-11

## 1. 原定义

系统允许外部输入、退出、迁移或扩展，边界可渗透。

## 2. 主要问题

- '可渗透'无上限，易变成无限开放导致病原/污染/风险无控扩散（歧义/适用边界）。
- 可退化为隐私消失、生态承载力被突破、强者借开放掠夺（滥用风险）。
- 与 S1 互补但缺少清晰选择条件（与其他协议重叠）。
- 原定义未设承载力与风险上限（缺少停止条件）。
- 未说明开放的正当用途清单（歧义）。

## 3. 生命共同体价值投影

价值：交流、迁移、知识传播、资源互助与系统适应，是共同体活力与适应的关键。条件：仅当在承载力与风险可控范围内，且保护隐私与弱势成员时才有价值。伤害：当无限开放导致污染扩散、隐私消失、承载突破或强者掠夺时，会伤害共同体。不可缺少的约束：承载力上限、风险可控、隐私保护、防止掠夺、可逆调节。

## 4. 推荐修订定义

在承载力与风险可控范围内，允许外部输入、退出、迁移或扩展以促进交流、迁移、知识传播、资源互助与系统适应；不得退化为无限开放、污染无控扩散、隐私消失、承载突破或强者掠夺。

## 5. 硬约束

- 开放须在生态/社会承载力上限内
- 病原、污染与风险须受控，不得无限制扩散
- 必须保护隐私
- 防止强者借开放实施掠夺
- 开放程度可随风险反馈可逆调节
- 弱势成员须有对等参与与保护机制

## 6. 停止条件

- 开放导致不可逆污染或病原扩散
- 生态/社会承载力被突破
- 开放造成隐私系统性消失
- 开放被强者用于掠夺弱势成员

## 7. 事实 pending

- '承载力上限'的可操作度量待跨域验证
- 开放—封闭的最优切换条件待建模与案例验证
- 防掠夺机制的有效性待实证
