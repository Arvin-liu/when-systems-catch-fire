# 元协议生成层（Meta-Protocol Generation Layer）

本目录是点火项目「元协议生成框架」的文档层，对应 `data/meta-protocols/` 数据层、`templates/` 模板层。

## 定位
- Ψ₀ 元判定框架：负责判定（J⁺/J⁻）、同构识别（I_iso）、收敛审核（L_meta）。
- 12 元协议：是 `P_meta` 向下展开的理论生成层，构成价值（V）/结构（S）/演化（E）三轴基础坐标。
- 64 组合矩阵：V×S×E = 4×4×4，是理论生成空间，不是经验穷尽。
- 两张表：统一函数总表 / 统一案例总表的已审核资产库。

- 元协议不是普通函数，不计入统一函数总表 D/MF/A/T 编号。
- 64 组合不是经验穷尽，须区分现实案例与推论形态。
- 22 本书案例为候选（candidate_only），未分配 C 编号，未进入正式案例表。
