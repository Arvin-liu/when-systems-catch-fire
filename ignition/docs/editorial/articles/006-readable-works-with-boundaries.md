# 把结果写成可读作品，而不越过来源、证据与许可边界

一个能读的东西，很容易被人当成一件已被认定的东西。研究项目最危险的滑动就在这里：当我们把零散的结果、审计、碰撞报告组织成一篇读起来顺畅的文章，读者（和我们自己）会本能地以为，那些被组织过的内容已经被证明、已经被收口、已经构成了"当前知识"。这篇文章不生产任何结论，只想把这道缝——"可读"和"可声称"之间的缝——留在光下，并说明这个仓库用了哪些纪律，让前者不悄悄滑成后者。

## 双来源池：先把"别人的"和"我们的"分开

项目有一套写作素材池，核心动作极其朴素却极其关键：它把素材分成两类——来自项目之外的外部输入，与由点火自身增量产出的内容。外部输入不是我们的，不能原样重发；点火增量则必须随身带着它的来历：canonical 路径与编号、生成它的任务、版本、主张上限、留下的不可容纳残余，以及指向原始来源的回链。

这套纪律里最容易被误读的一句是"复用分析、模型投影或反馈返回项，不构成独立复证"。意思是：一个结论被另一处引用、被某个模型投影过、被某次反馈返回过，都不等于它被重新验证过。素材池只是一个写作方法层（停在它该停的层级），它不会被写成新的理论层、不会被说成脑科学、不会被当成形式同构，更不会被当成一纸真理许可。

## 非重发原则：许可边界先于文采

外部输入不能重发，这条原则适用于一切从项目之外获得的材料，没有例外清单。它先于任何"这段写得太好了不引可惜"的冲动。一个可读作品能不能成立，第一步不是它是否优美，而是它有没有越过来源与许可的边界。这条线划在写作之前，而不是在发表之后补救。

## 1 分钟、5 分钟、完整：让不同读者各取所需

仓库为同一批资产准备了分层的阅读入口：一分钟的表面、五分钟的概览、完整的溯源。这不是把同一份东西复制三遍，而是承认不同读者要的不是同一个东西——有人只需要知道"现在有什么结论"，有人要追到"这个结论从哪条证据链来"。

关键在于：那一分钟的表面，从来不是权威本身。它是入口，不是裁决。把入口当成权威，是项目反复警示的误读之一。

## 五类职责：把"可读"拆成不互相冒充的角色

点火把写作成果收口为五类职责：人类总索引、机器注册表、正式作品、案例来源链，以及点火分析。它们各司其职，也互相设防。交接纪律里写得很硬的三条"不得"，正是对"可读滑向可声称"的护栏：

- 不得把 README 上"最近三项"的投影当成完整权威——那只是投影，不是全量真相；
- 不得公开受限的原始材料——可读不等于可以无差别披露；
- 不得从一篇被接受的作品，推出这套写作方法普遍有效——一篇写得好，不证明方法处处成立。

这五类职责的存在，本身就是对"一篇文章能做什么"的清醒：正式作品是其中一种角色，它不取代机器注册表，也不冒充案例来源链。

## 被隔离的 1.4.0：可见，不等于已接受

最能体现这套纪律"免疫反应"的，是一个被隔离的方法：持续阶段快照发布。它的状态不是当前、不是已接受，而是被 quarantine 的未决候选。规则写得很直白——快照出现在首页、或某个阶段快照对外可见，绝不意味着它已被接受、已成为当前、已被激活，或某个候选载荷已被合并。

这句话值得单独拎出来，因为它戳破了最日常的自我欺骗：我们太容易把"我看到了"当成"这已经定下来了"。隔离项之所以被隔离，正是为了提醒——可见性是一种呈现状态，不是一种认知许可。

## 我们写，但写有边界

回到开头的缝。这个仓库的诚实，不在于它产出了多少读起来顺畅的东西，而在于它拒绝让"读得顺畅"冒充"已被认定"。双来源池把来历钉死，非重发原则把许可前置，阅读分层把入口和权威分开，五类职责把角色互相设防，而被隔离的 1.4.0 则守着最后一道门：你看到的，未必是已接受的。

所以这篇文章不打算给自己收个漂亮的尾。它想留下的，恰恰是那个没有被填满的克制：这里组织过的内容，是"被整理过的"，不是"被我们全数证成的"。能读，和有边界地读，中间隔着整条编辑纪律。
