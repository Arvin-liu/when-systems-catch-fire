# 描述不等于证明：跨尺度、概率与关系网络能说什么，不能说什么

点火有一整套漂亮的表示机器：多尺度因果织体（MCF）、概率系统动力学（PSD）、自适应关系网络（ARN），以及把它们投影出来的 Ignition Atlas。它们能把一个系统画得清清楚楚——跨尺度的因果、随时间的概率演化、节点之间的关系结构。

于是出现一种很自然的滑动：当我们能把一个系统**描述**得很完整，就以为我们**解释**了它，甚至**证明**了它为什么会这样。这篇文章不想解决任何问题，只想把这道缝——"能描述"和"能证明"之间的缝——清清楚楚地留在光下。

## 表示能力不是因果证明

MCF、PSD、ARN 在资产状态里大多是 `CANDIDATE_OR_PENDING_SOURCE` 或 `SOURCE_INDEXED_WITHOUT_LIFECYCLE_INFERENCE`——它们是**候选的派生表示**，不是被证明的现实机制。项目反复声明：表示能力**不升级**为现实因果证明。

机制裁决平面（Mechanism Adjudication Plane，Q12 操作叠加层）的存在，正是为了把"这里有个机制草图"和"这个机制已被裁决"分开。网络理论源地图（121Q23）也只"引导表示与验证器边界"，不提供结论。

## Atlas 是派生的、版本化的，不是第二真相

Ignition Atlas 的地图被显式定义为**版本化的派生投影**：它不是永久的总图，也不是第二份 canonical 真相源（`NFC-1E10227F1B51E4D0`）。这意味着读者看到的任何一张系统图，都是从构件 registry、类型化 topology 与同步表面**计算出来**的某一帧，而不是被供奉的真理。

这一点和迭代方法的版本纪律一致：方法 1.3.0 与系统图 0.2.0/0.3.0 已为 Historical，0.1.0 更早；实现完成不能替代仓库同步完成，本地验证也不能声称任何未登记的实时外部状态已验证。

## 规范性协议是边界声明，不是经验定律

簇里还有两类材料值得单列：可持续性协议（V4）与网络协议（S4）的规范性审核。它们不是被发现的物理或社会规律，而是**价值—条件—伤害**的三段式边界：

- 可持续性（V4）：价值在于多时间尺度维持再生、承载、多样与代际公平；条件是与再生和公平一致；伤害是当它被用来保护有害系统、压制必要改革或牺牲主体尊严。
- 网络（S4）：价值在于分布式协作、多中心治理、冗余、知识共享与局部失效隔离；条件是责任可追溯、无隐形中心垄断、局部失效可隔离；伤害是当责任消失、隐形中心垄断、信息传染或网络效应锁定时。

把它们写成"协议"而不是"定律"，本身就是对"描述"与"证明"之别的尊重：它们描述的是我们**选择**如何组织，而不是宇宙**必然**如何运转。

## 开放问题之所以开放，是因为它不该被填

回到开头的缝。这个项目的诚实，不在于它有多少表示工具，而在于它拒绝用表示去冒充证明。跨尺度、概率、关系网络能让我们"看见"一个系统，但"看见"从来不是"证成"。

所以这篇文章不打算收尾成一个结论。它想留下的，恰恰是那个未被填满的开放区：哪些系统性质可以被派生表示捕获，哪些必须回到形式证明或外部实证——这道界限，本身就是当前最该被守住的开放问题。
