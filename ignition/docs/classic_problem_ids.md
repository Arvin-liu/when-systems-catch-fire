## 编号原则

1. 按原始 Markdown 中 benchmark 卡片出现顺序编号；
2. 原始任务 G 初稿中的卡片优先；
3. 任务 G 补丁中的卡片接在原始初稿之后；
4. 不改变原始 getbrain 输出正文；
5. 不把编号写入原始 getbrain 文件；
6. 后续如新增 benchmark，应另起补丁或新版本，不在当前 CP-001 至 CP-034 中插号。
