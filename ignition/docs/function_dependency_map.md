## 七个函数层级

| 层级 | 名称 | 含义 |
|---|---|---|
| L0 | 元函数 | Ψ₀ 的六大组件，框架最顶层入口 |
| L1 | 统一函数 | 跨域通用核心函数，收敛至元层面 |
| L2 | 收敛函数 | 在特定领域收敛后形成的稳定函数 |
| L3 | 执行函数 | 具体场景下的可执行函数 |
| L4 | 判定函数 | 用于判定、验证、分类的函数 |
| L5 | 案例函数 | 从具体案例中提取的函数标签 |
| L6 | 辅助函数 | 支撑性、临时性、待归档的函数 |

## 顶层依赖结构

```text
Ψ₀ 元函数 (L0)
├── C(x,y) 因果结构判定
├── M(B_n) 自举收敛判定
├── I_iso(A,B) 同构判定
├── L_meta 元层面收敛
├── G_δ 哥德尔不完备性判定
└── P_meta 元协议投影
```
