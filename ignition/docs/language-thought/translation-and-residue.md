# 翻译、框架差异与未映射残余

Version: `0.1.0`

## 不设“真正意义”字段

跨语言比较需要一个共同参照，却不能假装存在完全中性的语言外中介。本项目使用 `normalized_meaning_candidate`：它是一条有 provenance、有版本、可被反驳的比较候选。新证据或母语审校者可以修改它，旧版本仍保留。

一条正式记录的最小形状是：

```text
source_form
  + source_language_profile
  + normalized_meaning_candidate
  + target_form
  + target_language_profile
  + framing_deltas
  + unmapped_residue
  + claim_ceiling
  + provenance/version
```

`source_form` 与 `target_form` 都包含文本、语言标签、形式身份（原文／翻译／转述／机器生成）及框架标注。框架标注使用十二维基底，不要求每个维度都有差异，但要求每个观察到的差异都有处置。

## `framing_deltas` 怎样写

每项差异至少记录：

- `dimension_id`：变化落在哪个维度；
- `source_value` / `target_value`：两端的结构化描述；
- `delta_type`：保留、显化、弱化、增强、重排、分句、合句或修正；
- `epistemic_relevance`：是否可能改变命题、对象、论证、机制或证据权限；
- `disposition`：接受、修正、保留为残余或交人工裁定；
- `justification`：为何这个变化不会静默改义，或为何必须停止。

生产记录中，只要 `source_value != target_value`，就必须存在同维度差异项。认识相关变化不能标为 `silent`、`ignored` 或没有理由的 `unresolved`。

## `unmapped_residue` 不是失败垃圾桶

残余是目标形式尚未完整承载的东西，例如：

- 来源中的证据语气在目标语言没有一对一形态对应；
- 话题链允许多个指称恢复，而当前成品只选择了一个；
- 敬语同时携带礼貌、距离和制度角色，目标词只能保留其中一部分；
- 文学句法的声音压力无法被规范化释义完全描述；
- 受版权限制的原文不能进入公开仓库，只能保留哈希、边界和有界摘要。

每项残余标记是否影响 claim、当前处置和重新开放条件。影响认识权限且未裁定的残余会让生产记录停在人工复核状态；不影响事实主张的韵律损失也要保留，但可以在编辑审查后接受。

## 回译为什么不够

一句话可能回译得词面相似，却已经发生以下变化：

- 来源的无施事意外被目标语言补成某人负责；
- 进行中的动作变成达成终点的动作；
- `据说／看来` 在往返中消失；
- 中文话题链被补成多个固定主语，再回译成同样的名词；
- 译者增加 `therefore`，回译又得到 `因此`，制造出来源没有的因果。

因此 L5 要同时看来源—候选、来源—目标的逐维差异、对照释义、反向检查和人工审校。回译只是能暴露部分问题的对抗工具。

## 三种可接受结果

1. **保真实现：** 形式不同，认识相关框架不变；差异只属于语言实现，并有说明。
2. **显式修正：** 旧目标确实改变了意思，新目标修复并记录前后版本。
3. **诚实残余：** 当前没有足够依据选定唯一实现；保留候选和残余，不制造确定性。

“读起来顺”不自动属于第一类；“逐字对应”也不自动属于保真。
