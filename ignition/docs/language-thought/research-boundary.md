# 研究边界：语言会牵引组织，不会囚禁思想

Status: `CURRENT_BOUNDED_RESEARCH_SYNTHESIS`

## 可接受的主张

本项目采用“thinking for speaking / 为表达而组织思想”的有边界立场：语言会在表达、记忆和任务执行中牵引人去选择行为者、路径、终点、信息来源和篇章顺序；这种牵引可能在语言编码时最强，也可能延续到随后的记忆或判断。效应依任务、时间、语言经验和语境而变，可以被启动、改写或抵消。

项目不采用以下强主张：语言决定可思考的内容；不同语言具有不同真值逻辑；一个语言共同体共享不可改变的民族心智；语言表达差异必然对应非语言认知差异。

## 正、空与混合结果必须并存

| 研究 | 结果类型 | 本项目只采用的范围 |
|---|---|---|
| Fausey 等（2010），英语／日语意外事件 | 正效应且有边界 | 英语描述意外时更常显露行为者，英语使用者随后对意外行为者记忆更好；短时语言启动也改变记忆。样本、任务和文化共变限制仍在，不能推出一般责任观。DOI: [10.3389/fpsyg.2010.00162](https://doi.org/10.3389/fpsyg.2010.00162)。 |
| Gennari 等（2002），英语／西班牙语运动事件 | 混合／条件效应 | 非语言编码后的识别与相似性没有稳定语言组差异；语言编码后的相似判断出现差异。语言影响可在编码任务中出现，不等于持续改写知觉。DOI: [10.1016/S0010-0277(01)00166-4](https://doi.org/10.1016/S0010-0277(01)00166-4)。 |
| Papafragou 等（2008），英语／希腊语事件观看 | 混合／时序效应 | 准备说话时出现语言特定注意模式；普通非语言观看的即时知觉没有同样效应，部分差异在后续记忆阶段出现。DOI: [10.1016/j.cognition.2008.02.007](https://doi.org/10.1016/j.cognition.2008.02.007)。 |
| Papafragou、Massey、Gleitman（2002），运动事件 | 空效应 | 两组使用不同语言描述方式，却在给定任务的非语言记忆和分类中相近。DOI: [10.1016/S0010-0277(02)00046-X](https://doi.org/10.1016/S0010-0277(02)00046-X)。 |
| Ji 与 Papafragou（2026），英语／普通话事件有界性 | 语言差异 + 非语言空效应 | 两组在语言的终点／完成表达上不同，但非语言终点可能性与时间知觉任务相近。DOI: [10.1016/j.cognition.2026.106443](https://doi.org/10.1016/j.cognition.2026.106443)。 |
| Fedorenko 与 Varley（2016），语言与思想神经证据综述 | 分离证据 | 严重语言损伤与多种非语言推理能力可以分离；语言系统不是全部思想的唯一载体。DOI: [10.1111/nyas.13046](https://doi.org/10.1111/nyas.13046)。 |

Slobin 提出的 “thinking for speaking” 是本项目的工作框架，不是封闭定律：见 *Rethinking Linguistic Relativity*（1996）中的 “From ‘thought and language’ to ‘thinking for speaking’”。

## 描述语言时的四条约束

1. **把义务、默认、选项和标记形式分开。** “常见”不等于“语法必须”，“可以省略”不等于“总会省略”。
2. **保存语言内部差异。** 方言、语体、年龄、专业、文类、双语经验与作者选择都可能改变配置。
3. **把语言差异与非语言判断分开测量。** 描述不同不自动等于知觉、记忆或推理不同。
4. **不把类型学标签本质化。** SVO、SOV、topic-prominent、evidential 等只指明特定结构范围，不能概括文明或使用者。

## 证据怎样进入实现

研究只能支持“在哪些维度需要检查”，不能直接判定一条历史因果或一篇文章的意义。机器配置中的每条 tendency 都要回链证据 ID，并附 `claim_ceiling`。研究有冲突时，配置把该维度标为 `mixed` 或 `open`，而不是替争议制造结论。

当前证据注册表位于 [`evidence-registry.jsonl`](../../data/language-thought/evidence-registry.jsonl)。其中区分实验研究、参考语法、类型学资料和文学／语体校准；搜索结果摘要没有作为已咨询证据登记。
