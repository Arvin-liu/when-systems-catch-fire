# 语言—思维逻辑平面：阅读入口

这里记录语言怎样参与点火的来源保存、命题抽取、对象建模、论证、机制、验证和公共表达。它是一张横穿 L0—L6 的控制平面，不是 L7，也不是“中文写顺一点”的附属手册。

## 先读什么

1. [架构裁定](../architecture/language-thought-logic-plane.md)：为什么采用正交平面，为什么不增加 L7。
2. [研究边界](./research-boundary.md)：正效应、空效应和混合结果怎样共同限定主张。
3. [有限维度基底](./dimensional-basis.md)：十二个可复用维度及其反例、风险和验证对象。
4. [L0—L6 跨层合同](./cross-layer-contract.md)：每层必须保留什么，何时失败关闭。
5. [翻译与残余](./translation-and-residue.md)：来源、候选意义、目标成品、框架差异和未映射残余怎样并存。
6. [验证与审计指南](./validation-and-audit.md)：机器门、人工门、项目审计及指标的准确边界。
