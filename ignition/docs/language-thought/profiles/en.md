# 当代标准书面英语配置

Profile ID: `en-contemporary-written-r1`

Status: `FULL_PROFILE_WITH_BOUNDED_SCOPE`

## 范围

本配置服务当代标准书面英语的点火输入、研究摘要和目标输出。它不代表所有英语地区、方言、社会群体、学科和文学传统。参考骨架包括 Huddleston & Pullum, *The Cambridge Grammar of the English Language*（2002）以及有范围说明的类型学资料。

## 三层校准

1. **描述语法与类型学：** 有限小句通常要求显式主语，时制／体貌与从属结构形态较显著；命令、口语、省略、标题和文学偏离构成重要反例。
2. **普通语篇：** 连接与指称往往比中文书面散文更显式，但信息结构、语域和体裁会改变选择。
3. **文学校准：** 英语文学可以并置、断裂、省略、长周期推进或强名词化；配置不把标准说明文偏好冒充文学语法。

## 十二维配置

| 维度 | 当前配置 | 转换风险 |
|---|---|---|
| 话题／主语／焦点 | 有限陈述句强烈偏向显式语法主语；被动、cleft、fronting 等可调焦点。 | 从中文话题链转入时，为每句补同一主语并不总是保真；形式主语也不应变成现实行为者。 |
| 行为者／责任 | 主动／被动、非施事结构和词汇选择调节施事显露；意外描述可受任务影响。 | 把无施事中文变化句补成 agentive event，或把英文被动的未知施事擅自恢复。 |
| 时制／体貌／终点 | 有形态时制以及 progressive/perfect 等组合；词汇体和上下文仍重要。 | 英语时制选择被误写成客观终点，或中文 `了` 被一律译为 simple past。 |
| 证据／情态 | 主要用 modal、adverb、reporting verb 和来源短语；通常无强制证据形态。 | 将 Turkish 间接证据形式压成无来源直陈；`may/must/reportedly` 在摘要中丢失。 |
| 省略／指称链 | 标准有限句通常不允许中文式广泛零主语，但对话、协调、省略和非限定结构很多。 | 强补主语产生虚假承担者；反向省略让代词指向不清。 |
| 分句连接 | 从属标记和显式连接资源丰富；文学并置同样合法。 | 因为目标句需要完整结构而补出来源没有的因果／让步。 |
| 事件词汇化 | 运动事件常可在动词突出方式、卫星成分表达路径，但并非每句如此。 | 转入中文时拆错方式／路径／结果；把类型学倾向当词对词规则。 |
| 信息顺序 | 主语位置、there-construction、passive、cleft 和 intonation 共同组织 given/new。 | 把中文先事件后反思压成主语中心嵌套句，或把英语背景从句误当次要事实。 |
| 社会视角／立场 | 礼貌、称谓、modal、hedge 与 register 表达关系，语法化敬语有限。 | 将日语敬语只译成普通动词而删除关系残余，或凭礼貌词推断真实立场。 |
| 分类／词汇粒度 | 词汇、派生、复合和术语系统调节粒度；冠词和数形态要求作额外选择。 | 中文无冠词形式被强行解释为特指／泛指而未记录候选。 |
| 节奏／标点／呼吸 | 从属周期、并列、dash、semicolon 和段落均可控制节奏；长句不是翻译腔同义词。 | 为短而短切断论证，或把多个抽象从句无层级嵌套。 |
| 语体／文学标记 | 学术名词化、新闻压缩、口语省略和文学偏离都有合法位置。 | 把名词化一概视为坏写作，或用标准说明文抹平作者声音。 |

## 从中文进入英语的最低检查

- 对每个新增主语问：它是语法支架、可恢复参与者，还是被译者创造的行为者？
- 对每个 `because/therefore/although` 问：来源有明示关系、强语境关系，还是仅仅并置？
- 对 article、number、tense 和 endpoint 的新增选择保存候选与残余。
- 话题链跨句时先建立指称账本，再决定重复名词、代词、被动或重组段落。
- 名词化可以保留专业稳定性，但不能让事件主体和责任消失。

## 内部差异与未决项

不同英语地区、族群、专业和媒介在主语省略、集体名词、时制、标点、礼貌和信息结构上都有差异。实验中的英语组效应不能被写成所有英语使用者的固定注意方式。复杂文学句法、方言叙事和跨语码写作保持人工／专家审查。
