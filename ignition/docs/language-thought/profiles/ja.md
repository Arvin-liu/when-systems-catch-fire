## 为什么选择日语

日语在当前维度覆盖中同时压力测试话题标记、论元省略、SOV 基本语序、句末情态／立场和系统性敬语。这些组合能暴露中文—英文双配置容易忽视的社会视角与指称恢复问题。选择依据是维度覆盖，不是把日语当成日本社会或“高语境文化”的本质代表。

结构骨架参考 Shibatani, *The Languages of Japan*（1990）、Kuno, *The Structure of the Japanese Language*（1973）及有边界的 WALS 条目；社会关系／敬语采用语用和社会语言学描述。当前配置没有经过本轮原生日语成品出版，因此保持 preliminary。

## 十二维试点

| 维度 | 配置摘要 | 未决边界 |
|---|---|---|
| 话题／主语／焦点 | `は` 等话题资源与格标记共同组织信息；话题不等同语法主语。 | 助词在对比、旧信息和篇章中的解释依上下文。 |
| 行为者／责任 | 主动、被动、使役及省略共同调节施事；意外事件实验显示任务相关差异。 | 不从实验外推社会责任性格。 |
| 时制／体貌／终点 | 过去／非过去、`ている` 等与动词类别、语境互动。 | `ている` 不可统一映射英语 progressive 或中文 `在`。 |
| 证据／情态 | 句末形式、传闻／样态表达与引用结构可标记来源和立场。 | 类型学对“语法化证据性”的分析口径不一，保留分析争议。 |
| 省略／指称链 | 语境可恢复论元广泛省略，零照应高度依赖视角和话题连续。 | 自动恢复风险高；目标中文／英文不能任意补人称。 |
| 分句连接 | 连用、接续形式、名词化与并置组织关系，句末常承担关键裁定。 | 截断句尾可能丢失情态和礼貌。 |
| 事件词汇化 | 方式、路径、结果通过动词、复合和附加结构组织。 | 当前证据不足以给出一般认知效应。 |
| 信息顺序 | SOV 为窄范围基本语序；话题优先、焦点与 scrambling 使实际顺序有弹性。 | 不能把所有句子按 SOV 机械重排。 |
| 社会视角／立场 | 敬语、受益／授受表达、内外关系和视点选择可进入形式。 | 使用受身份、场景、组织规范、讽刺和个体选择影响。 |
| 分类／词汇粒度 | 计数词、敬语词汇、拟态词及借词提供不同粒度。 | 词汇丰富度不等于更强认知能力。 |
| 节奏／标点／呼吸 | 句末积累、助词链与书写标点组织阅读；文体差异大。 | 需要日语母语朗读审校。 |
| 语体／文学标记 | 普通体／敬体、书面／口语与文学偏离形成多重配置。 | 不能从单一文学作者生成一般规则。 |

## 主要转换风险

转入英语时最危险的是：为每个省略位置补出同一个人称；在主语位置过早固定话题；把句末的传闻、推测和礼貌压成无标记直陈。转入中文时虽然同样允许省略，也不能因此假定两种语言的零照应完全等价；视角、礼貌和授受关系可能成为残余。

## 试点裁定

本配置完成十二维覆盖与来源复核，可用于设计对抗样例和发现风险；它不能独立批准日语公共成品。任何日语正式出版需要母语审校、具体语体证据和该资产的转换账本。
