# 现代普通话书面中文配置

Profile ID: `zh-hans-modern-written-r1`

Status: `FULL_PROFILE_WITH_BOUNDED_SCOPE`

## 范围

本配置服务点火当前现代普通话书面中文输入与公共输出，兼顾可朗读的当代散文。它不代表所有汉语方言、文言传统、历史时期、地区用法或每位中文使用者。“话题突出”“可省略”等只描述可用资源和常见倾向，不是民族心智。

## 三层校准

1. **描述语法与类型学：** 以 Li & Thompson, *Mandarin Chinese: A Functional Reference Grammar*（1981）等参考语法和 WALS 的有界条目为结构入口；WALS 将普通话给定窄范围基本语序记为 SVO，但这不概括全部信息结构。
2. **普通语篇：** 关注话题链、零照应、体标记、语境恢复、分句并置及体裁差异；普通使用不是文学名家的平均风格。
3. **文学校准：** 使用多位作者的机制级观察压力测试自然度和有意偏离，见[中文文学校准](../chinese-literary-calibration.md)。不复制语料，不克隆作者。

## 十二维配置

| 维度 | 当前配置 | 转换风险 |
|---|---|---|
| 话题／主语／焦点 | 话题—说明结构和话题链是高生产力资源；主谓结构同样普通。话题可与语法主语不重合。 | 从英语转入时逐句补固定主语，会破坏话题延续；转出时擅自补主体会增添命题承担者。 |
| 行为者／责任 | 动词、处置式、被动式、无施事变化句和语境省略共同调节施事显露。 | `杯子碎了` 不可无证据翻成某人打碎；`被` 也不能被机械删除。 |
| 时制／体貌／终点 | 时间主要由体标记、时间词、词汇和语境组织；`了、着、过、在` 不一一对应英语时制。 | `了` 被机械当过去完成，或过程被翻成已达终点。 |
| 证据／情态 | 多用副词、助动词、引述和来源短语标记；一般不强制每句编码信息来源。 | `据说、看来、恐怕、可能` 消失会抬高确定性。 |
| 省略／指称链 | 语境可恢复时，论元和代词可广泛省略；话题链可跨句延续。 | 机器补入错误指称，或为了“简洁”删掉歧义消解所需名词。 |
| 分句连接 | 并置、语序、节奏和显性连词共同表达关系；因果可明说也可留给语境。 | 为英语完整性发明因果词；反向也不能把无连词误判为无论证。 |
| 事件词汇化 | 方向补语、结果补语、动词复合等可同时组织动作、路径与结果。 | 目标英语只留泛化动词，丢失路径／结果；也可能过度显化方式。 |
| 信息顺序 | 常见从语境／话题进入新断言，时间地点和条件位置有弹性；体裁差异大。 | 把抽象结论压在事件之前，形成“先解释再发生”的潜在翻译腔。 |
| 社会视角／立场 | 称谓、代词、礼貌表达、句末成分和叙述视角可编码关系，但没有单一敬语范式覆盖全部中文。 | 英译回中文时制造不必要尊卑；机构视角遮蔽受影响者。 |
| 分类／词汇粒度 | 量词、复合词、成语、专业术语和语境共同调节类别；无一词对应时可解释。 | 用一个目标词压平多个历史／制度术语，或把量词选择本体化。 |
| 节奏／标点／呼吸 | 分句、顿号、逗号、分号和句号组织呼吸；长短皆可，关键是视角、负荷和推进。 | 机械同长短句、逗号粘连、多层 `的` 与抽象被动会阻塞成句。 |
| 语体／文学标记 | 现代书面语内部有学术、新闻、公共散文、口语化及多种文学传统。 | “自然中文只有一种”；把有意拗峭抹平或把机器拗口误当文学。 |

## 中文目标语言实现门

成品按这个顺序检查：

1. 先确认事件、参与者、证据来源和 claim ceiling 没有变化；
2. 让事情先发生，再决定反思何时进入；
3. 检查话题能否延续、哪些主语可省、哪些指称必须重提；
4. 检查 `了／着／过／在`、时间词和终点是否一致；
5. 删除凭空因果和为“完整”而增加的承担者；
6. 朗读，辨认呼吸、标点、机器平行和抽象名词堆叠；
7. 对反常结构追问：这是表达所需，还是意思尚未真正组织成中文？

规则不能自动回答第 6、7 项。它们需要母语上下文审查和多谱系文学校准。

## 内部差异与未决项

南北方用法、地区词汇、专业语体、网络书写、口语转写、双语经验和作者选择都可能偏离这里的普通书面语配置。中文话题链的自动恢复、文学长句的呼吸和历史语体向现代语体的迁移仍保留为人工判断。配置不把省略等同含混，也不把显式连接等同英语化。
