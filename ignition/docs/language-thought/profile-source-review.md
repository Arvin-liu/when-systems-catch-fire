# 日语与土耳其语配置来源复核

Status: `BOUNDED_PROFILE_SOURCE_REVIEW_COMPLETE`

## 复核问题

本轮不问“哪种语言最有代表性”，只问：中文和英文配置之外，哪两种配置能以足够可靠的参考语法与研究证据暴露未覆盖的结构风险？裁定为日语与土耳其语；没有增加第五种语言，因为当前十二维已获得新的压力覆盖，继续扩张会降低研究深度。

## 日语

主要结构来源为 Masayoshi Shibatani, *The Languages of Japan*（1990）与 Susumu Kuno, *The Structure of the Japanese Language*（1973）。WALS 的基本语序条目只用于窄范围 SOV 参照，不把类型学标签扩大到全部语篇。敬语和社会关系采用语用／社会语言学描述；例如 Jarkey 关于日语社会关系的综合章节，DOI: [10.1093/oso/9780192845924.003.0002](https://doi.org/10.1093/oso/9780192845924.003.0002)。

Fausey 等（2010）的英语／日语意外事件研究只支持任务内的施事描述和记忆差异，不支持“日本人淡化责任”等文化本质结论。日语证据性分类在不同理论中口径不一，因此配置明确留为分析争议。

裁定：十二维风险识别可用；正式日语出版不可由本试点独立批准。

## 土耳其语

主要结构来源为 Aslı Göksel 与 Celia Kerslake, *Turkish: A Comprehensive Grammar*（第 2 版，2025）。语序与信息结构参考 Hoffman 的研究章节，DOI: [10.1093/oso/9780198236870.003.0013](https://doi.org/10.1093/oso/9780198236870.003.0013)。证据性采用 Johanson 的 Turkic evidentiality 综述，DOI: [10.1093/oxfordhb/9780198759515.013.24](https://doi.org/10.1093/oxfordhb/9780198759515.013.24)，并参考土耳其语语法证据性加工研究，DOI: [10.3389/fpsyg.2015.01387](https://doi.org/10.3389/fpsyg.2015.01387)。

WALS 将土耳其语的 evidential distinction 编码在 tense system 类型中，只作为跨语言定位。`-miş` 的具体作用不能被压成单一“传闻”，更不能据此判断信息真假。

裁定：D03／D04／D08／D10 获得重要新增覆盖；正式土耳其语出版仍需母语与形态专家复核。

## 未采用第五种语言

本轮没有为大洲、文明或数量平衡增加第五种语言。增加语言必须满足两个条件：确有当前基底未覆盖的维度缺口；能获得足够深的结构、普通语篇和文学校准证据。目前优先完成四配置的实现与项目修复，比扩大清单更诚实。
