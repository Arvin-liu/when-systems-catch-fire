# 一群鹤怎样暴露了潜在英语句架

Status: `TASK_114_CONTEXTUAL_REPAIR_EXPLANATION`

## 修订前

> 它们飞得并不需要先知道自己将被怎样解释。

问题不只是 `飞得` 后面更适合程度／结果补语。这个句子把四件事塞进一个主体中心：鹤飞、鹤无须知道、后来的人解释、鹤成为被解释对象。抽象被动和从句嵌套让每个局部都能分析，整体却没有沿自然中文的信息顺序发生。鹤仿佛先承担了一个关于未来解释的元命题，才获得飞行许可。

因此它同时触发：D02 行为者与责任、D05 指称链、D08 信息顺序、D11 呼吸和 D12 语体。若只把 `飞得` 改成 `飞`，潜在句架仍在。

## 当前修订

> 鹤只是从宫门上空飞过。人们后来怎样解释这一幕，是另一回事。

这里先让事件落地：鹤飞过。第二句再把话题转给后来的人和解释活动。两个事件的时间顺序、参与者和认识权限都更清楚，也不要求鹤承担一个抽象被动命题。

这不是“短句总比长句好”。若上下文需要持续的一口气，长句也完全可能是自然中文；关键在于事件、视角和反思是否按作品真正需要的顺序展开。任务 114 的其他修订同样不按被动词或句长批量替换，而逐段判断是否改义、是否只是自然度问题、是否属于应保留的标记句法。
