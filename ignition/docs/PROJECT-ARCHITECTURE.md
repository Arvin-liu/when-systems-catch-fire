# 项目架构兼容入口

根目录 [ARCHITECTURE.md](../ARCHITECTURE.md) 是现行架构唯一权威；本文仅保留 docs/PROJECT-ARCHITECTURE.md 的稳定路径并提供兼容摘要。冲突时以前者为准。

## 现行定位

点火是一套面向跨领域材料的、证据可追溯、对象类型明确、推理过程可检查、结论等级可审计的形式化机制发现与建模系统。它不是现成的统一数学理论、物理理论、万能证明器，也不是纯文学或纯哲学知识库。

## 七层架构

L0 来源与证据；L1 受控语义命题；L2 形式对象；L3 逻辑论证；L4 数学模型与证明；L5 验证与有效性；L6 解释、应用与出版。L6 只能引用下层成果，不能产生新的数学真实性。

## 数学与逻辑双地基

数学负责对象、结构、函数、关系、模型、度量、运算与可证明命题；逻辑负责前提、量词、推理规则、结论蕴含、反模型和论证有效性。二者及证据、来源、范围状态彼此独立，详见 [FOUNDATION.md](../FOUNDATION.md)。

## 权威、兼容与核心重分类

data/foundation/ 下的对象、命题、论证、来源、证据、映射、证明、验证和迁移注册表承担类型与状态权威；动态计数来自 project-state.json 和 migration-summary.json。

统一函数总表与统一案例总表保留为 legacy source / compatibility view，零删除、零重编号、不得独立生长。Ψ₀ 重新定性为工作流编排器/算法协议；J+ / J- 是内部审议通道；12 元协议默认属于规范、启发或治理协议；64 组合属于设计与生成空间。
