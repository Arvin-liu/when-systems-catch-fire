# Participate

This page describes current participation paths for this repository. It is an interface for real signals, not a claim that the project has external recognition, funding willingness, or production adoption.

## Participation Paths

### Independent Review

Use the independent review issue form when you can point to a specific artifact, claim, mechanism map, validator, report, or release boundary.

A useful review names:

- the artifact and version reviewed;
- the claim or mechanism being examined;
- the evidence used;
- the strongest alternative explanation or failure condition you see;
- the result of any reproducible check.

Review does not need to be favorable. A verified gap enters the project's gap-discovery, structural-correction, and revalidation path.

### Non-Commercial Use Report

Use the non-commercial use report form for personal learning, education, public-benefit review, independent research, compatibility exploration, or other non-commercial use within the current license scope.

A useful report names:

- which version or commit you used;
- what you tried to understand, reproduce, teach, inspect, or adapt;
- what worked;
- what failed or was unclear;
- whether your report depends on private data that should not be published.

Do not include private contact information or payment details.

### Sponsorship Or Commercial Licensing Inquiry

Use the sponsorship or commercial licensing inquiry form only when there is a real resource commitment, concrete commercial evaluation need, or serious licensing question.

Resource support can help cover AI quota, CI, storage, network access, equipment, review, release work, and basic living support. It cannot buy facts, evidence grades, governance rights, merge rights, roadmap control, suppression of criticism, or exemption from validators.

Commercial production use may require a separate commercial license or written reciprocal agreement. Public-benefit and non-commercial use remain low-friction within the license scope.

## Signal Boundaries

The project distinguishes at least three signal types:

- independent review;
- non-commercial use;
- sponsorship or commercial licensing inquiry.

They are not interchangeable. One organization posting many comments is not many independent reviewers. Oral encouragement is not a resource commitment. Stars, views, likes, reposts, and friendly comments do not replace real review, real use, or real funding/legal commitment.

## Existing Contribution Guide

For direct repository contributions, also read [CONTRIBUTING.md](../CONTRIBUTING.md) and the current license files. Contributions that affect code, validators, reports, schemas, or release artifacts must respect the current layered license and contributor authorization boundary.
