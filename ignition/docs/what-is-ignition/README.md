# 何谓点火：历史观点、问题与回应

本栏目收录不同时期、不同参与者对“点火是什么”的解释、质疑、回应、修订与撤回。观点按日期和来源并列保存；本栏目是历史阅读入口，不是真值注册表、Current 定义、价值宪章或能力目录。发言次数、模型一致、赞美、代码状态与 CI 都不会自动提升观点的地位。

## 来路与创作分工

依据 Owner 对早期对话的回溯，2026-07-25 的讨论涉及紫阳地方历史、张伯端（号紫阳真人）与道教南宗内丹。2026-07-26，Owner 将“南派炼丹”的意象转化为点火持续求知、没有终极形态的项目隐喻；ChatGPT 随后拟出四句，Owner 认可并决定保留，且将它定位为独立“项目宣言”。这里记录的是一段人机协作的创作来路，不声称点火是张伯端教义的继承者，也不把私人对话包装成已公开、可独立核验的历史原件。

诗句的 2026-07-27 公布版本为：

> 丹无定形，火有法度；

> 炼无终局，化有来路。

公共仓库 [PR #142](https://github.com/Arvin-liu/when-systems-catch-fire/pull/142) 将它作为独立“项目宣言”合并；[合并后的 README](https://github.com/Arvin-liu/when-systems-catch-fire/blob/26b598d39b1863506b4fa7cc089a5efb1d0f1b24/README.md) 可核对当时的呈现。2026-08-28，[提交 3d4209f](https://github.com/Arvin-liu/when-systems-catch-fire/commit/3d4209f3113f021268bab5988be16637430c572c) 在首页简化时移除了含有诗句的旧引言。展示被移除只证明页面发生过变化，不证明 Owner 否定了它的思想含义。

紫阳县人民政府的[“地名由来”说明](https://www.zyx.gov.cn/Content-1750445.html)将县名来源叙述为与张伯端及当地传说相关，并引《陕西通志》；这是地方政府的地方历史叙述，不代替对古人生平争议的学术考证。道教文化中心资料库的[张伯端条目](https://zh.daoinfo.org/index.php?title=%E5%BC%A0%E4%BC%AF%E7%AB%AF)汇总了其与内丹及后起南宗传统的联系，并列出辞书来源；该条目也不是本栏目对宗教史的独立裁定。炼丹意象的现代转化属于 Owner 在讨论中提出的点火解释，不能反推为南宗本来主张“没有终局”。2026-10-13 GPT-6 评论中对《金刚经》的引用，是后来追加的一层理解，不是诗句的初始来源。价值宪章中的“长瞻一宇同叩月，此心相契共今宵”是另一首诗句，不与此宣言混为一谈。
