# 断言等级说明

点火框架中的结论分为不同层级。为了避免把结构性推论误读为外部学科证明，所有重要结论应尽量标注断言等级。

## L0：比喻性表达

用于启发理解，不构成严格命题。

示例：

> 某个社会系统像物理系统一样发生“相变”。

## L1：结构性类比

两个系统在结构上相似，但尚未证明同构。

示例：

> 金融危机中的反馈链条类似物理系统中的级联失稳。

## L2：结构性推论

点火框架基于 `C / M / I / L / G / P` 等函数给出内部可追踪推论。

示例：

> 某现象可被解释为门控面合并、自举收敛或退出权失效。

## L3：框架内判定

在点火框架内部，`J⁺ / J⁻` 判定通过，并可记录为 `true / false / contradiction / pending`。

注意：这仍然只是框架内判定，不等于外部数学证明或实验验证。

## L4：外部数学证明

命题已经被翻译成公认数学语言，并给出形式化或可复核证明。

## L5：外部实证验证

命题已经连接外部数据、实验、观测或独立来源，并经受了可重复检验。

## 使用原则

- README 首页默认只展示 L1-L3 层级。
- 涉及物理学、数学、医学、法律、金融等高风险领域时，必须说明是否达到 L4 或 L5。
- 如果没有外部证明或实证数据，禁止使用“已证明”“已解决”“已经统一”等容易误导的表达。
- 证据不足时应标记为 `pending`。
