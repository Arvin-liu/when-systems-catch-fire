# 当前科学与 WAIC 研究线：从覆盖表到可反驳的研究对象

## 这条研究线留下的不是“科学已经证明了点火”

当前科学映照的真正产出，是一套把外部知识带进点火时仍不越过证据边界的研究纪律。它能回答：某个外部方法看见了什么、可以和点火的哪个对象比较、哪里只是结构类比、哪些反例会迫使点火降级。它不能回答：点火已经被外部科学验证，或者某个框架族就是世界的真实分层。

因此本篇把三种对象分开：

1. **证据源**：研究论文、方法、标准、反例和可定位的全文材料；
2. **研究映照**：外部对象与点火对象之间的 `DIRECT_PROJECTION`、`PARTIAL_PROJECTION`、`STRUCTURAL_ANALOGY`、`GAP_EVIDENCE` 或 `NO_VALID_MAPPING`；
3. **点火候选**：由映照产生的待检验原语、研究问题或架构候选。

“被覆盖”最多说明第二层完成了某种结构比较；它不自动把第三层变成事实。

## V1 到 V2：哪些被保留，哪些被改写

研究线 V1 的基线是 145 个来源、56 条负证据、14 个框架族和 38 条全文等价材料。V2 沿着两条线深化：一条是把全文口径严格收紧并补到 76；另一条是主动寻找潜在系统、不可识别性、等效解释和历史方法论反证。

| 旧结论/对象 | R2 处置 | 当前能说到哪 |
|---|---|---|
| 145 源、56 条负证据、14 族 | `RETAINS` | 仍是 V1 可追溯基线，不等于 145 个独立真理 |
| V1 的 38 条全文等价基线 | `RETAINS`，但 V2 严格核账 | 其中一部分只有摘要权限；只有实际读到正文位置的材料才进入严格全文口径 |
| “14 族是最终版” | `REVISES` | 新增 F15 候选，但不重排整个架构 |
| Q40 候选 C（由 Ψ₀ 吸收） | `SUPERSEDED` | 新证据显示潜在系统发现闭环不能静默散入 Ψ₀ |
| Q40-D | `REVISES` 为 D1+D2 | D1 是操作闭环，D2 是依赖假设的分析视图；两者均不编号 |
| G1/G2/G3 是全部真实缺口 | `REVISES` | 潜在系统候选曾被漏列，缺口清单不能声称穷尽 |

V2 的 55 张 overlay 卡与 V1 共同形成 200 张机器可合并卡；严格全文合计 76。另有 17 张 `ABSTRACT_REVIEWED` 材料被明确排除出“已闭合”计数，只能作为线索。这里的 `COMPLETE` 是该研究任务在自身交付条件下完成，不是人类已采纳其中每个判断。

## 五个当前最佳研究命题

### 1. 可识别性是解释的刹车，不是附录

系统、因果和历史材料都显示：同一组可见结果可能由不同系统组合、参数或叙述产生。潜在变量因果发现可能返回 `unknown`；参数松弛和 equifinality 允许多组解释拟合相同观测；历史材料还受到档案、选择和权力关系影响。

所以点火的研究闭环不能只保存“最像的解释”。它至少要保存候选集合、观测等价关系、门禁状态和下一项最有信息价值的资料。`IdentifiabilityGate` 不是保证因果为真，而是阻止“唯一真实起因”在证据不足时被写出来。

### 2. 多系统视图可以暴露遗漏，但不会制造唯一真相

华北大旱（1876–1879，事件 ID `E-1876-1879-NCF`）原型把气候、农业、财政、物流、人口、信息和治理作为互相连接但不等价的视图。纯气候解释留下死亡率差异、赈济时滞、粮价非线性和冲突热点不重合等残差；残差可以触发财政、物流和信息系统候选。

原型比较了 `{S1}`、`{S1,S3}`、`{S1,S3,S4,S6}` 和 `{S1,S5,S7}` 等组合，结论不是选出 A1–A4 中的一个“真祖先”，而是判定总问题为 `NOT_IDENTIFIABLE_FOR_UNIQUE_ORIGIN`，并把 A2/A3 的部分观测等价写入正文。人口史、货币经济史、信息行政史三个投影视图减少了重复、暴露了遗漏，却没有收敛为唯一历史真相。

这使“多史投影”成为一种比较和遗漏发现工具，而不是文明进步叙事、世界本体证明或跨时代机制同一的许可证。

### 3. F15 是条件性方法族候选，不是第七层或总模型

V2 的 O2 裁决提出 F15：系统之系统、潜在系统发现与世界演化投影。它的可操作部分包括开放且可修订的系统登记、残差记录、潜在系统候选、跨系统祖先图、替代分解集、可识别性门禁、三角验证和 claim ceiling。

F15 有三条硬边界：不认证单一世界基质；不新增 L7；不把相关、时间先后或结构同构升级为因果。D1（潜在系统发现与跨系统重建）即使拒绝“世界单一基质”假设也仍可作为残差审计能力；D2（多史投影）则明确依赖假设、有损、视角化。

在当前成果册中，F15/D1/D2 是 `CURRENT_BEST_AI_GENERATED_CANDIDATE`，不是 formal 执行对象。至少两名独立人类评审、原型独立复核和 Q41/Q42 接口实现验证仍是采纳触发条件；人类没有完成前，不得写成已采纳架构。

### 4. 评估容量是能力声明的一部分

V2 的反证审查把“AI 生成超过人审”列为主动风险，而不是已经解决的风险。研究材料可以支持某个系统在某个设置下声称完成了任务；它不能由演示速度、论文数量或产品页面自动推出现实可靠性。

当生成、检索、模拟和传播速度超过人工抽查、复现、隐私审查和责任裁决能力时，系统的瓶颈会从生成端迁移到评估端。一个合格的能力主张因此必须同时给出样本、失败集、基线、协议、独立复现、人工接管和外部影响；否则只能停在“已报道的能力主张”。

### 5. 研究映照本身有立场，不能伪装成中性镜子

选择哪些事件、数据和来源，决定了什么会出现在系统底盘里。历史事件不是无视角的自然标签；多史投影也不能消除档案可得性、语言、殖民知识秩序和幸存者偏差。`SourcePerspectiveAndSelectionRecord`、`STRUCTURAL_ANALOGY` 标签和反证登记的意义，是让立场可见，而不是声称已经消除了立场。

## WAIC 837 篇：公共话语语料的具体用法

WAIC-2026 知识库有 837 个 Markdown 文件，横跨大会年份、企业实践、具身智能、机器人、芯片、医疗、金融、城市、治理、教育和组织等入口。它的研究价值不是“条目很多”，而是把一段时期内公共 AI 话语的重复问题放在一个可检索的语境中：

- **从云到物理世界**反复出现，说明具身化、工业化和机器人是重要议程；但议程密度不等于部署效果、鲁棒性或社会收益。
- **从模型到 Agent、从个人到组织**反复出现，说明责任、权限、数据基础设施和评估容量正在成为应用叙述的一部分；但演讲、展会报告和企业案例不能替代执行日志、失败样本或独立审计。
- **“可信、安全、治理、向善”与产业落地并行出现**，说明能力叙述已经主动携带规范性语言；但规范性承诺只有在申诉、纠偏、退出和责任归属记录中才可能被检验。
- **年份、来源类型和宣传语境高度混杂**，同一产业叙事可能被多篇转述；标题数量、专题数量和重复关键词都不能当独立证据计数。

因此 WAIC 在成果册中登记为 `RESEARCH_CORPUS / SOURCE_LEAD_MAP`：它可以帮助选择研究问题、发现待核验主体和追踪公共叙事变化；它不能单独支撑模型能力、产业成效、治理有效或点火机制的结论。下一次使用 WAIC 时，至少要为每个命题补原始论文、官方数据、合同/政策正文、运行记录或独立调查，并把“报道说了什么”和“世界发生了什么”分栏。

## 反证与研究出口

本线主动保留九类攻击：过度统一、巨型总模型、隐蔽立场、事件选择偏差、因果不可识别、同构冒充机制、历史目的论、AI 超过人审、学科霸权。当前状态不是“全部已解决”：

- 过度统一、巨型总模型、同构冒充机制和历史目的论主要由定义护栏缓解，但护栏被删掉就会复发；
- 隐蔽立场和事件选择偏差只有部分缓解，仍受来源与档案结构限制；
- 因果不可识别在强制使用门禁时有明确刹车，但不能保证未来数据可识别；
- AI 超过人审是主动未消除风险；
- 非英语正文获取仍不足，非西方来源的数量增长没有自动消除学科霸权。

下一轮最有价值的研究不是再增加一张“支持点火”的表，而是：扩大独立 source family；为每条支持证据配反证；把人类接管、退出和纠偏记录纳入能力评估；完成非英语权威正文核验；并单独邀请人类评审审查 F15/D1/D2 的方法边界。

## 证据与维护边界

本篇依据仓库内 V1/V2 研究资产、V2 overlay、有限历史原型、反证审查和 WAIC 目录编写。具体原始路径作为 `PROVENANCE_REF_ONLY`，不意味着出版分支必须携带全部研究原件。机器卡、全文位置和持续更新合同仍以 `research/current-science-reflection/` 与 `research/current-science-reflection-v2/` 的版本化资产为准。

更新时保留 V1 与 V2 overlay，使用 `RETAINS`、`REVISES`、`SUPERSEDES` 说明变更；新支持证据至少配一条反证，证据状态不得从摘要直接跳到全文或架构采纳。未来可以升级、降级、修订、拆分、合并或撤回本篇任何命题。
