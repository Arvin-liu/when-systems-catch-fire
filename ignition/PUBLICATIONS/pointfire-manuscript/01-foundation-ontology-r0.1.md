# 基础本体：人类互动的候选构件 r0.1

**DRAFT · 第一轮研究笔记 · 2026-11-22**  
**工作标识：** `POINTFIRE-FOUNDATION-ONTOLOGY-001`

## 问题

若研究对象是人与人之间的互动，哪些东西必须分开记录？本笔记从制度分析、社会学、组织研究、心理学、政治学、人类学、经济学、金融学、复杂系统与历史资料中取候选工具。它不是正式理论，也不假定任何一套术语能跨所有时期、文化和尺度直接通用。

## 最低候选构件

| 构件 | 初步用法 | 不能混为一谈 |
|---|---|---|
| 主体/行动者 | 承担行动、选择、反应或结果的分析单位 | 不是其角色，也未必是自主、知情或单一的 |
| 角色/位置 | 在某项关系或制度中对权限、义务和期待的定位 | 不等于个人身份，也不保证被履行 |
| 身份/地位 | 被承认、授予或主张的社会分类及相对位置 | 不自动代表实际权利、资源或影响力 |
| 利益/受影响位置 | 主体追求或承担的结果及其与议题的关系 | 表达的目标、制度利益、研究者推断和实际影响需分别记录 |
| 权力/依赖 | 特定关系中控制资源、信息、制裁和替代选项的能力 | 不是固定人格特征；同一主体可在不同关系中依赖或占优 |
| 关系 | 交换、照护、联盟、冲突、代表、竞争、债权等联系 | 不是单次行动；可能有方向、时间、网络层及多人结构 |
| 行动/不行动 | 有时间位置的选择、回应、拒绝、沉默、延迟、退出或未采取行动 | 不可由结果倒推动机；沉默也不自动表示同意 |
| 规则/规范/资源 | 塑造允许、要求、禁止、激励和实际可行性的条件 | 纸面规则不等同实践规则；文化意义也不等于法律 |
| 集体行动者 | 通过某种协调程序、决策接口或授权代表行动的多主体集合 | 不等于无分歧的单一意志；记录内部联盟、异议、授权和否决 |
| 观察者/记录者 | 生产、分类或保存证据的人/机构 | 不应被设作全知视角；记录立场和缺失进入证据链 |
| 结果/残留 | 行动后变化的规则、资源、关系、声誉、能力、债务或记忆 | 不等于研究者的“成功/失败”标签；微观到宏观需机制解释 |

Merton 的角色集提醒角色与位置及相关他者相连；Emerson 将权力理解为关系中的依赖；March 将公司分析为政治联盟；Ostrom 的制度分析框架区分参与者、规则和行动场域；Coleman 讨论微观行动通往宏观结果所需的解释桥梁。[来源路线和边界见研究路线](00-research-route.md)。这些是不同问题下的分析启发，不共同证明一份普遍本体。

## 文化差异作为显式变量 `C`

文化差异纳入本体的情境变量，而非国籍标签或固定群体性格。初步记录案例中的本地语言与分类、互惠和义务期待、亲属/陌生人边界、公平标准、权威正当性、声誉和制裁、仪式与叙事，以及不同阶层、地区、年龄、性别、组织位置和代际间的争议。

跨文化经济博弈研究发现不同社会的行为存在显著差异，且经济组织、市场整合与日常合作收益等因素也与差异相关。这支持测量群体情境，不能证明“文化单因果”，不能把群体均值套到个人，也不能将实验结果直接当作现实社会关系。国家层文化研究中的生态谬误和跨语言测量等值必须主动审查。[Henrich et al. (2005)](https://www2.psych.ubc.ca/~henrich/Website/Papers/Henrich_1-62.pdf) · [文化研究中的生态谬误](https://journals.sagepub.com/doi/10.1177/0170840613517602) · [人类学“礼物”文献综述及其争论](https://anthroencyclopedia.com/entry/gifts)

文化情境会被行动者学习、理解、争议、策略性运用和改写。因此后续记录应同时问：什么规范被说出，谁有解释权，实际如何执行，哪些人拒绝或不认同，制度与资源条件怎样共同塑造行为。跨文化材料须保存原语表述、翻译和研究者编码；文化内部变异与时间变化不可被一个国家或民族均值覆盖。

作为数据组织占位，可记：`O = f(A, R, E, X, I, M, C, H, N, L, Q, P, T)`。其中 `O` 是互动/结果观察；其余依次为行动者、位置、关系、行动、制度、物质条件、文化情境、历史、网络、尺度、信息、权力/依赖和时间。此式**不是因果模型、估计函数或理论定律**。

## 互动机制候选

- **协作和冲突：** 目标是否互依、互补或竞争？实际目标与各方对目标互依的认识应分别记录。
- **信任和互惠：** 先前互动史、信息、风险、替代选项和规范期待如何影响承诺与回应？小型实验只支持限定的实验观察。
- **联盟和组织：** 哪些主体通过程序形成集体行动？代表授权从何而来？内部收益与风险如何分布？
- **规范和制度：** 正式规则与实践规则何时一致、冲突或被改变？谁制定、执行、规避或承受规则？
- **退出、发声与留存：** 权利、可行性、行动、关系终止、被迫排除、成本、替代和反馈分开研究；“没退出”可能只是无替代或不可见。
- **跨尺度变化：** 个体互动如何经由组织和制度接口影响更大系统？不能把微观行为简单相加成宏观因果。
- **多人高阶互动：** 若联盟、仪式、协商或协同行动无法从成对关系还原，再考虑高阶网络表示；表示选择本身不证明机制。

## 首轮交叉案例

本轮研究卡涵盖：Berg 等人的双人信任/互惠实验；15 个小规模社会的经济博弈；尼泊尔灌溉集体行动；WeWork 的公司控制权披露与重组文件；美国制宪及权利法案争议；现代土耳其政治转折；西班牙—墨西加战争多方结构；点火已有历史案例的来源边界。这些材料压力测试构件区分能力，不构成统一因果定律。现有研究卡保留了来源级别和下一轮核验需求。

未发生案例尚不填造：须先定义结果、机会/风险集与观察时间窗，再选“结果可能发生但未发生”的负例。材料没有留下记载不是事件没有发生的证据。

## 点火已有材料的边界

Formal 基线的成果册把协作/认同双层、提议者—响应者事件、退出分类/成本等列为项目内部概念或工具，仍要求案例观测和替代解释；A1–A9 是变量接口而非测量概率。MCF 是候选派生表示，不构成因果证明。Workbench 的 `EXECUTOR` / `VALIDATOR` 是代理流程角色，不应冒充社会角色。既有案例来源质量不一，尤其金兴起案例有混合来源和未核验主张。因此本笔记仅把既有点火术语纳入候选对照。

## 当前可说与不可说

**可说：** 多个研究传统提供了可用于分别观察行动者、位置、关系、规则、文化情境和结果的工具；群体互动差异应在具体情境中调查。  
**不可说：** 本轮未证明统一角色表、普遍文化维度、通用互动公式、点火因果定律、普遍退出概率或任何历史案例的唯一原因。
