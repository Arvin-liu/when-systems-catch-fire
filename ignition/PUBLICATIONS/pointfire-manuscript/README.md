# 《点火》研究手稿

> **状态：DRAFT · 研究进行中 · r0.1（2026-11-22）**  
> 本目录是《点火》书稿项目的独立入口，与[《点火成果册》](../pointfire-results-book/README.md)分开。以下内容是首轮基础研究笔记，不是已接受的正式理论或已完成书稿。

《点火》暂定副标题为“从华夏的反复重铸，看人类共同体如何自我塑造”。项目研究历史、群体、组织、制度、政策、国家、人际及跨尺度互动。研究范围按问题开放给历史学、社会学、心理学、政治学、人类学、经济学、金融学、复杂系统等相关领域；不以点火仓库现有材料作为唯一信源。

## 本轮研究边界

- 区分来源事实、分析解释与候选假说；把未知保留为未知。
- 文化差异作为显式情境变量 `C` 纳入研究，不以国籍或群体均值代替个人，也不把文化与制度、生态、市场、资源、网络等因素混为一谈。
- 不预设通用角色清单、普遍公式、成功法则、因果方向或退出概率。
- 组织/共同体不默认是单一行动者；记录授权、联盟、内部利益差异、异议与被排除者。
- 不把外部冲击或材料缺失等同于内部失败或“没有发生”。
- 本轮只完成第一轮公开研究骨架；案例主张核验、负例遴选、同行评议和 Owner 接受仍未完成。
