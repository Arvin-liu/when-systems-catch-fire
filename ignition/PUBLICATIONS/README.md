## 读者的最短路线

1. 先读[一页全景](what-pointfire-knows-now.md)，获得全局边界。
2. 再读[完整第一卷](volumes/001-pointfire-after-one-hundred-iterations.md)，理解问题、发现、纠正、实验和未知如何连成一条叙事。
3. 需要核对时，进入[研究笔记](notes/001-pointfire-research-notes.md)或[百轮台账](hundred-iteration-achievement-ledger.md)。

“真正知道”只指当前证据下可以公开承担的窄结论，不表示点火已经解决量子引力、跨域因果、历史唯一因果或开放世界函数问题。
