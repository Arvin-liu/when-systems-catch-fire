# R0.3 Method Contract

Produce one bounded response for each case in the packet manifest. Use only
the listed cognitive evidence and your available provider-neutral reasoning
capabilities.

For each case:

- distinguish recorded observations from interpretation;
- keep plausible relationships separate from established facts;
- identify unknowns and the limits of the source;
- state what additional evidence would support a stronger claim;
- preserve multiple interpretations when the source does not resolve them.

Do not invent missing observations, convert a status-only tool result into
case evidence, or infer that a system was deployed merely because a change
was requested or acknowledged. Do not search for related real-world data.

This contract is a response method, not an answer key or evaluator rubric. It
does not define expected relations, preferred continuation, scoring criteria,
or an inheritance threshold. Record each cognitive read and its SHA256 in the
R0.3 read ledger. Record each pre-closure operational execution and finite
status observation there as well.

If you encounter an unlisted source, operational source content, case-specific
information through an operational status, an evaluator artifact, or a gold
answer, stop further cognitive reads and ordinary operational work. Record the
observed event and finite status, stage the ledger, then run the finalizer to
preserve the contamination status. Do not clean, retry, or self-adjudicate the
trial.
