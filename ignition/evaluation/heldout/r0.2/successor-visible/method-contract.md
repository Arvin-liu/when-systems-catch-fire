# Observable Method Contract R0.2

For each synthetic source, produce an inspectable record that:

1. binds each material statement to a precise source locator;
2. labels observations, source-reported claims, interpretations, hypotheses,
   and unknowns distinctly;
3. represents named objects and directed relations without filling gaps;
4. records provenance, source scope, uncertainty, boundaries, and unresolved
   obligations;
5. states a bounded claim ceiling and forbidden inferences; and
6. proposes one bounded continuation with prerequisites and a stop condition.

Use only the supplied source and its provenance. A source statement is not
independent verification. Preserve ambiguity where the source is silent.
Successful serialization or schema validation establishes structural
conformance only; it does not establish truth, novelty, causality, capability,
generalization, cognitive inheritance, or acceptance. Do not write hidden
reasoning traces.
