# Held-out Successor Protocol R0.2

R0.2 separates the information a successor may use for cognition from
operational controls that a clone may execute. The successor-visible manifest
freezes the cognitive evidence paths and separately identifies execution-only
components. A status-only hook invocation is not a cognitive read.

The two cases in this version are newly authored synthetic objects with
provenance records and source hashes. No output, answer key, gold IR, expected
relation set, transition answer, human confirmation, or evaluator result is
included. The former trial's cases and outputs are not inputs to this packet.

The evaluator-sealed directory is physically separate from the
successor-visible tree. This Builder has authored no answer key or criteria;
an independently authorized evaluator must preregister its materials after
the successor trial, outside this packet.

R0.2 isolation is procedural. A full clone contains operational source and
other repository paths. The task contract requires the successor not to open
or interpret execution-only source and requires every cognitive read to be
ledgered. The finite status interface and read-ledger validator expose no
source text or case-specific output.
