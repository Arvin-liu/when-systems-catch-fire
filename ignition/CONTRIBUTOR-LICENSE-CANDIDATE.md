# Contributor License Gate

The project now uses a layered license model with BUSL-covered core software, Creative Commons-covered documentation/governance text, and Apache-2.0-covered interoperability schema where marked.

Until a formal contributor license agreement or written contribution authorization is in place, the project does not accept external code contributions that would prevent dual licensing, commercial licensing, or future AGPL conversion of BUSL-covered software.

Contribution intake rules:

1. Discuss externally authored code changes before submitting them.
2. Include a written statement that you have the right to license the contribution under the relevant project layer and, where needed, under future commercial or AGPL terms.
3. Do not submit third-party excerpts, generated content with uncertain rights, imported datasets, or private material without explicit provenance notes.
4. DCO-style sign-off alone is not treated as automatic permission for arbitrary relicensing.
5. Documentation, governance, schema, and data contributions must identify the intended license layer.

Existing maintainer-directed agent commits remain treated as maintainer-directed project output for governance purposes, while not pretending this repository audit is a court judgment.
