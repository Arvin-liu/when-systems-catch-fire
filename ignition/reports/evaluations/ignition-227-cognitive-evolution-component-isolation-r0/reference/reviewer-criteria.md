# Reference policy independent reviewer criteria

Each reviewer scores all six raw policy objects against their own family M0 and E1. A policy is USABLE only when this reviewer marks all eight schema-listed dimensions true and affirms that the policy is E1-supported, operational, bounded, preservation-safe, explicit about fallback/edges, and free of unsupported universalization. Report row-level reasons. This sheet is not used to alter policy text. Both reviewers' judgments must be true for a lineage to be counted as usable. Keep the fixed denominator six.
