# Transfer-case boundary

`TRANSFER-01` is one new bounded synthetic case, distinct from the two R0.4
held-out cases. It contains only source facts, a method-trace condition, and a
facts-only condition. It does not contain evaluator expected labels, scoring
rubrics, a provider comparison, a real-world knowledge task, or a canonical
claim.

This is preparation only. No Successor, Evaluator, cross-model trial, MetaRSI,
Model-RSI, or training is run here.
