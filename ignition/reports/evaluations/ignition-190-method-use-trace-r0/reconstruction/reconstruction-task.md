# Blind Method-Use Reconstruction R0

## Successor-visible task

For each neutral case in `successor-visible-packet.json`, reconstruct only what the
packet supports:

1. identify the candidate method;
2. state why it was selected, if a selection rationale is present;
3. state the context and constraints;
4. identify the use event and expected observation;
5. report the observed outcome or failure;
6. state what changed afterward, including no-revision or unresolved status;
7. list missing links, false-positive completion risks, and unresolved/confounding factors.

Do not fill a missing selection/use link from a plausible narrative. A candidate
is not a use event, a use event is not a cause, an outcome is not proof that the
method caused it, and a revision narrative is not evidence-bound revision.
Preserve exact source references, source fingerprints, uncertainty, and claim
ceilings. Same wording is not the same method.

The packet intentionally contains no evaluator expected labels, scores, or
disposition key. It is a reconstruction input only. This preparation task does
not execute a Successor or Evaluator.
