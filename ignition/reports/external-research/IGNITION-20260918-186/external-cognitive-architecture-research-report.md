## Findings

### MetaRSI

The v2 paper proposes a typed deployed-system triple of data, model, and harness; separate improvement operators; horizontal operator scheduling; vertical revision of proposal policies; and a meta-scheduler. It also describes an Anchor/evaluation boundary, held-out task set, release rule, resource accounting, perishable evidence signals, and a proposed lifecycle that consolidates/de-duplicates harness memory and retires scaffolding after internalization. These are paper claims and reported benchmark results, not results reproduced by Task186.

The same paper's generated-data path assigns Operator and blind Anchor roles to the same target model and relies on input isolation. Its evaluation scores are explicitly benchmark-bound. The bounded v2 search found no separate TTL for self-knowledge or capability profiles. The perishable learning signal and typed artifact freshness are evidence-freshness mechanisms; they should not be relabeled as a self-model expiration policy.

The pinned RSI-Harness repository is narrower than the paper: it provides versionable Genomes and a user-confirmed workflow that turns selected session history into a Harness-RSI Genome. Its README states that the repository has no benchmark, data-generation, training, or evaluation code. The extension uses host instructions/skills to perform policy work; the inspected workflow is not a runnable Data/Harness/Model loop.

### External mechanisms

The frozen comparisons support distinct, bounded results:

- Reflexion reports within-task-family improvements across trials from verbal reflection memory; its evaluator varies by task, and the paper notes self-evaluation/test-generation limits.
- Self-Refine improves outputs through finite same-model feedback and refinement; a separate blind human comparison evaluates sampled outcomes, but the method does not create a persistent cross-task method artifact.
- Voyager stores/retrieves executable Minecraft skills and reports their reuse in a new world on novel tasks; it does not establish a domain-neutral skill-generation or evaluation method.
- DSPy optimizes declared prompts/demonstrations/program candidates against a caller metric. In the pinned MIPROv2 code, omitted `valset` creates an internal split from the supplied trainset; it is not a sealed external holdout.
- Generative Agents retrieves simulation memories using recency, relevance, and importance. Its pinned code's `expiration` field does not by itself prove deletion.
- MemGPT pages between context and external memory; its paper says queue-evicted messages are summarized but remain in recall indefinitely. Letta Code's separate pinned product repository provides explicit, attributable memory patches, Git persistence, and size/depth limits without evidence of semantic capability-profile freshness.
- SWE-agent reports benchmark outcomes from an agent-computer interface, using development examples for design and execution-based human-written tests for benchmark scoring. AgentBench provides repeatable multi-environment measurement, publishes its Dev and Test data, and reports test scores; its public test set is not a confidential holdout.

No reviewed primary source establishes general cross-model inheritance of the procedure that creates, selects, validates, and retires improvements. MetaRSI proposes the closest architecture for method revision, but its reported results and current public repository do not establish that broad transfer. Task success, reflection memory, skill reuse, prompt optimization, and long-context retrieval are not interchangeable with cognitive-method inheritance.

The source crosswalk separates active-context size, durable-store size, retrieval weighting, compression/eviction, explicit deletion, and semantic retirement. MemGPT's context summary retains source messages; recency reduces retrieval probability without deleting a record; a TTL field is not a quality judgment; a last-N buffer is not evidence-based retirement. Letta Code and Pointfire provide explicit mutation/provenance controls, while MetaRSI's broader consolidation/retirement behavior remains paper-level in this comparison.
