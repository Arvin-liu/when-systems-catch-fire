## 4. R1–R5 findings

### R1 — primitive ablation

`P` is recouped by existing source, M/E, claim-ceiling and non-escalation contracts. `O` is a useful name for a distributed family of stop, pause, rollback, reconciliation and degradation paths, but has no common state or universal domain. `N` retains a Charter-originated normative boundary that evidence and topology cannot derive; it is not thereby a new universal primitive. `A` is decomposable into authority source, approval/consent, accountability sink, contest/revocation and consequence visibility.

### R2 — A placement

The strongest surviving A content is a junction review question: does a named decision have a legitimate authority source, a bounded execution path, a resolvable accountability sink and a contest/stop route? Existing Owner, Approval, Stage Snapshot and Runtime contracts each carry parts of this. A without those sources is circular; those sources without the label still operate.

### R3 — orthogonality

The four quadrants show that a bounded claim can coexist with broken authority topology, and a complete approval/topology path can coexist with an over-ceiling claim. This establishes non-implication, not two foundations. N can alter the admissible action space, O is entangled with contest/rollback, and a provenance change can force signer/action re-review.

### R4 — diagnostics

`PROVENANCE_WITHOUT_CEILING`, `ABSTENTION_AS_AVOIDANCE`, `SIGNATURE_WITHOUT_CONTESTABILITY` and `COMPLETE_RECORD_WITHOUT_ACCOUNTABILITY` survive as cross-contract review lenses. `BUDGET_AS_HARM_LICENSE` is redundant as a failure class because Policy and Charter already prevent resource budget from becoming normative permission; it remains a useful anti-confusion warning. No `NEW_FAILURE` is claimed because no independent executable fixture establishes a new stable error class.

### R5 — arbitration

Evidence versus window, negative capability versus avoidable neglect, risk budget versus non-externalization, Owner versus distributed contribution, reversibility versus necessary irreversible action, audit completeness versus real-time response, and contestability versus emergency delegation all retain object-specific context. Existing priority, permission, deadline, fail-closed, reconciliation and human-review paths can carry the decisions; no universal precedence or new meta-arbitration layer is proven.
