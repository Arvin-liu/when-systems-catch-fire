## 7. Open contradictions and next task

The following remain open findings rather than being smoothed over:

1. Evidence and claim ceiling can delay an action needed for continuity; current thresholds are object- and risk-sensitive but do not provide a universal cross-domain emergency rule.
2. Abstention can be either corrigible restraint or avoidance; the current surfaces lack one universal deadline/opportunity-cost/comprehension contract.
3. An engineering failure budget can be confused with a normative harm allowance; the latter is rejected by the Charter boundary and is not given a new name here.
4. A nominal Owner or signature can exist without demonstrated comprehension, contestability or practical consequence-bearing; identity is necessary for responsibility routing but not sufficient for ethical adequacy.
5. Complete logs can preserve an incorrect judgment; auditability does not imply truth, correctness, accountability or recoverability.
6. Conflicting protocols require scoped authority, fail-closed handling or human review; the repository does not establish one total precedence order for every V/S/E conflict.

Recommended next task, only if Owner requests continuation: a narrow `RESEARCH_TO_CONTRACT` adversarial review that replays the seven Track A and ten Track B cases against existing contracts, measures false blocks / missed hazards / maintenance cost / authority expansion, and returns an explicit `ABSTAIN` option.
