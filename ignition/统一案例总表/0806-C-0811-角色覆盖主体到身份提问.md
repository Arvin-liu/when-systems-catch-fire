# C-0811｜角色覆盖主体到身份提问

## 编号

C-0811

## 一句话概括

李丹阳在随迁期把「贤内助/全职太太」设为人生目标、创业期只任首席内容官，主体性长期被角色覆盖，直到提出「剥离角色后我是谁」的开放追问。

## 现实场景

个人成长与家庭/创业角色交织的女性生命历程。

## 核心冲突

社会角色（妻子、母亲、内容官）持续占据评价入口，独立自我叙事被遮蔽；主体长期以角色定义自身，决策权外移。

## 因果链

1. 随迁期把「贤内助/全职太太」设为人生目标，主体性沉睡（A5）。
2. 创业期主动放弃董事长、只任首席内容官，自我认知局限（A8）。
3. 育儿现实与父亲重病击碎粉红想象，主体性开始苏醒（A10）。
4. 下一个大题：剥离妈妈/创业者/妻子后「我是谁」（A15）。

## 边界条件

该案例只说明：

- 当角色期望稳定且外部只按角色评价时，独立自我可能被覆盖。
- 剥离角色后的身份追问是主体性恢复的可修订过程，非拒绝抚养/合同责任。

不能推出：

- 所有女性都经历角色覆盖（需代表性数据，E5 pending）。
- 角色本身有害（角色与自我一致时不覆盖）。
