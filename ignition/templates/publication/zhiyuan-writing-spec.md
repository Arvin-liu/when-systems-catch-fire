# 之元写作法故事规格

Method version: `0.5.0` current; `0.4.0` and `0.3.0` remain historical
Status: `CANDIDATE_BACKSTAGE_TEMPLATE_PENDING_INDEPENDENT_REVIEW`

本规格用于后台生成与审计，不是前台提纲。字段顺序不是段落顺序；允许折返、留空、合并、分叉和 `UNNAMED`，不得把它变成固定层数、五段式或隐蔽分幕。

方法以之元命名以标记其心智与作品来源；模板只承载可迁移的心智层级跃迁内核，不能复制之元本人。

## 双来源素材池

这里的“素材来源”是写作生成角色，不把点火派生产物伪装成新的外部证据。按实际使用复制条目。

### 外部输入源 `<n>`

- `source_class`: `external_input`
- 题名／对象／事件：
- 作者、时间、渠道、版本与 canonical locator：
- 版权、隐私与可公开范围：
- 外部核验状态与 claim ceiling：
- 它提供的事实、经验、语言或张力：

### 点火增量输出源 `<n>`

- `source_class`: `ignition_increment`
- 增量类型：`claim / argument / formal_object / mechanism / map / gap / residue / Q12 / Q13 / Q14 / MCF / PSD / ARN / Atlas / point-fire analysis / provenance-gated return / other`
- canonical 路径／ID、生成任务、版本或 commit：
- 它回链的外部材料、操作或反馈：
- 当前状态与 claim ceiling：
- 未决 gap、residue、竞争解释和不可映射部分：
- 它在写作中承担：`起始承载点 / 概念压力 / 跃迁接口 / 竞争解释 / 回照对象 / 其他`
- 是否被误算为独立复证：`NO / 需要修正`

### 入池审计

- 所有材料是否已标记来源类别：

- 受限全文是否保持不公开：
- 是否错误提高 L0—L5 claim 或暗增新层：

## 项目来源与表达目标

### 工作节点 `<n>`

- 跃迁接口：`双重归属铰链 / 概念递归重定义 / 未解决问题 / 相同张力 / 观察者变化 / 时间或意义连续变形 / 其他`
- 若递归重定义：同一概念的旧世界 → 新世界：

- 回照后旧层新增意义：
- 潜题是否生长、移动、分叉、合并或反向显影：

## 潜题生长与反向显影

- 后层回链了前文哪些词、选择、张力或材料：
- 哪些开头／中段材料因此改变意义：
- 是否只是事后总结或空降宏大命题：
- 哪些部分应保持开放：

## 出版审计门

- 层级门：新层是否至少一次真正改写旧层？
- 连续门：跃迁是否有作品内部连续性，而非强制铰链词？
- 回照／潜题门：起点或旧层是否增义；潜题是否由材料生长？
- 证据门：哪些句子必须回链来源；哪些只能写成候选？
- 价值门：事实限制、个体经历、物理差异、受损／沉默主体是否保留？

### 语言—思维逻辑平面记录

- `source_form`、来源语言／变体／语体／版本：
- `source_language_profile`：
- `normalized_meaning_candidate`（必须标明候选投影，不是真义）：
- `target_form` 与 `target_language_profile`：
- 行为者、体貌、证据来源、指称、连接、信息顺序等 `framing_deltas`：
- `unmapped_residue` 及其是否影响 claim：
- 转换 provenance、version 与不变的 claim ceiling：
- 是否存在认识相关静默变化；若有：`FAIL_CLOSED`：

### 目标中文实现门

- 事情是否先按作品所需发生，再让反思进入；若倒置，表达收益是什么：
- 话题／主语／焦点是否自然，省略是否可恢复，代词是否唯一或诚实地保留歧义：
- `了／着／过／在`、时间、过程、完成和终点是否一致：
- 是否凭空补出因果、让步、确定性或行为者：
- 被动、名词化、多层 `的` 与机器平行是否遮蔽事件或主体：
- 全文朗读时，长短句、停顿和标点是否落在意思关节：
- 反常句法的可审计收益；若无：退回重写：
- 是否正在模仿一个作家或统一作者声音；若是：停止：

## 信息增益停止

尝试的下一层是否改变：

- 问题／定义／边界／观察者：
- 机制／干预／残余：
- 潜题或此前层意义：
- 若全部为否：`STOP_NO_INFORMATION_GAIN`
- 潜题是否已经足以回照主要来路：
- 结束是否允许开放，而不强制总结：
- 停止理由（不得只写字数、幕数或“中心思想已总结”）：

## 可选高维压缩结尾

- 使用：`YES / NO / UNDECIDED`
- 若使用，可展开回哪些已生成层级：
- 是否格言化、空降宏大词或提高下层 claim：
- 若不用，作品如何自然结束：

## 可选编辑修订（生成之后，Draft PR 候选）

本段仅在草稿已有稳定事实边界、claim ceiling 与概念运动后启用，用于重组认知迁移的公共可见性。**可选、非强制**，长反思文、学术说明或文学随笔可整段留空或只取部分。字段顺序不是执行顺序。

### 修订触发与草稿诊断

- 草稿主导类型：`概念密集 / 史料编年密集 / 清单综述密集 / 已连贯仅局部修订 / NOT_APPLICABLE`
- 选择的主要编辑压力：
- 是否误把诊断变成文体准入门槛：`NO / 需修正`

### 冻结认知迁移不变量

- 一句话：读者读完对什么的理解不同了？
- 起始理解（读者带入的想法）：
- 修订后理解：
- claim 边界（不可越过的事实／因果／强术语）：
- 低层现实（重写必须存活的具体人、事件、差异、受损／沉默主体）：

### 结构承载选择

- 主承载：`递归追问 / 程度加深 / 视角切换 / 组合`
- 是否与现有概念对应：前视压力／递归重定义／横向换域但同潜题／起始承载点／信息增益停止
- 是否逐段机械轮换：`NO / 需修正`

### 去公式化对比审计

- 是否把表面语法当成认知迁移唯一承担者：`NO / 需修正`
- 保留的必要否定／精确对比句（附理由）：
- 是否误作禁词令：`NO / 需修正`

### 具体锚定审计

- 每段是否至少有一个证据支撑的锚（人／场景／物／数／引文）：
- 是否出现为可读性杜撰的锚：`NO / 出现需删除`

### 开头结尾契约

- 开头是否建立具体承载＋活问题＋继续理由：
- 结尾是否避免自动总结／升华／说教／炮制金句：
- 结尾若产金句，是否夸大证据或压平论证：`NO / 已驳回`

### 朗读与反套路审查矩阵

- 硬门（不可妥协）：事实、claim ceiling、受损／沉默主体是否保留：
- 可选项（随文体浮动）：金句密度、升华程度、段落形状
- 是否发现重复 AI 段落形状／排比小标题／过早文明级升华：

## 返回点火记录

- 发布／试读版本、渠道、时间和受众范围：
- 要观察的误解、现实反例、遗漏主体、失败铰链、伪同构或伪压缩：
- 反馈主体、原文范围、时间、渠道和解释限制怎样记录 provenance：
- 哪些反馈可成为候选 L0 source／gap／现实反馈：
- 哪些只能作为审美、情绪或传播数据：
- 适用返回入口：`Q12 / Q13 / MCF / PSD / ARN / Atlas / iteration / other`
- 停止、修订、撤回与回滚条件：
- 禁止升级：点赞、赞美、传播和多 AI 共识不得直接升级真实性。

## 前台清除

删除字段标签、固定方法顺序、项目缩写、说明性转场、未经支持的强断言和机械模仿的作者意象。模板完成、CI、自动评分或“像之元”不得被写成文学质量证明。
