# 角色—身份—主体性补全书单（2026-07）

## 结论先行

第 57 期照亮的不是一个孤立问题，而是一条长期缺口链：

- 点火对退出权、组织门控、系统遮蔽已经较强；
- 但对“人如何被角色解释、如何把角色内化成自我、又如何从角色里把名字拿回来”的理论核仍偏薄。

因此本轮不追求固定数量，而是先形成一个“可立即碰撞的核心批次”，再给出扩展批次。

## 后续研究方向（不计入书单）

- Stuart Hall 的其他文化身份文集，可作为下一轮扩展阅读，但不再用“等相关文集”充数。
- 身体社会学补充线可继续扩到 Crossley 等作者，但需要逐本拆分后再入表。

## 为什么这批书优先

1. 它们直接覆盖 `role theory / identity theory / symbolic interactionism / narrative identity / recognition / subjectivation / care / organizational identity`。
2. 它们能把第 57 期的“听话、贤内助、糕妈、内容官、我是谁”拆成不同层级，而不是混成一团经验感想。
3. 它们为后续函数碰撞提供的是机制原语，不是励志话术。

## 当前风险

- 这批书理论密度高，不能机械做“读书摘抄入表”。
- 其中不少书是解释框架，不自动生成新函数。
- 对中译本质量、版本差异与术语对齐，后续还需要一轮细查。

## 建议碰撞顺序

1. `Goffman → Mead → Berger/Luckmann`
2. `Honneth → Foucault → Butler`
3. `Ricoeur → Hochschild → Tronto`
4. `Burke/Stets` 作为组织身份与反馈层补充
