# 新增注释 · 赛课机制下的教师生存困境

## 可作为现有函数/案例注释的内容

### 注释 N1（挂接退出权函数族 FUNC-L1-EXIT）
- 对应条目：退出权函数族（A4 应约者感知退出权 / A9 退出概率 / D499 退出权时间衰减）。
- 注释内容：赛课机制中「职称硬门槛 + 资历豁免 + 多锻炼劝说」构成一种**隐性退出权剥夺**——个体法律上可拒绝，但待遇绑定使实际退出成本无限高，退出概率趋零。这补入退出权函数族的「结构性不可拒绝」子类。
- 类型：机制注释 / 来源补充
- 来源：source.md §职称绑定的无奈裹挟
- 是否入表：作为现有函数注释，回填复核时并入，不新建条目。

### 注释 N2（挂接指标化相关 D244 / D173）
- 对应条目：D244 自主意识涌现临界条件（量化相关）、D173 显态粘性（表演化固化）。
- 注释内容：当考核只采集可量化信号（获奖等级、AI 课堂时长），不可量化核心价值（育人、师生联结）被排挤出考核表——这是「指标替代价值」而非「指标本身有误」。技术元素（AI/跨学科）是否为形式主义，取决于是否脱离教学需求，不能一概判定。
- 类型：边界澄清
- 来源：source.md §量化指标消解课堂温度 / §形式大于内容的设计
- 是否入表：作为现有函数边界注释。

### 注释 N3（挂接不可逆判据 D364 / D423）
- 对应条目：D364 实际不可逆判据、D423 不可逆体积参数归约。
- 注释内容：教师身心代价（流产、抑郁、心脏早搏）具有**实际不可逆性**，可映射「不可逆体积」的社会身心维度；系统性钝化是群体级不可逆稳态。
- 类型：跨域映射注释
- 来源：source.md §被透支的教师群体
- 是否入表：作为现有函数跨域映射注释。
