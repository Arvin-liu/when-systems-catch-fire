# 故事化评分维度

| 维度 | 说明 | 分值 |
|---|---|---|
| 可理解性 | 普通读者是否容易理解 | 1-5 |
| 结构清晰度 | 是否能清楚展示点火结构 | 1-5 |
| 跨域连接度 | 是否能连接多个领域 | 1-5 |
| 情节张力 | 是否有冲突、转折、困境、选择 | 1-5 |
| 边界清晰度 | 是否容易标注 pending 和失败边界 | 1-5 |
| 公开安全性 | 是否不容易引发误读或高风险误用 | 1-5 |
| 代表性 | 是否能代表点火框架的重要函数或问题 | 1-5 |
| 可扩展性 | 是否能继续扩展成系列文章、案例库或图解 | 1-5 |

总分 40 分。

- 32-40 分:第一批高优先级故事化
- 24-31 分:第二批中优先级故事化
- 16-23 分:暂缓,需补材料或降风险
- 15 分以下:不建议当前故事化

# 风险提醒

- 故事化不是证明。
- 高优先级不等于可以立即公开。
- 暂缓不等于没有价值。
- 高风险题材必须保留 pending 边界。
- 物理、数学、历史、教育、AI、艺术等领域都不能因为故事化表达而被写成“已解决”。

---

# pending 清单

- 所有高风险案例公开前都要检查 pending 条件。
- 所有故事化案例都要保留反例空间。
- 所有暂缓案例不得直接写成公开故事正文。
- 所有候选故事都要先确认其对应的证据制度和失败类型。
