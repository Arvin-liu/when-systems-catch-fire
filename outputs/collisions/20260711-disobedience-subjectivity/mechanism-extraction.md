# 机制抽取（mechanism-extraction）

> 候选机制 M1–M9。每条含：输入条件、中间变量、输出、反馈、触发、停止、反例、来源锚点(A层)、断言等级、是否需外部证据。
> 同构判定基于已读函数 D595–D599、D583、T40、D245 与对函数总表全量检索结果（家庭/身份/价值感/沉没/托举/管理成本/支持 轴 grep 零命中）。

## M1 听话—低成本控制机制（control-saving-by-compliance）

- 输入：权力方定义「听话」为美德；服从可换取认可/关系安全。
- 中间：控制成本↓，独立判断与退出能力↓。
- 输出：控制关系延长、管理成本外部化到被控方。
- 触发：存在可识别的权威—服从结构（家庭/学校/组织）。
- 停止：被控方恢复真实退出权、重新协商规则。
- 反例：信息充分后自愿合作（非服从，是协商）、无真实选择下的被迫服从（非美德驱动）、合理规则遵守（规则本身被接受）。
- 来源锚点：A1（分数惩罚）、A2/A3（志愿与人生被代定）。
- 断言等级：材料内成立；普遍性 pending（E1）。
- 同构判定：**与 EXIT 族 / D595(绩效绑定裹挟) 实质同构**——约束来源都是权力方的管理成本，退出权被架空。判定为 **已有函数边界扩展**（命中点火 V1「维持关系何时阻止退出」）。

## M2 外部评价内化—自我规训（internalized-evaluation-self-discipline）

- 输入：外部评分与人格价值耦合（A1）。
- 中间：持续自我监控 → 过度准备、差错厌恶 → 外部监督撤除后仍自行执行。
- 输出：主体性长期沉睡（A5 随迁期）。
- 触发：长期高压 + 单一评价入口 + 低修复通道。
- 停止：出现可替代评价体系、获得真实退出权。
- 反例：外部评价健康、未内化；评价多元时不易形成单一自我监控。
- 来源锚点：A1（分数惩罚）、A5（角色沉睡）、A10（现实击碎粉红想象才唤醒）。
- 断言等级：材料内成立；普遍性 pending。
- 同构判定：**与 D598(系统性钝化) + D597(量化指标替代真实价值) 实质同构**。D598 描述长期高压低可拒绝性下的适应稳态；D597 描述指标替代真实价值。判定为 **已有函数覆盖**（本材料提供家庭/女性轴补强证据，非新原语）。

## M3 资源托举退化为路径控制（support-degrades-to-path-control）

- 输入：提供方提供资源与安全（父母兜底、伴侣支持）。
- 中间：资源附带路径条件 → 接受者退出成本↑ → 支持变成选择约束。
- 输出：接受者决策空间被绑定到提供方预期路径。
- 触发：资源高度集中、提供方以「为你好」定义唯一好生活（C4）。
- 停止：接受者获得经济/身份独立、明确边界。
- 反例：无条件兜底（不绑定路径）、纯建议（无资源约束）、资源交换（双方明确契约，非隐性绑定）、实质胁迫（已超出托举，属强制）。
- 来源锚点：A2/A3（志愿被改、回乡路径被规划）、A4（结婚才第一次打破）。
- 断言等级：材料内成立；普遍性 pending（E2）。
- 同构判定：**函数总表「支持/托举/兜底/父母」轴 grep 零命中；EXIT 族描述退出权但非「支持→控制退化」结构**。判定为 **真新候选函数**（边界扩展 EXIT 族，新增「正向支持退化为路径控制」原语）。

## M4 角色覆盖主体身份（role-covers-subject-identity）

- 输入：社会角色（母亲/妻子/贤内助/内容官）持续占据评价入口。
- 中间：个人能力被解释为角色附属 → 主体名字与独立目标被遮蔽 → 决策权外移。
- 输出：主体长期以角色而非自我定义自身。
- 触发：角色期望高度稳定、外部只按角色评价。
- 停止：主体重新确认独立目标、角色外建立自我叙事（A15 下一大题）。
- 反例：角色与自我一致、角色多元不互相覆盖、角色可逆且不绑定决策权。
- 来源锚点：A5（贤内助目标）、A8（只任内容官、放弃董事长）、A15（剥离角色后我是谁）。
- 断言等级：材料内成立；普遍性 pending（E5）。
- 同构判定：**函数总表「身份/角色/父母/家庭」轴空白；D245(自我模型) 是数学门控面二阶门控，非社会角色遮蔽结构，二者不同构**。判定为 **真新候选函数**（社会身份遮蔽原语）。

## M5 价值创造权—决策权错配与回收（value-creation-vs-decision-right-mismatch）

- 输入：价值来源（内容灵魂）与实际决策权分离（A7 战略分歧、A8 放弃董事长）。
- 中间：组织战略漂移、关系内耗 → 主体确认自身是核心价值来源 → 收回驾驶权。
- 输出：砍除非核心业务、身份与决策重新对齐（A9）。
- 触发：贡献者创造核心价值但无对应决策权。
- 停止：决策权与价值创造权对齐、组织回到核心。
- 反例：决策权与价值创造自然对齐、非核心业务确实增值（非错配）、集体决策而非单点错配。
- 来源锚点：A7（战略分歧）、A8（放弃头衔）、A9（坐回驾驶舱）。
- 断言等级：材料内成立；普遍性 pending（E6）。
- 同构判定：**T40(决策权与信息权对称) 仅覆盖信息/决策权对称，未覆盖「价值来源与决策权分离→回收」结构**。判定为 **真新候选函数**（组织层价值—决策错配原语）。

## M6 高执行力双刃结构（high-execution-double-edge）

- 输入：高自律 + 单一评价体系绑定。
- 中间：高产出 ↔ 世界模型窄化、过度准备、机会与生活空间收缩。
- 输出：能力↑但选择空间↓。
- 触发：长期单一评价目标 + 高执行投入。
- 停止：主动引入多元评价、承认计划失效（见 M7）。
- 反例：高自律 + 多元目标（不窄化）、低执行（无双刃效应）。
- 来源锚点：A1（为下一次考试准备）、B1（永远在准备）、A12（完美展示带来他人压力，反向说明窄化）。
- 断言等级：材料内成立；普遍性 pending（E3）。
- 同构判定：**D583(认知肌肉锻炼) 只描述写作/思维训练的正向提升，未覆盖高执行力的窄化副作用**。判定为 **已有函数边界扩展**（D583 增加反向约束边）。

## M7 计划过期识别与主动刹车（plan-expiry-detection-and-braking）

- 输入：强执行 + 持续现实反馈 + 允许承认旧选择失效。
- 中间：克服沉没成本 → 停止旧路径 → 重选目标。
- 输出：从惯性执行切换到主动重置。
- 触发：旧计划与现实持续冲突、出现新可行路径。
- 停止：新目标稳态建立。
- 反例：沉没成本陷阱（无法刹车）、无计划惯性（本就无计划）、外部强制中断（非主动识别）。
- 来源锚点：A10（育儿现实击碎粉红想象）、B5（承认旧计划过期仍惯性执行）、A9（刹车回归内容）。
- 断言等级：材料内成立；普遍性 pending。
- 同构判定：**函数总表「沉没/计划过期/刹车/止损」轴 grep 零命中**。判定为 **真新候选函数**（主动刹车原语）。但受「新函数≤5」约束，本轮优先 M3/M4/M5，M7 进 candidates/ 待下一轮或外部证据补强。

## M8 努力—结果—自我价值解耦（effort-result-selfvalue-decoupling）

- 输入：社会将「努力」与「人格价值」错误绑定（努力羞耻）。
- 中间：努力≠结果≠人格价值三者解耦失败 → 个体因高强度努力仍自我贬低。
- 输出：提出「紧绷美学」——高努力本身可合理，但不等于人格证明。
- 触发：评价系统把努力当道德凭证。
- 停止：个体建立「努力是策略、非人格价值」的独立评价体系。
- 反例：努力确实带来结果与认可（健康耦合）、结果好但自我仍贬低（解耦未建立）。
- 来源锚点：B6（反对努力羞耻）、A11（被评「理性」才首次用非传统女性词定义自己）、A12（不再展示完美）。
- 断言等级：材料内成立；普遍性 pending。
- 同构判定：**函数总表「价值感/努力/认可」轴空白**。判定为 **真新候选 / 边界扩展**（与 M2 互补，M2 是内化规训，M8 是价值解耦；本轮作为 M2 的补充扩展候选，不单独占 5 名额，进 candidates/）。

## M9 模糊需求显性化与协作排序（fuzzy-need-explicit-sorting）

- 输入：亲密/合作关系中需求隐含、易错位。
- 中间：目标对齐 → 需求 0–10 打分 → 9+ 必优先、6.5− 灵活 → 事后复盘 → 空间边界（卧室/卫生间不谈工作）。
- 输出：协作冲突↓、关系可持续。
- 触发：多角色/多目标并行、需求隐性。
- 停止：形成稳定协作协议。
- 反例：单目标关系（无需排序）、需求本就一致、强制排序引发新冲突。
- 来源锚点：A13（打分制+复盘+空间边界）。
- 断言等级：材料内成立；协作机制普遍性 pending。
- 同构判定：**函数总表协作/需求/对齐机制轴空白**。判定为 **真新候选函数（协作协议实例化）**。受≤5约束，本轮 M9 进 candidates/，不与 M3/M4/M5 争名额；若用户后续要求可独立回填。
