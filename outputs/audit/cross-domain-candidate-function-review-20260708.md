## NF-X1 指标排名隐性分层

查重结果：
- 精准 0 命中；模糊「分层」条目（D94/D154/D17）边界均不覆盖"量化积分与公共资格/晋升/荣誉挂钩 → 积分高低被默认等同贡献大小 → 制造新的隐性分层"。
- 三领域复现：社会学（荣誉阶层）、自然科学（续资助分层）、历史学（职称层级）。

Ψ₀：

- C(x,y)：存在新因果结构。机制链＝量化排名成为公共资格显式入口 → 排名高低被默认为贡献大小 → 生成新的隐性社会/组织分层。这是 D597（指标替代价值）下游涌现的社会后果，但引入了 D597 未命名的独立变量（排名→贡献等价错觉→分层）。
- M(B_n)：三领域稳定复现，机制可稳定成函数，收敛性良好。
- I_iso(A,B)：与 D597 高度同构——它本身就是 D597 机制链"指标成为唯一入口 → 真实价值被挤出"在分层维度的具体表现。但它携带一个 D597 未表述的子结构（排名→贡献等价→阶层固化）。
- L_meta：不是"指标化替代价值"的另一种表述形式，而是 D597 触发后的可观测社会结果，应停在 D597 子层，不应无限下钻为新独立理论。
- G_δ：三领域材料足够支持 L2/L3 候选结论；不足以支持 L5。同时该复现恰好为 D597 的"跨行业普遍性 pending"提供了跨域证据，可用于上收 D597 的 pending 状态。
- P_meta：作为 D597 的跨域扩展注释最合适——记录"当量化排名与公共资格/晋升/荣誉挂钩时，会固化新的隐性分层"，并将三领域复现作为 D597 pending 解除的支撑证据。不再单列独立函数，避免与 D597 重复计数。

最终：**D597 扩展注释**（同时建议在上收 D597 pending 时引用本证据）。

## NF-X2 刷分博弈

查重结果：
- 精准 0 命中；模糊「博弈」条目（A8/D107/D114）均不描述"产出可拆为可量化最小单元且与评价绑定 → 主体把真实活动拆成可测动作刷分 → 真实价值被稀释"。
- 三领域复现：社会学（拍照打卡）、自然科学（重复变体）、历史学（拆分碑刻）。

Ψ₀：

- C(x,y)：存在新的、独立的因果结构。机制＝评价绑定到可量化最小单元 + 产出可分解 → 主体采取"拆分真实活动以最大化可测动作"的理性博弈策略 → 真实价值被稀释。这是一个激励博弈（Campbell 定律式）原语，不等同于 D597 的"价值替代/挤出"。
- M(B_n)：三领域稳定复现，机制清晰可稳定成函数。
- I_iso(A,B)：与 D597 部分同构（共享"指标成为显式入口"这一基底），但 NF-X2 增加了 D597 没有的独立机制——主体的策略性分解/博弈响应。二者是"基底—响应"关系，非同一机制。
- L_meta：不是 D597 的指标体系替代价值的另一种说法，而是主体对指标激励的二阶博弈反应，应作为独立机制停在函数层。
- G_δ：三领域材料足够支持 L2/L3 候选函数；不足以支持 L5（需更多学科验证）。
- P_meta：与 D597 紧密耦合但不冗余——D597 是价值替代的"因"，NF-X2 是主体博弈的"果/响应"。独立成函数更利于后续引用与反例测试，避免把"激励博弈"淹没在 D597 的价值替代叙事里。

最终：**新增函数**（建议正式编号 D 层新条目，与 D597 建立"基底—响应"关联；回填前需再次查重 + 分配正式编号）。

## NF-X3 指标驱动噪声累积

查重结果：
- 精准 0 命中；模糊「反馈回路」命中 D312（正反馈噪声放大，数学 δp_max·K^k 指数放大）、D326（正反馈饱和）——但 D312/D326 是数学/物理正反馈噪声机制，与"评价系统中数量指标成为入口、忽视不确定性、低质/假阳性产出在数量驱动下累积"机制不同构。
- 仅自然科学（高通量 p 值考核）强出现；社会学/历史学弱相关。

Ψ₀：

- C(x,y)：机制＝数量指标成为显式入口且忽视不确定性 → 假阳性/低质产出在数量驱动下累积。表面与 D312 共享"噪声增长"，但 D312 的因果原语是反馈增益 K，NF-X3 的因果原语是"指标入口 + 不确定性被忽略 + 数量偏好"，机制不同。
- M(B_n)：仅单领域强复现，社会学/历史学弱，跨域收敛性不足，暂不能稳定成函数。
- I_iso(A,B)：与 D597 可视为其质量衰减侧面（指标替代价值 → 以数量形式表现为低质噪声累积），但独立证据弱。
- L_meta：停留在候选层即可，不应上收为通用函数。
- G_δ：当前跨域材料不足（仅 1/3 领域强出现），无法支撑跨域强结论；依 G_δ 判定，对"是否跨域成立"这一主题尚不能收敛，触发暂缓，保持 pending 待更多领域验证。
- P_meta：暂缓。可记为 D597 的潜在扩展方向，但需至少再补 1–2 个强相关领域后再判定。

最终：**暂缓**（pending，待更多领域复现后再判定；不回填、不新建）。

## 总结

```txt
D597 量化指标替代真实价值  （跨域普遍性 pending 可由 NF-X1 三领域复现上收）
├── NF-X1 指标排名隐性分层   → D597 扩展注释（并记录三领域复现证据，辅助解除 D597 pending）
├── NF-X2 刷分博弈           → 新增函数（独立激励博弈原语，与 D597 为基底—响应关系）

```

关键边界判定：
- NF-X1 与 NF-X2 的本质区别：NF-X1 是 D597 同构下游的"社会分层后果"（与 D597 同基底、同机制、不同表现层），故归 D597 扩展；NF-X2 是主体对指标激励的"二阶博弈响应"（引入 D597 没有的独立因果原语），故独立成函数。
- NF-X3 与 D312 的本质区别：D312 是数学正反馈噪声放大（δp_max·K^k），NF-X3 是评价系统内数量指标忽视不确定性导致的低质累积；机制不同且跨域证据弱，故暂缓。
