# MF-0001~0005 补入审计记录（2026-07-08）

## 为什么补入

MF-0001~0005 是 Codespace 救援函数表中 Section 0 自举元函数（MF-0000）的 5 个内部子通道/判定器，在差异审计（codespace-rescue-two-tables-diff-audit-20260708.md）中被识别为**救援函数表独有增量**（救援 476 / 正式 612 / 重叠 471 / 救援独有 5）。复核报告（mf-0001-0005-rescue-review-20260708.md）确认：

- 正式函数表目录搜索 5 个关键词（正向自举通道/反向自举通道/正反互斥判定器/自举嵌套判定器/自举收敛判定器）**全部 0 命中**；
- D141（0190-D141-自举元函数.md）仅对自身函数做正反向收敛检查，并未以独立条目或等价命名定义这 5 个内部子通道；
- 编号无冲突、标题无冲突。

因此这 5 个是 MF-0000 的内部结构件，而非普通重复函数，具备独立结构价值，应补入 Section 0。

## 新增了哪些文件

统一函数总表/ 下新增 5 个独立条目（采用 `0000-` 前缀以归入 Section 0 内部层，不与 D/A/T 层编号撞车）：

- `统一函数总表/0000-MF-0001-正向自举通道.md`
- `统一函数总表/0000-MF-0002-反向自举通道.md`
- `统一函数总表/0000-MF-0003-正反互斥判定器.md`
- `统一函数总表/0000-MF-0004-自举嵌套判定器.md`
- `统一函数总表/0000-MF-0005-自举收敛判定器.md`

每个文件含：定位（MF-0000 内部子算子）、作用、定义、语义、与 MF-0000 关系、边界、收敛状态（internal_suboperator）。
