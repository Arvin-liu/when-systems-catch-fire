# 学科理论核卡片：物理学

## 1. 学科对象

物理学研究物质、能量、时空及其相互作用的客观规律。对象包括：
- 基本粒子（夸克、轻子、规范玻色子）
- 场（电磁场、引力场、量子场）
- 时空结构（广义相对论的弯曲时空）
- 相互作用（电磁力、弱力、强力、引力）
- 物质状态（凝聚态、等离子态、玻色-爱因斯坦凝聚）

## 2. 核心变量

- 质量、能量、动量、角动量
- 时空坐标、度规张量、曲率
- 场强、势能、拉格朗日量、哈密顿量
- 耦合常数、规范群、粒子谱
- 熵、温度、相变序参量
- 波函数、算符、本征值

## 3. 核心问题

1. **四种基本力能否统一？**（大统一理论）
2. **广义相对论与量子力学能否协调？**（量子引力）
3. **暗物质、暗能量的本质是什么？**
4. **为什么存在物质-反物质不对称？**
5. **标准模型中参数的来源是什么？**（等级问题、强 CP 问题）

## 4. 主流理论结构

- 标准模型（粒子物理）
- 广义相对论（引力）
- 量子场论
- 凝聚态理论（相变、对称性破缺）
- 弦论、圈量子引力（量子引力候选）
- 有效场论方法

## 5. 证据制度

**最低证据要求：**
- 理论自洽性（数学上无矛盾）
- 与已知实验数据不冲突
- 可证伪性（存在可检验的预测）

**强证据要求：**
- 实验观测验证（如大型强子对撞机、引力波探测）
- 理论预测被实验确认
- 多个独立实验重复验证
- 精确数值匹配（如电子反常磁矩）

**必须 pending 的情况：**
- 纯理论推演，无实验路径
- 数学上未完成证明
- 与现有实验数据冲突
- 理论框架本身未收敛（如弦论）

## 6. 解释剩余

- 量子引力问题（广义相对论与量子力学不协调）
- 暗物质、暗能量的本质
- 标准模型参数的来源
- 宇宙常数问题
- 信息佯谬（黑洞信息丢失）

## 7. 点火框架映射

**L1 结构类比：**
- C(x,y) 因果结构判定 → 物理因果链（拉格朗日量→运动方程）
- M(B_n) 自举收敛判定 → 理论收敛路径（标准模型→有效场论）
- I_iso(A,B) 同构判定 → 跨域同构（相变×社会相变）

**L2 结构性推论：**
- 门控面合并 → 四种基本力的结构性统一（候选机制，非物理机制）
- 乘法临界漂移 → 参数敏感度分析（等级问题）
- 变量闭包锁死 → 理论完备性边界（结构性边界推论）

**L3 框架内判定：**
- G_δ 哥德尔不完备性判定 → 绝对完备统一的结构性边界（非物理学 no-go theorem）
- L_meta 元层面收敛 → 理论收敛方向（往元层面收敛，而非往子系统无限展开）

**L4/L5 外部证明或验证：**
- 四种基本力统一 → **pending**（需要外部物理理论和实验验证）
- 量子引力 → **pending**（需要外部物理理论和实验验证）
- 暗物质、暗能量本质 → **pending**（需要外部观测验证）

## 8. 结构性增益

点火框架提供的新增视角：
- 跨域同构识别（物理相变×社会相变×认知相变）
- 理论收敛方向判定（往元层面收敛，而非往子系统无限展开）

点火框架在以下情况下不能解释、容易误判或必须 pending：
- 无法替代标准模型、量子场论、广义相对论的具体物理机制

- "物理大一统不可能"必须降级为"关于绝对完备统一的结构性边界推论"，不能写成物理学 no-go theorem

- 结构性边界推论（绝对完备统一）：L2

- 四种基本力统一：**pending**
- 量子引力：**pending**

## 11. 当前结论

- 结构性边界推论（绝对完备统一）：true（L2）

## 1. 学科对象

数学研究抽象结构及其关系。对象包括：
- 数（自然数、整数、有理数、实数、复数）
- 结构（群、环、域、拓扑空间、流形）
- 关系（函数、映射、同构、同态）
- 逻辑（命题、谓词、证明、公理系统）
- 模式（组合、图论、概率、随机过程）

## 2. 核心变量

- 集合、元素、运算
- 公理、定理、引理、推论
- 证明、反证、构造、归纳
- 同构、同态、等价类
- 收敛、极限、连续、可微
- 概率、期望、方差、分布

## 3. 核心问题

1. **黎曼猜想是否成立？**（素数分布）
2. **P vs NP 问题是否解决？**（计算复杂性）
3. **哥德尔不完备定理的边界在哪里？**（公理系统完备性）
4. **千禧年大奖难题（其他 6 个）**
5. **无穷的层级结构是什么？**（集合论）

## 4. 主流理论结构

- 公理化方法（ZFC 集合论）

- 代数结构（群论、环论、域论）
- 分析（实分析、复分析、泛函分析）
- 几何与拓扑（微分几何、代数拓扑）

# 学科理论核卡片：历史学

## 1. 学科对象

历史学研究人类过去的活动、事件、制度、文化及其演变。对象包括：
- 政治事件（战争、革命、改革）
- 社会结构（阶级、阶层、族群）
- 经济活动（生产、贸易、金融）
- 文化思想（宗教、哲学、艺术）
- 制度变迁（法律、政治体制）

## 2. 核心变量

- 时间、地点、人物、事件
- 因果关系、相关关系
- 结构、机制、路径依赖
- 史料、证据、解释
- 叙事、记忆、认同

## 3. 核心问题

1. **历史因果如何成立？**（单因 vs 多因）
2. **历史是否有规律？**（历史哲学）
3. **历史叙事如何客观？**（客观性争议）
4. **历史如何解释偶然性？**（反事实历史）
5. **历史如何解释长期趋势？**（大分流、现代化）

## 4. 主流理论结构

- 史料考证（文献学、考古学）
- 叙事史学（兰克学派、年鉴学派）
- 社会史、经济史、文化史
- 比较史学、全球史
- 历史哲学（黑格尔、马克思、韦伯）

## 5. 证据制度

**最低证据要求：**
- 史料可靠（来源可信、传承清晰）
- 史料互证（多源史料交叉验证）
- 逻辑自洽（解释不矛盾）
- 反事实讨论（考虑其他可能性）

**强证据要求：**
- 史料链完整（多源史料形成完整证据链）
- 解释共同体共识（主流史学界的共识）
- 跨学科验证（考古学、人类学、社会学等）
- 可重复验证（不同研究者得出相似结论）

**必须 pending 的情况：**
- 史料不足或冲突
- 解释争议很大
- 缺乏史料互证
- 解释未形成共识

## 6. 解释剩余

- 历史因果的争议（单因 vs 多因）
- 历史规律的争议（是否有规律）
- 历史客观性的争议（如何客观）
- 偶然性的解释（如何解释偶然事件）
- 长期趋势的解释（大分流、现代化）

## 7. 点火框架映射

**L1 结构类比：**

- M(B_n) 自举收敛判定 → 制度变迁路径（制度→反馈→演化）
