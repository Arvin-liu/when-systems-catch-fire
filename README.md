# 使用说明书：如何使用点火项目
### 1. 这个项目适合用来做什么
点火适合用于分析一个复杂现象为什么会发展成现在这样，分析一个系统在什么条件下会被“点燃”，也适合分析某个事件、人物、组织、技术或文化现象的演化路径。

它也适合把模糊直觉转成结构化假说，把分散材料整理成函数、案例、约束、触发条件和反馈关系，并帮助人和 AI 一起澄清“我真正想问的问题是什么”。

它更适合生成可讨论、可修改、可检验的解释框架，不等于生成最终答案。

### 2. 这个项目不适合用来做什么
点火不适合替代专业学术研究，也不适合替代法律、医疗、金融等专业判断。

它不是算命工具，不是预言工具，也不是万能公式，更不是直接证明一切结论的工具。

它不适合被用来为任何先入为主的观点强行找解释，也不适合把复杂问题压缩成一个单一答案后就停止思考。

### 3. 人类如何直接使用本项目
最直接的用法，是先用一句话写下自己想推论的问题，然后把问题中的关键对象列出来。

接着观察这些对象之间的约束、冲突、资源、激励和反馈，判断系统中是否出现了能量积累、结构临界、触发事件、路径锁定或自举循环。

然后写出一个临时假说，再主动寻找反例，根据反例修改假说，最后保留不确定的部分，而不是强行闭合。

### 4. 如何借助 AI 使用本项目
你可以把 README、AGENT_ENTRY、函数表、案例表和相关材料交给 AI，让 AI 协助你做问题澄清、变量拆解、系统边界识别、结构关系提取、点火路径建模、反例生成、竞争解释生成、最小结论总结和可检验命题生成。

AI 的作用不是替人下结论，而是帮助人拆问题、找结构、生成假说、检查反例、整理推论过程。

使用 AI 时，要明确要求它不能只顺着点火框架解释，而必须同时给出反例、限制条件和竞争解释。

### 5. 用点火框架推论一个问题的基本流程
问题输入：先把你真正想问的事写清楚，尽量只保留一个主问题。

明确对象：说明这个问题里有哪些人、事、物、组织、技术或制度对象。

确定系统边界：判断哪些因素算在系统内，哪些因素只是背景，不要一上来把所有东西都算进去。

识别约束与资源：找出限制条件、可用资源、成本、机会和结构性条件。

识别冲突与激励：看对象之间是否存在竞争、合作、信息不对称、收益不一致或反馈回路。

识别触发条件：判断系统是否存在某个临界点、外部刺激或事件，使它从潜伏状态转入明显变化。

观察是否出现自举循环：判断某个结构是否会在一次行动之后反过来增强下一次行动。

生成点火假说：把上面的观察整理成一个临时解释框架，说明它为什么会这样演化。

生成反例：主动找出这个假说解释不了的情况，避免只看支持证据。

生成竞争解释：给出至少一种不同于点火框架的解释路径，避免把单一框架当成全部真相。

收敛为临时结论：在比较多种解释之后，先得到一个足够克制、足够可用的阶段性结论。

标注不确定性：明确哪些部分证据充分，哪些部分仍然模糊，哪些地方需要继续验证。

## 适用范围

### 一、适用系统特征

**必须同时满足三个条件：**

1. **存在约束边界**
   - 系统有明确的约束条件（物理约束、制度约束、资源约束、认知约束等）
   - 约束边界可识别、可量化
   - 约束条件对系统演化有实质性影响

2. **存在优化目标**
   - 系统有明确的优化方向（能量最小化、熵最大化、效率最优化、收益最大化等）
   - 优化目标可数学化表达
   - 系统演化受优化目标驱动

3. **存在动力学演化**
   - 系统状态随时间变化
   - 演化过程受因果结构约束
   - 存在反馈机制和自调节

### 二、已验证适用领域

**1. 物理系统**
- 热力学系统（相变、临界现象）
- 量子力学系统（退相干、量子隧穿）
- 统计力学系统（自由能最小化、熵增）
- 天体物理系统（引力坍缩、黑洞形成）

**2. 社会系统**
- 文明演化（制度变迁、文明重启）
- 政策实施（政策扩散、政策失败）
- 组织演化（公司转型、组织变革）
- 社会运动（集体行动、社会革命）

**3. 认知系统**
- 学习过程（技能习得、知识更新）
- 决策过程（风险决策、博弈均衡）
- 创新扩散（技术采纳、观念传播）
- AI系统（模型训练、参数优化）

**4. 经济系统**
- 市场演化（价格发现、市场出清）
- 投资决策（资产配置、风险对冲）
- 产业升级（技术替代、产业转移）

### 三、适用案例示例

- **文明重启**：约束（资源有限、制度僵化）+ 优化（生存概率最大化）→ 点火（文明转型）
- **政策扩散**：约束（制度成本、利益格局）+ 优化（政策效果最大化）→ 点火（政策采纳）
- **技能习得**：约束（认知能力、时间资源）+ 优化（技能熟练度最大化）→ 点火（技能突破）
- **市场出清**：约束（供需关系、交易成本）+ 优化（资源配置效率最大化）→ 点火（均衡达成）

## 不适用范围

### 一、不适用系统特征

**满足以下任一条件即不适用：**

1. **纯随机过程**
   - 演化完全由随机性驱动
   - 无明确约束边界
   - 无优化目标
   - 例：布朗运动、纯随机游走

2. **纯决定论过程**
   - 演化完全由初始条件和决定论方程决定
   - 无优化动力学
   - 无反馈机制
   - 例：刚体运动、经典力学轨道

3. **无约束系统**
   - 系统演化不受约束限制
   - 无边界条件
   - 例：理想气体自由膨胀（无外场）

4. **无优化目标系统**
   - 系统演化无明确优化方向
   - 演化由外部强制力驱动
   - 例：机械运动、被动响应

### 二、不适用领域示例

**1. 纯随机领域**
- 量子随机过程（测量塌缩）
- 统计随机过程（泊松过程）
- 金融随机波动（布朗运动驱动）

**2. 纯决定论领域**

- 电磁学（麦克斯韦方程组）
- 流体力学（无湍流层流）

**3. 无优化领域**
- 机械系统（齿轮传动、杠杆原理）
- 被动系统（弹簧振子、阻尼振荡）
- 静态系统（结构力学、材料强度）

### 三、不适用案例示例

## 边界判定标准

### 判定流程

1. **识别约束边界**
   - 系统是否有明确约束条件？
   - 约束是否可量化？
   - 约束是否对演化有实质性影响？

2. **识别优化目标**
   - 系统是否有优化方向？
   - 优化目标是否可数学化表达？
   - 演化是否受优化目标驱动？

3. **识别动力学演化**
   - 系统状态是否随时间变化？
   - 演化是否受因果结构约束？
   - 是否存在反馈机制？

**三个问题全部答"是" → 适用Ψ₀**
**任一问题答"否" → 不适用Ψ₀**

- 湍流：约束（流体力学方程）+ 优化（能量耗散最小化）+ 动力学（非线性演化）→ 适用

**边界外（不适用）：**
- 层流：纯决定论过程，无优化动力学 → 不适用
- 机械记忆：被动响应，无优化目标 → 不适用
