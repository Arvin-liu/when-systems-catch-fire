# When Systems Catch Fire / 点火

> 丹无定形，火有法度；炼无终局，化有来路。

点火是一个仓库原生、版本化、可审计的跨领域研究与行动基础设施原型。它保存来源，把命题与证据、模型、证明、反例、验证和现实反馈分开记录，并允许结论在新证据出现后被修订、降级、隔离或撤回。

本仓库的结果是当前证据、计算资源、模型和方法条件下的当前最佳版本，不是自动产生外部真理的机器；编号、公式、AI 输出、内部自洽、测试通过或登记闭合都不能单独证明现实。

## 1. 点火现状

当前公开阶段是：以 Foundation、Function OS 有界基准、MCF、PSD、ARN、语言—思维逻辑平面、Evidence Program、知识体验层和公开写作为构件的持续研究与出版系统。公开结果保留 `CURRENT_WITH_OPEN_OBLIGATIONS`、`PENDING`、`QUARANTINE`、`WITHDRAWN`、`NULL` 和 `PARTIAL` 等状态，不把完成的工程动作写成科学真理。

当前尤其要记住：Foundation 的登记闭合不等于对象已证明；Function OS v0.2 只在声明的 bounded domain 内获得支持；Crossref/OpenAlex 试点是书目元数据结果；MCF/PSD/ARN 是有边界的模型和表示；历史案例、跨域因果、物理统一和语言—思维关系仍有开放义务。独立 GitHub Pages 阅读面已退出维护，持续公开权威是本仓库的 Markdown 与相对链接。

查看[当前结果](./RESULTS/LATEST.md)、[纠正与撤回](./RESULTS/CORRECTIONS.md)、[开放问题](./RESULTS/OPEN-QUESTIONS.md)和[最新变化](./KNOWLEDGE/WHATS-NEW.md)。

## 5. 完整系统架构

完整架构仍按 L0—L6 组织：来源与证据 → 受控语义命题 → 形式对象 → 逻辑论证 → 数学模型与证明 → 验证与有效性 → 解释、应用与出版。语言—思维逻辑平面横穿这些层，但不增加 L7；之元写作法位于公共表达层并接受来源、版本、证据与残余约束。

进入[Foundation 文档](./docs/foundation/README.md)、[MCF](./docs/architecture/multiscale-causal-fabric.md)、[PSD](./docs/architecture/probabilistic-system-dynamics.md)、[ARN](./docs/architecture/adaptive-relational-network.md)、[语言—思维逻辑平面](./docs/architecture/language-thought-logic-plane.md)、[自我纠错引擎](./docs/governance/self-correction-engine.md)和[Evidence Program](./evidence-program/README.md)。所有架构、状态和证据义务都可以在未来被修订、降级或撤回。
