# 点火知识入口

这里是普通读者的统一起点。你不需要知道目录、注册表或资产编号：可以先看变化、按问题探索、搜索熟悉的词，或选择 1 分钟、5 分钟与完整阅读。若只想先知道百轮运行究竟留下了什么，请从[百轮成果书架](../PUBLICATIONS/README.md)和[一页全景](../PUBLICATIONS/what-pointfire-knows-now.md)开始。

## 百轮成果出版层

- [成果书架](../PUBLICATIONS/README.md)：五份可直接阅读的出版前台成果，包含第一卷、研究笔记、全景和成果台账。
- [第一卷](../PUBLICATIONS/volumes/001-pointfire-after-one-hundred-iterations.md)：以问题、发现、纠正、失败和未知组织百轮材料，不把任务状态冒充科学结论。
- [出版审计与溯源](../data/operations/iterations/112/publication/)：保存 R0 冻结、逐项审计、三重审稿和最终验证资料。

## 四条阅读路线

- [最新变化](./WHATS-NEW.md)：按时间看新结论、新纠正、新文章、新实验和新发现。
