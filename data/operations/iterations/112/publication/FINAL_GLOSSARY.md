# 第一卷术语表

| 术语 | 本卷中的窄义 | 不应读成 |
| --- | --- | --- |
| 点火 / Pointfire | 一个把跨域观察、函数、断言、来源、工程运行和纠正放入可追踪工作流的研究系统 | 已经完成的统一科学理论 |
| 跨域相似 | 不同材料在对象、关系、时间或反馈上出现可比较的候选结构 | 严格同构、共同机制或因果 |
| claim ceiling | 一条主张根据其证据类型、范围、版本和失败条件最多能说到的高度 | 自动判真器或永久等级 |
| Foundation | 保存对象身份、来源、成熟度、证据、义务、处置和反例的研究账本 | 证明器、同行评议或现实真理库 |
| 函数 | 在本项目语境中可作为关系、评分、模型或候选规则记录的对象 | 所有条目都已定义良好、可运行或有物理意义 |
| non-function claim | 非函数型的定理、机制、因果、历史或经验断言记录 | 已经被证明的结论 |
| quarantine | 暂不让一条含混、过强或证据不足的对象进入当前公共结论的保护状态 | 结论已被证伪或永远不能研究 |
| Function OS | 在声明输入、语义和 oracle 内运行函数候选并保存失败现场的有界工程系统 | 通用解释器、生产安全平台或开放世界执行器 |
| bounded benchmark | 版本、样本、输入域、oracle 和验收规则都已声明的局部基准 | 普遍能力证明 |
| oracle | 用来判断某次运行输出是否满足预先声明的期望的独立判定机制 | 程序自己给出的自证 |
| Crossref / OpenAlex | 用于 DOI、题名、年份和书目匹配的外部元数据入口/试验 | 论文内容、机制或科学真值裁判 |
| target | 可被冻结、输入、运行并观察 trace/output 的具体程序或历史建模对象 | 一个故事、预测句或想象中的实现 |
| target absent | 当前材料中没有足够的可执行对象来开展程序复现 | 历史叙事已被证伪 |
| memoir association | 回忆材料把人物、事件和思想联系起来的有边界来源事实 | 唯一直接因果或瞬间完整理论来源 |
| null | 在声明查询、时间、来源或匹配协议内没有得到足够支持的结果 | 来源不存在、理论错误或失败已证明 |
| 百轮 | 混合的长期迭代史，其中包含研究、纠正、实验、方法、基础设施和维护 | 一百个独立实验样本 |
| 出版层 | 让人类作品、证据边界、来源和纠正可以被连续阅读与追踪的公共入口 | 自动提升结论可靠性的包装层 |
| 研究机构 | 在公共责任、独立审查、可撤回性、维护和外部反驳中持续承担责任的组织能力 | 有仓库、CI 或很多文件的项目 |
