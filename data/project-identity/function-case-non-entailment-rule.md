# Function-Case Non-Entailment Rule

中文规则：

任何函数与案例之间的关系都不得被写成双向必然蕴含。案例不能被描述为必然推出某函数；函数也不能被描述为必然指向某案例。允许的表述是：该案例启发、触发、支持、限制、反证或部分验证该函数；该函数可以解释、投影到、关联或帮助重读该案例。所有函数—案例关系必须标注为推论、候选解释、当前映射或证据关系，而非定论。

English Rule:

No relation between a function and a case may be written as a bidirectional necessary entailment. A case must not be described as necessarily deriving a function; a function must not be described as necessarily pointing to a case. Allowed expressions include: the case inspires, triggers, supports, limits, falsifies, or partially verifies the function; the function can explain, project onto, relate to, or help reinterpret the case. All function-case relations must be marked as inference, candidate explanation, current mapping, or evidence relation, not as final determination.

核心句:

函数—案例关系是推论关系，不是定论关系。
Function-case relations are inferential relations, not definitive entailments.
