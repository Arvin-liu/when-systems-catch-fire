# Project Growth Rule

This project is not a closed table but a living knowledge base. Functions, effects, cases, discoveries, predictions, new answers, and analytic solutions may continue to grow through new questions, curiosities, cases, and derivations. No Agent may treat current counts as final counts or current layers as a closed structure.

本项目不是封闭表格，而是活体知识库。函数、效应、案例、发现、预测、新答案、解析解等对象都可以因新的问题、新的好奇、新的案例、新的推导而继续增长。任何 Agent 不得把当前数量写成终局数量，也不得把当前结构写成封闭结构。
