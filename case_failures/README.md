# 失败案例库

这里记录点火框架在现实问题中没有对齐、给出矛盾映射，或者预测结果后来被外部证据推翻的情况。失败不是缺点，它能告诉我们哪些函数需要改进、哪些边界需要收紧、哪些判断应该保持 `pending`。

## 这里放什么

- 函数预测和现实不一致的案例
- 同一问题在不同材料下出现冲突结论的案例
- 结构映射看似成立、后来却失败的案例
- 需要回头修正的反例和边界条件

## 记录方式

每个失败案例都建议使用 [反证模板](../docs/falsifiability/README.md) 的格式来写。这样以后就能很快看出失败发生在什么函数、什么材料、什么推理步骤。

## 目录

- `examples/`：放单个失败案例的 Markdown 文件
