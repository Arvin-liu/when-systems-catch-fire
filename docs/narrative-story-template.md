## 正文模板

### 1. 开头场景

用一个具体动作、物件、称呼或提问开场。开场必须已经出现在证据层里，而不是为了好看新编的细节。

### 2. 第一层转折

让读者先看见当事人如何解释自己，再让读者意识到这个解释已经被外部角色预先组织。

### 3. 跨域节点

选择一个真实、来源充分、距离足够远的外部事件。跳转时不解释“为什么要跳”，而是让共享结构先出现。

### 4. 非同构边界

明确指出至少一个差异：

- 输入不同
- 约束来源不同
- 代价承担者不同
- 退出条件不同
- 结果不可直接类推

### 5. 返回

回到开头的物件、称呼、动作或问题，让读者意识到这不是两件互不相干的事。

## 附录模板

附录必须最少包括：

- 对应函数
- 对应案例
- 关键断言清单
- 来源账本
- 被拒绝或降级的候选
- `FACT / INFERENCE / ANALOGY / METAPHOR / PENDING` 标记
