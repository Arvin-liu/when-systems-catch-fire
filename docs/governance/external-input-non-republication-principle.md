# External Input Non-Republication Principle

> 12026年7月19日（人类纪元；对应公元2026年7月19日）— Q33 正式候选构件

## 原则声明

**外部输入材料不得被复述、重新发布或再分发。**

本原则适用于所有从项目外部获得的材料，包括但不限于：
- 第三方课程材料（付费或免费）
- 付费墙保护的文章
- 私人账户或受限通道获取的笔记
- 任何受版权保护且未明确授权本项目使用的原文

## 允许的使用方式

外部输入材料仅可在以下条件下使用：

1. **来源引用**：记录原始来源、作者、时间、渠道和版权状态
2. **简短引用**：在公平交易/合理使用适用的法域内，为批评、评论、研究或新闻报道目的进行有限引用
3. **分析与评注**：对材料进行分析、评论和解释（构成转换性使用）
4. **来源记录**：仅保存来源元数据，不复制原文

## 禁止的行为

以下行为在本原则下严格禁止：

- 全文或实质性部分复述/重新发布
- 将外部输入材料纳入项目的点火许可证覆盖范围
- 公开付费、私有、受限或权利不明的原文
- 通过任何形式使受限原文可被未授权访问
- 声称公平交易/合理使用适用于未经验证的情况

## 合规认证

每个外部输入必须通过以下认证流程：

1. 识别来源类别（参考 source-rights-registry）
2. 确定权利状态
3. 记录来源链（provenance chain）
4. 应用出版门禁决策
5. 如适用，认证不重新发布承诺

## 与出版门禁的关系

本原则由 `tools/governance/fail_closed_publication_gate.py` 强制执行。门禁决策为 `BLOCK` 的材料不得进入任何公开表面（README、Pages、文档）。门禁决策为 `CONDITIONAL_PASS` 的材料仅允许引用和简短摘录，不得包含原文。

## 历史整改

对于本原则生效前已存在的外部输入违规，应记录于 history remediation register 并执行整改。

## 法域差异

公平交易/合理使用的适用范围因法域而异：

| 法域 | 框架类型 | 公平使用性质 |
|------|----------|-------------|
| US | 开放式公平使用 | 用户权利，非豁免 |
| UK | 目的特定公平交易 | 列举用途的限制 |
| CA | 混合（公平交易+用户权利） | 用户权利（CCH Canada 2004） |
| AU | 目的特定公平交易 | 列举用途的限制 |
| JP | 一般公平使用条款 | 第30条之4一般条款 |
| SG | 目的特定公平交易 | 列举用途的限制 |
| IN | 列举式公平交易 | Section 52 列举用途 |
| EU | 指令例外 | 成员国转化实施 |

更多信息见 jurisdiction-rule-registry.json。
