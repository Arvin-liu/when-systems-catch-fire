## V2（黄色协议）— 全成本效率度量待验证

- 全成本效率的边界：效率提升在何种范围、何种尺度上才算“净正”，需明确边界。
- 生态、代际、社会和主体性成本如何计量：需要跨域可操作指标（经济学 / 生态 / 伦理 / 社会）。
- 成本外部化识别：如何识别并量化被转嫁给弱势成员或外部系统的代价。
- 不同时间尺度的净效率：短期提速与长期净收益的权衡函数待实证。
- 不可通约成本如何处理：生命、生态、代际、主体性成本之间不可简单相加时如何比较与决策。

## V3（黄色协议）— 可逆性度量待验证

- 可逆性度量：如何量化“可逆优先”，可逆 / 不可逆的判定阈值如何设定。
- 创新失败的停止阈值：失败反馈缺失或损害达到何种程度必须停止。
- 沙盒与现实扩散边界：小规模试验与真实扩散之间的边界如何界定与控制。
- 不可逆风险识别：何种信号表明创新已产生不可逆且不可补偿的共同体伤害。
- 未来选择空间如何测量：适应能力、问题解决能力与未来选择空间的增量如何可检验。
