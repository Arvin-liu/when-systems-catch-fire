# S3 规范性审核 - 层级协议 (Hierarchy Protocol)

> 外部治理记录 · IGNITION-20260709-043

> 审核日期：2026-07-11

## 1. 原定义

系统由层级结构组织，上下层存在控制或信息梯度。

## 2. 主要问题

- '层级'未限定权责关系，易把服从本身当成价值（歧义/滥用风险）。
- 可退化为不可问责、不可撤销、决策不可复核的权力结构（适用边界）。
- 与 S4 互补但缺少权力—责任边界（与其他协议重叠）。
- 原定义无底层申诉与退出机制（缺少停止条件）。
- 未说明层级的正当用途（应急/分工/复杂任务）与限度（歧义）。

## 3. 生命共同体价值投影

价值：责任清晰、应急协调、专业分工与大规模复杂任务，是有效组织的工具。条件：仅当权力可问责、层级可撤销、决策可复核且底层有申诉与退出机制时才有价值。伤害：当层级不可问责、不可撤销、把服从当价值或剥夺底层权利时，会伤害共同体。不可缺少的约束：权力可问责、层级可撤销、决策可复核、申诉与退出、服从非价值。

## 4. 推荐修订定义

为责任清晰、应急协调、专业分工与大规模复杂任务而组织的上下层控制/信息梯度结构；权力须可问责、层级可撤销、决策可复核，底层成员有申诉与退出机制，且不得把服从本身当成价值。

## 5. 硬约束

- 权力必须可问责
- 层级必须可撤销、可调整
- 关键决策可复核
- 底层成员有申诉与退出机制
- 服从本身不是价值
- 层级不得用于固化不可挑战的特权

## 6. 停止条件

- 层级不可问责且不可撤销
- 决策不可复核且持续伤害成员
- 底层丧失真实申诉与退出权
- 层级退化为压迫性结构

## 7. 事实 pending

- '权力可问责'的可操作指标待治理定义
- 层级 vs 网络(S4)的适用边界量化待案例验证
- 申诉/退出机制在层级中的有效性待实证
