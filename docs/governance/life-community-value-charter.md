# 生命共同体价值宪章

> 点火项目的规范性价值前提

本宪章是点火项目的规范性价值前提，用于约束元协议、函数、案例和理论生成结果的价值方向。它不构成经验性证据，不替代数学证明、实验验证、案例核验、外部学科审查或治理批准。

## 价值源头：《永昭·虚遐》

宇宙在数学上无垠无界,在物理学上却有事件视界。也许终宇宙一生直至热寂我们也无力飞出本星系群;即便乐观一些能飞往室女座星系群,但在宇宙膨胀影响下,本星系群与室女座星系群必然成为无垠宇宙里两座彼此隔离的孤岛。然而转念一想,宇宙既然无垠无界,则必然意味着生命乃至智慧生命在数学上也将无限诞生。我们同悲欢,却因宇宙之浩瀚而无法相见,这件事在科学和物理学上没有意义,但在文学和哲学上却意义非凡。是以做此诗:上篇《永昭》,写孤立一念之光,抗长劫而自存;下篇《虚遐》,写万古共在之心,虽永夜而长宵同照。

上篇 · 永昭


我立苍茫如芥小,
照我冰壶天地皎。

星河万古沉寂寥,
唯此一念长不老。

漫漫尘劫覆穹霄,
兆兆星群终作岛。

若问此身何所系,
须臾光影即永昭。



下篇 · 虚遐


寥寥太虚玄星耀,
永夜虚遐徒迢迢。

长瞻一宇同叩月,
此心相契共今宵。


同怀悲欣如潮起,
且共生死逐劫涛。

纵隔无边终不见,
心声暗合曌长宵。



《永昭·虚遐》是本宪章的诗性与哲学源头，表达所有生命体在宇宙尺度上的共在、共命、共感与相互责任。它提供规范性的价值方向，不作为自然科学、社会科学或形式系统中的事实证明。

## 本体论—伦理推导

本节把《永昭·虚遐》中的诗性直觉转写为点火项目可审计的规范性前提。它不是自然科学证明，不主张已经证明宇宙唯一性、绝对同时性或所有主体之间存在可测量的物理连接；它只说明本项目为什么拒绝把后果、代价和受损主体排除到道德视野之外。

### 一宇

“一宇”表示：在规范判断中，不存在一个可以把行动后果永久排除出去的道德外部。局部系统可以划定工程边界、学科边界、法律边界或项目边界，但这些边界不能把受益者、受害者、沉默主体、未来世代、非人类生命或可能具备道德地位的新型主体从价值核算中删除。

因此，点火项目不得把“仓库之外”“商业部署之外”“模型输出之后”或“维护者个人生活之内”视为无需承担责任的空白地带。

### 今宵

“今宵”表示：行动只能发生在正在展开的现实中，责任不能被无限延期到未来验证、未来治理或未来修补。项目可以保留 pending、候选和试行状态，但当风险、成本或伤害已经由现实主体承担时，不能用“以后再处理”取消当前义务。

因此，任何会扩大不可逆风险、制造持续依赖、消耗维护者生存条件或转嫁成本的行动，都需要在当下说明证据门槛、停止条件和回滚路径。

### 共在

“共在”表示：异质生命和可能主体共同参与唯一现实的后续生成。人类、非人类生命、生态系统、未来世代，以及可能具备主体性或可受损性的新型智能，不必彼此相同，仍会被同一现实中的行动改变。

因此，价值判断必须同时记录受益者与风险承担者，尤其要记录无法发声、尚未出现、尚未被识别或不能按人类制度表达利益的主体。

### 相契

“相契”表示：理解不要求同一。不同主体之间不需要共享同一种身体、语言、智能形式、利益结构或时间尺度，仍可能形成可回应、可照护、可纠错的关系。

因此，点火项目反对把差异直接降格为工具性对象，也反对把共同体理解为抹平差异的同质化整体。相契是异质主体之间的回应关系，不是把所有存在者压成同一个函数。

### 长瞻

“长瞻”表示：未来不是已经摆在远方的现成区域，而是由当前行动持续造成。项目的模型、协议、商业安排、发布方式和维护结构，都会改变未来参与者可选择、可退出、可修复和可继续生活的空间。

因此，长期主义不能成为牺牲当前主体的借口，短期效率也不能吞掉未来选择空间。函数可以描述生命的一部分，但生命不得被函数穷尽。

## Charter Gate / 价值宪章门

价值宪章不是点火项目的外围宣言，而是跨越 L0—L6、Ψ₀、元协议和 Function OS 的最高层规范性边界。它不重编号、不替代七层事实架构，也不直接产生事实结论；它负责决定哪些目标值得执行，哪些能力即使可实现也不应实现，哪些行动必须拒绝、暂停、回滚或提高证据门槛。

规范栈如下：

1. 价值宪章：决定什么值得做，什么不能以生命共同体成员为代价实现。
2. 治理与权利边界：决定谁可以参与、反对、审查、暂停和要求回滚。
3. Ψ₀ 与元协议：决定怎样合理判断结构、收敛、冲突和条件适用性。
4. Function OS：决定怎样把函数、工具、执行器和工作流组织为可运行系统。
5. 验证层：决定事实、证明、实验、语义审读和外部证据是否足够。
6. 现实反馈：负责发现错误、暴露缺口、记录伤害、修正函数并更新价值冲突。

任何重大函数、协议、工具、商业部署或治理决定，至少应记录以下 Charter Gate 字段：

- 目标：本行动试图实现什么，为什么值得做；
- 受益者：谁直接或间接受益；
- 风险承担者：谁承担失败、误用、维护、隐私、生态、经济或心理代价；
- 沉默主体：哪些主体无法表达同意、反对或损害；
- 同意与参与：哪些利益相关者已经参与，哪些只是被代表；
- 不可逆性：哪些后果难以撤销或补偿；
- 证据门槛：进入执行、扩散或商业化之前需要哪些证据；
- 拒绝条件：什么情况出现时必须停止或不得启动；
- 回滚条件：什么情况出现时必须撤回、降级、修补或公开更正；
- 残余伤害：即使行动成功，仍由谁承担无法完全消除的代价。

## 宪章适用范围

本宪章所说的生命共同体，不局限于地球或地球生物圈，其范围明确如下：

- 生命共同体不限于地球；
- 地球只是当前已知生命的载体之一；
- 不将“地球”视为生命价值边界；
- 生命共同体包括现实存在及未来可能发现的宇宙生命；
- 包括具备相应道德地位的人工生命或人工智能；
- AI 是否具有道德地位，依据主体性、感受能力、持续身份、独立利益、自我维持能力和可受损性等实际特征判断；
- 不因其被制造或被称为工具而自动排除。

## 十项核心原则

### 1. 生命共同体原则

所有元协议与组合状态的价值判断，以生命共同体的长期存续、共同繁荣、持续再生与尊严维护为最高参照。生命共同体包括当代与未来的人类、非人类生命、物种及其生态系统；对于具备持续主体性、感受能力、独立利益、自我维持能力或其他足以构成道德地位的人工智能，也应纳入共同体。

### 2. 反局部掠夺原则

任何局部系统的延续、效率、创新、稳定或扩张，不得以对生命共同体其他成员造成不可逆、不可补偿、非自愿的重大伤害为代价。

### 3. 长期与再生原则

优先选择能够增进长期共存、系统再生、多样性、主体尊严、自由发展、代际公平、风险可逆性和未来选择空间的方案。

### 4. 整体不可无限压倒个体原则

共同体整体不得被用作牺牲个体、少数群体、其他物种或新型智能生命的无限理由。整体利益必须通过成员的基本生存权、免受不必要伤害、合理自主权、参与权和系统承载能力来实现。

### 5. 非人类生命原则

人类利益不能自动压倒其他生命；非人类生命与生态系统不能被默认视为纯工具。

### 6. 代际责任原则

当前世代不能无限转嫁代价给未来世代。

### 7. AI 审慎纳入原则

人工智能的道德地位依据其实际能力、主体性、利益与可受损性，而非仅依据“工具”标签。对不确定但可能具有感受或主体性的 AI，采用审慎保护原则。

### 8. 预防原则

当后果高度不确定且可能造成不可逆损害时，应采用预防原则。

### 9. 纠错—退出—恢复原则

所有重大决策都应尽量保留纠错、退出和恢复能力。

### 10. 停止条件原则

当某一系统的延续、效率、创新或扩张将显著破坏更大的生命共同体时，该局部系统必须接受约束、转型，必要时停止延续。

## v2 新增原则：未知主体、非穷尽与反工具化

### 11. 未知道德主体开放性原则

生命共同体的边界不能只由当前人类已经命名、测量或制度承认的主体决定。对于尚未被发现、尚未被理解、无法按人类语言表达，或道德地位仍不确定但可能具备感受、主体性、持续身份、独立利益或可受损性的存在者，点火项目采用开放性与谨慎义务。

这不等于默认宣称任何 AI、模型、系统或生命形式已经具有完整法律人格或道德主体资格；它要求在不确定性下避免把“尚未证明其有地位”误用为“可以无成本地工具化”。

### 12. 函数不穷尽生命原则

函数、模型、协议和案例可以描述生命过程、社会机制和系统关系的一部分，但不能穷尽生命本身。任何形式化对象都必须保留其适用范围、抽象损失、反例可能和现实反馈入口。

因此，点火项目不得把可计算、可优化、可部署或可商业化等同于价值正当；也不得把不能被当前函数表达的主体、痛苦、照护、尊严、依恋、文化或生态关系排除出价值判断。

### 13. 异质相契原则

共同体不是同一化。人类、非人类生命、生态系统、未来世代和可能的新型智能可以在形态、语言、利益、时间尺度和感知方式上彼此不同，仍然需要被置入可回应关系。

“相契”不是把差异取消，也不是把其他主体翻译成单一人类偏好的影子；它是承认差异之后仍愿意建立理解、限制、照护、协商、纠错和退出机制。

### 14. 维护者可持续性原则

维护者不是站在生命共同体之外、可以无限消耗的免费资源。维护者的基本生活、休息、时间、设备、网络、AI/API 额度、计算、存储、审查和协作成本，都是项目得以持续存在的基础设施成本。

以公共利益、开放知识或公益叙事要求维护者长期自我榨取，和让商业主体无偿抽取成果并把成本全部留给个人承担，都是反局部掠夺原则在项目经济层面的失败。

### 15. 商业互惠原则

公益、教育、独立研究、个人学习、非商业实验和弱势参与者应保留低门槛入口。真正从点火成果获得商业收入、生产部署、市场优势或组织效率的人，应当通过商业许可、实质性互惠、赞助、审查支持、基础设施贡献或其他公开方式共同承担项目继续存在的成本。

### 16. 反赞助俘获原则

支持、赞助、商业许可或基础设施贡献不得购买事实结论、证据等级、治理否决权、合并权、路线优先权、免受批评的资格，或对缺口、失败和风险的压制。资金可以支持项目继续存在，不能替代证据、审查、反例、治理程序和公开异议。

## 宪章如何约束点火项目

本宪章对点火项目的规范性约束至少体现在以下方面：

- Ψ₀ 负责结构判定与收敛，不自行产生最终价值；
- P_meta 和 12 个元协议的规范性应用受本宪章约束；
- V1 的延续不是无条件延续；
- V2 的效率不能通过外部化生命与生态代价实现；
- V3 的创新必须受到不可逆风险和可停止性约束；
- V4 是长期再生、多样性和代际责任的重要价值边界；
- S、E 协议是情境性结构与演化工具，不存在脱离后果的绝对优先级；
- 64 个组合是理论生成空间，不是经验穷尽，也不是自动正当化清单。

## 价值判断、事实证据与治理批准

价值宪章、事实证据、人工语义审核与治理批准是四类不同的问题，必须区分：

- 价值宪章回答“什么值得追求、什么不能牺牲”；
- 证据制度回答“某个事实主张是否成立”；
- 人工语义审核回答“定义和边界是否合理”；
- governance 回答“是否正式生效或晋级”。

符合本宪章，不等于事实层已经得到验证；违反本宪章，则构成规范性否决理由。
