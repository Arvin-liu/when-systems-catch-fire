# 点火故事输出层 v0.1

## 目标

把已经通过点火证据制度的函数、案例与碰撞结果，转换成普通读者可以读懂、但又不会越过事实边界的故事产物。

这不是宣传层，也不是把漂亮类比反向当成证据的捷径。它是一层受审计约束的表达层。

## 双层结构

### 1. 证据层

证据层保存故事背后不能丢失的事实约束：

- `assertion_id`
- `claim_type`
- `assertion_text`
- `source_id`
- `source_locator`
- `assertion_level`
- `time_people_org_event`
- `mapped_variables`
- `non_isomorphic_limits`
- `counterexample_or_boundary`
- `can_enter_body`

### 2. 叙事层

叙事层保存读者实际读到的组织方式：

- `scene`
- `viewpoint`
- `mental_layer`
- `jump_hinge`
- `cross_domain_node`
- `return_node`
- `reader_frame_shift`
- `hidden_function_map`

## 硬规则

1. 故事可以重排事实出现顺序，但不得改写事实。
2. 可以隐藏结构标签，但不得隐藏证据边界。
3. 正文可以省略 D 编号、公式与内部术语，但附录必须能追溯回来。
4. `FACT`、`INFERENCE`、`ANALOGY`、`METAPHOR`、`PENDING` 必须可区分。
5. 至少写出一个失配点，证明不是为故事强配同构。

## 输出门槛

### 事实门

- 关键年份、人物、组织、动作可回到可靠来源。
- 不编造引语、动机或单线因果。

### 同构门

- 至少映射输入、机制、状态变化、输出、边界。
- 关键词重合不能单独构成同构。

### 反例门

- 至少有一个看似相似但被降级或拒绝的候选。

### 层级门

- 正文至少形成 5 层心智或尺度嵌套。
- 不把层级编号写进正文。

### 跳转门

- 跨域跳转必须依靠共享意象、动作、变量、句法回声或因果铰链。
- 禁止机械句式，例如“这让我想到”。

### 审计门

- 每个关键段落都能映射回 ledger 中的断言、来源和函数边界。

## 建议的隐藏层级模型

- `L1` 一个具体动作、物件或场景
- `L2` 当事人如何解释自己
- `L3` 他人如何用角色解释当事人
- `L4` 制度或组织如何塑造选择
- `L5` 跳到另一领域的真实事件
- `L6` 两个事件在同一结构中重叠
- `L7` 返回开头并改变读者对自己处境的解释

## 适用范围

当前 v0.1 适用于：

- 已完成函数 / 案例碰撞的公开表达
- 读者导向的故事样稿
- 书单和缺口地图的叙事化导语

当前 v0.1 不适用于：

- 把单材料直觉直接升格为故事结论
- 把 pending 普遍性写成已证实规律
- 把规范性价值判断写成经验定律
