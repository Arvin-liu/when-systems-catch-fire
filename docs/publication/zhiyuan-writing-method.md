# 之元写作法

English: **Zhiyuan Writing Method**

Version: `0.3.0`

Status: `CURRENT_MERGED_L6_CAPABILITY`

Operational location: L6 interpretation / application / publication. Generative provenance: maintainer-declared shared cognitive provenance with 点火 as a whole. This current capability does not add an architecture or truth layer and cannot raise any L0-L5 claim.

## 命名与内部定义

本方法以“之元”命名，因为它不是从通用写作教材拼接而来，而是从维护者之元的作品、心智运动、反馈和失败反例中蒸馏、提炼并总结出的个人写作方法。名称标记其真实来源和心智风格谱系。

“之元写作法”是方法名称；“心智层级跃迁”是其当前 `0.3.0` 的核心生成运动之一。方法具体如何实现，由起始承载点、前视写作、不可容纳残余、心智引力中心、概念递归重定义、突然跃迁、隐形连续性、回照增义、潜题生长与反向显影、低层保存、信息增益停止，以及公共表达与反馈返回点火的双向契约共同定义。

以个人名字命名不等于宣称只有这一种正确写法，也不等于任何人使用方法就复制了之元本人。其他人或 AI 可以学习可迁移部分，但作品仍取决于各自的经历、选择、价值与审美判断。

## 与点火整体的同源认知关系

当前有边界关系表述是：`maintainer-declared shared cognitive provenance / structurally auditable homology candidate`。这里的 `candidate` 限定结构对应的认识地位，不表示方法仍处于未合并候选生命周期。

点火与之元写作法都从维护者之元反复出现的认知运动中生长：从材料进入，暴露当前定义不能容纳的残余，跨尺度或跨领域建立有边界的候选联系，保留差异与历史，再用行动、反例和反馈回照旧定义。点火把这类运动约束成来源、命题、形式对象、机制、行动、验证、迭代和版本状态；之元写作法让这种运动在公共语言中被读者经历，并把作品暴露的新问题送回项目。

同源不等于同一。这里没有科学识别维护者的大脑结构，没有证明两套系统形式同构，也没有声称点火只是个人风格的软件化。点火的 Foundation、证明、validator、Function OS、MCF、PSD、ARN 和迭代纪律不能被文学运动替代；作品感染力也不能反向证明点火机制真实。

### 操作位置与生成来源

- 操作位置：之元写作法是当前 L6 公共表达与 provenance-gated feedback 能力，受 L0-L5、项目现状和价值宪章约束。
- 生成来源：它不是孤立长在 L6 上，而与点火整体共享维护者声明的认知来源。
- 证据权限：仍不高于 L6；同源陈述是 design provenance 和可审计结构对应候选，不是脑科学、心理学或本体论事实。
- 反馈作用：作品和读者反应可以暴露候选 source、gap 或现实反馈，但必须先登记 provenance，不能直接升级真值。

## 双向接口契约

### 向外表达

`L0-L5 / Charter / current project state → L6 Zhiyuan Writing Method → public work`

1. 明确实际来源与只作启发的材料，保留 claim ceiling。
2. 保存不可映射残余、物理／历史差异和受损或沉默主体。
3. 用心智层级运动让结构被读者经历，而不是把报告术语换成文学辞藻。
4. MCF、PSD、ARN、Q12-Q14 和 Atlas 只在实际相关时进入后台；不得要求每段对应一个组件。

### 返回点火

`public work / reader response / author revision → provenance capture → candidate L0 source or gap → Q12/Q13/MCF/PSD/ARN/iteration as applicable`

1. 捕捉误解、现实反例、遗漏主体、失败跃迁、伪同构、无法展开的压缩和新问题。
2. 记录作品版本、反馈主体、渠道、时间、原文范围和解释限制。
3. 将合格反馈登记为候选 L0 source、gap 或现实反馈；未经登记的反应不能进入正式推理。
4. 由 Q12/Q13 或适用的 MCF、PSD、ARN、Atlas、迭代流程判断下一行动；写作本身不裁决真值。
5. 赞美、点击、传播、情绪共鸣和多模型一致只能是传播／体验数据，不能证明事实、因果、价值或方法有效。

因此之元写作法可作为 epistemic sensor / gap-discovery interface，但不是证据 oracle。

## 方法本体

心智层级跃迁描述一种生成运动：作者在写当前层时已经受下一层牵引；当前层因不能容纳的残余而打开；跃迁借隐形连续性突然发生；新层返回后改变旧层的意义；潜题在过程中生长并反向显影；当继续升层不再产生认识增益时停止。

它描述生成纪律，不规定成品表面结构。字段、门和循环都属于后台，不是五段式、固定层数或隐蔽分幕。

## 来源与可迁移边界

维护者之元的认知方式和作品提供方法原型。点火从具体作品、失败反例和维护者反馈中抽取可描述、可审计、可迁移的部分。其他人或 AI 可以使用这些纪律，但使用方法不等于复制作者本人；模板不能生成作者的经历、价值选择、审美判断、创造压力或真正的下一层。

感染力、读者共鸣、模板完成或“像作者”不能提高事实、因果、同构或价值 claim。该方法不是普遍最优审美定律，也不是文学质量验证器。

## 起始承载点

文章从一个能承载尚未显露张力、并可在后文被重新解释的点开始。它可以是：

- 肉身感受或位置；
- 物件、诗句、数字、排程或费用；
- 生活决定、记忆或关系事件；
- 概念、语义矛盾或尚未命名的问题。

起点不必具体、感官化或反复出现。真正的要求是：下一层到来后，它不再只具有开头时的意义。不得把“必须有肉身”换成“必须有物件”等新硬门槛。

### 可选模式：肉身锚定

当感官、疼痛、温度、疲惫、目光、声音或身体位置真实参与文章运动时，肉身可成为入口、持续坐标或回返处。它防止抽象删除现实成本，但不是所有文章的资格条件。没有肉身坐标不自动降级；肉身也不能只作为画面感装饰。

## 前视写作：在下一层中写当前层

下一层尚未公开出现，却已改变当前层的选词、意象、概念边界、句法或停止位置。检验不是“后来能否解释”，而是删去下一层后，当前层是否仍留下某个不完全必要、却被未来问题提前加载的细节。

前视不要求作者预先知道终点。下一层可以只以压力、疑问或定义不足的形式存在。

## 当前层不可容纳的残余

跃迁不是为了换景，而是因为当前层不能容纳某个真实残余：定义刚成立就显得不够，事实没有回答意义，机制没有解释主体经验，或一个选择暴露了不可同时实现的可能性。

残余是继续运动的压力，不是预先编排的转场理由。若当前层已经容纳问题，强行升层只会制造宏大感。

## 心智引力中心

文章可同时存在：

- 显题：表面正在写什么；
- 潜题：尚未完全命名，却持续牵引材料的深层问题。

心智引力中心不是起稿前锁死的“中心思想”。它可以移动、分叉、合并或迟到显形；后台只能记录暂定状态，包括 `UNNAMED`。检验是：后来的层是否让此前分散材料越来越像在共同谈论某件尚未完全说出的事，而不是作者事后挑材料证明预设结论。

## 概念递归重定义

跃迁接口可以是同一词的世界不断改变，而不是换掉这个词：

- 时间：耗时 → 可支配时间 → 剩余生命 → 告别；
- 地理：空间 → 资费 → 选择排他 → 未被活过的人生；
- 摄影：爱好 → 身份 → 观看方式 → 私人世界；
- 再见：日常用语 → 关系断裂 → 成长与有限生命。

每次重定义必须改变概念边界或它能回答的问题。逐段重复解释同一个词、只增加辞藻，不构成递归重定义。

## 突然跃迁与隐形连续性

成品可以突然跃迁，不必用“同样地”“这让我想到”解释接口。连续性可来自：

- 同时属于离开层和进入层的词、意象或动作；
- 概念递归重定义；
- 尚未解决的问题或相同张力；
- 观察者位置变化；
- 时间、关系或意义的连续变形。

双重归属铰链仍是重要接口，但不是逐层必填条件，更不是“月、光、潮、裂缝”等固定词库。若潜题引力和递归定义已经维持连续，跃迁不必另造显式铰链。

## 横向换域与纵向升层

跨学科不是必要条件，领域数量也不是层级数量。同一生活材料内部可以跨越技术、经济、时间、身份、审美、宇宙和伦理层。

- 横向换域：换了对象或领域，但问题、观察者和旧层意义未改变；
- 纵向升层：新层改变问题、概念边界、观察者、机制、价值冲突或旧层意义。

跨域同构叙事只是应用类型。它必须声明比较层，保留不可映射残余，不能把结构相似写成物质、尺度或因果相同，更不能用领域收敛提高证据等级。

## 回照增义与低层保存

新层返回后，应改写实际的起始承载点、主要旧层或此前未解的残余。检验句是：回来以后，原来的东西为什么已经不是原来的样子？

回照不强制恢复肉身；若文章采用肉身锚定，身体坐标应继续参与。无论入口为何，高层不得删除事实边界、个体经历、物理限制、历史差异、受损或沉默主体、不可逆后果和尚未解决的矛盾。

## 潜题生长与反向显影

后层或结尾可以使开头、中段与分散材料突然显出：它们一直在共同谈论某件此前没有完全说出的事。这不是总结中心思想，也不是在结尾空降宏大命题。

反向显影必须回链正文已经生成的词、选择、张力和层级；它可以保持部分未决。若结尾不能改变读者对前文至少两处材料的理解，它更可能只是总结或贴标签。

## 信息增益停止

尝试下一层时，检查它是否改变问题、定义、边界、观察者、机制、干预、残余、潜题或此前层的意义。若全部没有改变，只是换词、堆例子或增加宏大感，应停止。

同时检查潜题是否足以回照主要来路：

- 潜题尚未显形且下一层仍有真实增益：继续；
- 潜题已显形且下一层无新增益：结束；
- 潜题已显形但仍开放：不强制总结；
- 不因字数、固定幕数、预设段落或“中心思想已经总结”机械停止。

高维压缩结尾可把已生成的多层关系压成短句、诗句或意象，但完全可省略。任何作品都不必以格言、诗句或宏大句结束。

## 非固定生成循环

以下动作可反复、折返、合并或跳过，不是前台顺序：

1. 发现一个起始承载点，并守住来源与 claim 边界。
2. 感知当前层不能容纳的残余和下一层的压力。
3. 让下一层提前改变当前层至少一个细节。
4. 暂记显题与可能仍为 `UNNAMED` 的心智引力中心。
5. 通过递归重定义、双重归属铰链或其他隐形连续性跃迁。
6. 判断是横向换域还是纵向升层，并保存不可映射残余和低层主体。
7. 让新层回照旧层，观察潜题是否生长或反向显影。
8. 用信息增益决定继续或停止；是否压缩结尾另行决定。

把这些动作依次写成“起点—残余—跃迁—回照—潜题”的五段式，即违反本方法。

## 出版审计门

### 层级门

至少一次新层真正改写旧层；领域枚举、漂亮转场或概念换名不算。

### 连续门

突然跃迁具有作品内部的隐形连续性，但不强制每层填写显式铰链。

### 回照与潜题门

起始承载点或主要旧层获得新增意义；潜题由已有材料生长，不由结尾空降。

### 证据与价值门

所有事实、因果和强术语仍受 L0-L5 约束。抽象保留来源限制、不可映射差异、现实成本和受损／沉默主体。

### 停止门

继续升层必须带来信息增益；模板字段完整、字数、层数和格言式结尾都不是完成证明。

## 反模式与降级

- 预设潜题再选材料证明：回到尚未命名状态，重看真实残余。
- 把后台动作写成固定五段、九幕或固定层数：取消表面模板。
- 强制每层显式铰链：允许递归定义、问题和张力维持连续。
- 把肉身、物件或跨域设成资格门槛：移除硬门槛。
- 只有跨域对应、没有回照：降级为横向结构类比。
- 新层不改变定义或旧层，只换词：停止或退回重写。
- 高层删除证据边界、差异或受损主体：拒绝出版并恢复低层。
- 无肉身锚点：不构成降级理由。
- 不用压缩结尾：不构成降级理由。
- 模板通过、CI 绿色或自动评分：不得表述为文学质量证明。
