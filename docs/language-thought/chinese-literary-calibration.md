# 中文思想组织与文学校准

Version: `0.1.0`

## 作家不是语法

中文配置依次接受三类校准：描述语法与类型学提供结构边界；普通母语使用说明通常怎样成句；文学作品展示优秀作者如何使用、拉伸或有意违反默认。第三类不能覆盖前两类，也不能成为作者克隆训练集。

本轮不提交大型版权语料，不复刻具体句子，不把某位作者的可识别指纹变成生成目标。以下只是阅读时要观察的机制压力；真正成品仍由文章自己的材料、作者位置和 claim 边界决定。

## 多谱系校准组

| 校准对象 | 只提取的机制 | 防止哪种误判 |
|---|---|---|
| 汪曾祺 | 松弛的语序、自然省略、口语与书面之间的呼吸、具体事物先落地 | 把所有思想都搭成抽象主语 + 多层从句；也防止把“简净”机械化成短句模板。 |
| 鲁迅 | 有意的拗峭、断裂、反讽压力和视角碰撞 | 把一切不顺滑都当错误；文学反常可能是思想必须承受的阻力。 |
| 老舍 | 说话人口吻、社会位置、城市语汇与可听见的节奏 | 只检查书面规范而删掉人物和社会关系。 |
| 沈从文 | 叙事视点、景物与行动的缓慢接合、地方经验 | 把具体生活过快概念化，或让抽象结论遮住观察位置。 |
| 朱自清 | 层次清楚的长短句调度、抒情与说明之间的转移 | 把长句等同翻译腔，把短句等同自然。 |
| 孙犁 | 节制、留白、物与人的轻接触 | 误以为每个逻辑关系都必须显式写出。 |
| 阿城 | 压缩、口语和古典资源之间的张力 | 把短句做成幼稚口号，或把省略当信息缺失。 |
| 史铁生 | 能容纳反思转折的长句、身体经验与抽象问题同在 | 用“去从句化”抹掉思想展开，或以抽象取消现实处境。 |

这些标签本身也不是作者全集的定义。每位作者会跨语体、时期和作品改变写法；校准组只用来证明“自然中文有多种合法实现”。

## 中文出版人工门

审稿者按全文语境回答：

1. 事情是否先在句子里发生，还是一开始就被抽象解释压住？
2. 话题、主语和视角是否自然延续？省略的参与者能否被唯一或诚实地恢复？
3. `了、着、过、在`、时间词、完成和终点是否彼此一致？
4. `因此、然而、其实、意味着` 等是否来自真实论证关系，而非模型的段落胶水？
5. 被动、名词化、多层 `的` 和抽象主体是否隐藏了行为者或只是在模拟学术感？
6. 朗读时，停顿是否落在意思的关节？长句能否保持视角，短句是否只制造假力量？
7. 反常结构带来了什么可说明的收益：压力、速度、歧义、视角、声音还是回响？若没有，退回重新成句。
8. 修订是否正在把作品统一成某位作家的样子？若是，停止并恢复作者自己的声音。

## 三档处置

- **硬缺陷：** 指称、体貌、连接、施事或句法关系改变意思；拒绝出版直到修复。
- **强自然度警报：** 意思可分析但没有沿目标中文自然展开；要求上下文重写和朗读复核。
- **可选建议：** 多种中文实现都成立，仅涉及节奏或风格；作者有最终选择。

有意标记句法不因“反常”自动失败，但必须通过收益说明；通过也不会提高事实 claim ceiling。
