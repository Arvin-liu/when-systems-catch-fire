# 现代土耳其语对照配置

## 为什么选择土耳其语

土耳其语把本项目带到中文、英文和日语组合仍覆盖不足的区域：高度黏着的形态链、窄范围 SOV 基本语序、受信息结构约束的灵活语序，以及与时制／体貌系统紧密结合的直接／间接信息表达。它特别压力测试 D03、D04、D08 和 D10。

结构骨架参考 Göksel & Kerslake, *Turkish: A Comprehensive Grammar*（第 2 版，2025）、Johanson 关于 Turkic evidentiality 的综述，以及 WALS 有边界条目。当前配置没有经过本轮土耳其语母语成品出版，因此保持 preliminary。

## 十二维试点

| 维度 | 配置摘要 | 未决边界 |
|---|---|---|
| 话题／主语／焦点 | 基本 SOV；语序变化受话题、焦点、韵律和语篇约束，前动词位置常与焦点相关。 | “灵活”不等于任意；具体语境须母语判断。 |
| 行为者／责任 | 格标记、语态与动词形态组织参与者；主语人称可由动词恢复。 | 省略恢复与责任归属不可仅凭词序判断。 |
| 时制／体貌／终点 | 丰富后缀组合编码时制、体貌和情态，词汇体与语境仍参与。 | 形态切分准确不等于事件解释唯一。 |
| 证据／情态 | `-miş` 系列可表达间接／推断／获知等范围，`-di` 等形成对照，但具体语义随语境。 | 不把 `-miş` 简化成单一“传闻”，也不据形态判事实真伪。 |
| 省略／指称链 | 动词一致和语境允许论元／代词省略。 | 转入英语时强补主体可能消除歧义或制造承担者。 |
| 分句连接 | 非限定动词、后缀化从属和连接词可建立复杂关系。 | 拆成英语有限从句时可能抬高某分句断言地位。 |
| 事件词汇化 | 动词、格、派生与复合表达路径、使役、结果。 | 当前试点不主张一般认知后果。 |
| 信息顺序 | 基本 SOV 与话题初始、前动词焦点等倾向互动。 | 不把线性位置机械对应 given/new。 |
| 社会视角／立场 | 称谓、礼貌策略、情态和人称选择表达立场；没有日语式同构敬语系统。 | 社会意义受场景和社群变化。 |
| 分类／词汇粒度 | 黏着派生可在一个词中组合多层语法信息。 | 翻成多词结构时必须保留形态作用与残余。 |
| 节奏／标点／呼吸 | 形态长度、从属链、焦点与韵律共同组织句子。 | 本轮无充分口语／文学样本，保留专家审校。 |
| 语体／文学标记 | 正式书面、日常口语、地区变体和文学写法差异显著。 | 当前只覆盖现代标准书面语风险识别。 |

## 主要转换风险

最严重的风险不是词序，而是把一个词形中的时制、体貌、证据来源、人称和语态拆散后遗漏其中一项。`-miş` 不能一律译成 `据说`，也不能无声变成英语或中文的确定直陈。为英语显式主语而补人时，必须说明这个参与者来自形态、语境还是译者选择。

## 试点裁定

本配置足以作为维度压力测试和结构化 fixture 来源，不足以自动批准土耳其语公共成品。正式成品需要母语／专业审校，并对形态分析、语序焦点和 evidential 语境逐项确认。
