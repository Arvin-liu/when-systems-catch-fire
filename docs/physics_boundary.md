# 点火框架与物理学问题的边界

## 核心定位

点火框架不是物理学理论，不替代标准模型、广义相对论、量子场论、粒子物理或宇宙学。

它能做的是：在结构层面分析物理理论中的统一、门控、耦合、相变、收敛、约束和存在性条件。

它不能直接给出：

- 统一规范群；
- 拉格朗日量；
- 哈密顿量；
- 具体粒子谱；
- 耦合常数数值；
- RG 流精确结果；
- 实验可测数值；
- 替代标准模型的完整理论。

## 关于“物理大一统不可能”

点火框架中的“不可能”不应被表述为“物理学已经证明大一统不可能”。

更准确的说法是：

> 点火框架提出了关于复杂系统内部不可完备性的结构性推论：任何足够复杂的统一体系都可能受限于自身公理边界、观测边界或门控边界，因此“绝对完备的大一统”应被视为待定义、待限制、待验证的命题。

如果要把它升级为数学定理，必须明确：

1. 模型类是什么；
2. 假设条件是什么；
3. “统一”被定义为什么；
4. “不可能”指哪种不可能；
5. 是否覆盖已知 no-go 定理之外的情况；
6. 是否存在反例模型。

## 关于“四种基本力统一”

点火框架可以将基本力统一描述为“门控面在高能尺度上的合并”。

但这不是粒子物理意义上的四力统一理论。

要成为物理学意义上的统一候选理论，至少需要给出：

1. 统一规范群；
2. 场内容与表示；
3. 对称性破缺链；
4. 低能极限如何恢复标准模型与广义相对论；
5. 耦合常数的 RG 流；
6. 异常消除；
7. 质子衰变、LHC、宇宙学或其他实验约束；
8. 可检验的新预言。

在这些条件满足前，项目中的“四力统一”应表述为：

> 四种基本力统一的结构性机制候选：门控面合并。

而不是：

> 四种基本力已经被点火框架统一。

## 关于“七团乌云”

点火框架中的“七团乌云”应被明确为项目自定义的跨域同构瓶颈，而不是物理学史或现代物理中公认的固定问题列表。

如果要继续使用这个说法，需要创建明确清单：

1. 每一团乌云是什么；
2. 它对应哪个学科问题；
3. 主流定义是什么；
4. 点火框架给出的结构性解释是什么；
5. 哪些证据支持；
6. 哪些条件下失败；
7. 当前状态是 `true / false / contradiction / pending` 中的哪一种。

## 推荐表述

推荐使用：

- “结构性推论”
- “候选机制”
- “框架内判定”
- “待验证命题”
- `pending`
- “门控面合并机制”
- “跨域同构瓶颈”

避免使用：

- “已经证明”
- “已经解决”
- “已经统一四种力”
- “物理学大一统已被否定”
- “现代物理七大难题已解决”
