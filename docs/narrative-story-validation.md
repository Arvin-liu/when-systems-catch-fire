# 点火故事验收清单 v0.1

## 结构验收

- 有正文、source ledger、structure map、validation report 四件套
- frontmatter 字段完整
- 关键段落都能回到 `assertion_id`

## 事实验收

- 关键事实都有 `source_id`
- 来源定位可读
- 不存在伪造引语
- 不存在把争议历史压扁成单线因果

## 认识论验收

- `FACT` 和 `ANALOGY` 没有混写
- `PENDING` 没有伪装成已证实
- 至少一个候选被拒绝、降级或保留边界

## 同构验收

- 至少列出输入、机制、状态变化、输出、边界
- 至少列出一个 `non_isomorphic_limit`

## 可读性验收

- 正文不依赖函数表先验
- 正文不机械排比三个领域同一句话
- 正文避免连续堆叠内部编号

## 当前 057 的落地口径

- 以 D600 / D601 / D602 与 C-0810 / C-0811 为正式基础
- D603 / D604 只能作为 056 开放 PR 候选参考
