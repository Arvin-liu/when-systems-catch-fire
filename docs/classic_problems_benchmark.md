# 经典问题 benchmark

本文记录点火项目 v0.2 阶段的经典问题 benchmark。

## 当前初稿

- [经典问题 benchmark 初稿：得到大脑输出 20260706](../outputs/getbrain/classic-problems-benchmark-draft-20260706.md)

## 定位

经典问题 benchmark 用于测试点火框架在各学科经典问题上的表现。

它不是普通案例库，而是测试集。

普通案例库更像训练材料，用于生成函数、案例和推论；经典问题 benchmark 用于检验点火框架是否真的有结构增益，还是只是重述、失败或 `pending`。

## 当前测试维度

每个经典问题主要检查：

- 所属领域；
- 问题定义；
- 主流解释路径；
- 证据制度；
- 点火框架映射；
- 结构性增益；
- 点火框架只是重述的部分；
- 可能失败类型；
- 当前断言等级；
- benchmark 结果；
- 后续需要的证据或验证；
- 是否适合作为公开案例。

## benchmark 结果类型

当前采用以下结果类型：

1. 结构增益 + `pending`；
2. 结构增益 + 重述；
3. 重述为主；
4. 失败；
5. 待补；
6. 待复核。

## 与证据制度库的关系

每个 benchmark 问题都必须调用对应学科的证据制度，判断该问题的成立标准与 `L0-L5` 断言等级。

## 与失败类型学的关系

每个 benchmark 问题都必须标注可能失败类型，例如：

- 材料错误；
- 边界选错；
- 尺度错配；
- 证据等级不足；
- 学科证据制度误配；
- AI 过度解释；
- `L2` 推论误写成 `L5` 结论。

## 与公开案例的关系

如果 benchmark 结果是“结构增益 + `pending`”，可作为结构性推论样本，但不能写成“已解决”。

如果 benchmark 结果是“结构增益 + 重述”，可作为跨域同构识别样本，但应明确哪些部分只是重述。

如果 benchmark 结果是“失败”或高风险未处理，不应直接公开故事化。
