# 结构缺漏审计

本文用于记录点火框架当前仍需补齐的结构缺口。

## 1. 对象定义协议

### 问题

点火分析中的对象可能是：

- 人；
- 组织；
- 制度；
- 技术；
- 观念；
- 事件；
- 学科；
- 函数；
- 系统；
- 变量；
- 边界本身。

如果对象层级混用，容易导致同构误判。

### 待补

建立对象分类协议：

- object；
- relation；
- system；
- boundary；
- constraint；
- resource；
- observer；
- evidence；
- function；
- claim。

## 2. 系统边界协议

### 问题

点火分析需要明确系统边界，否则会出现：

- 把环境变量误认为内部变量；
- 把局部机制误认为全局机制；
- 把短期现象误认为长期结构；
- 把观察者位置误认为对象属性。

### 待补

建立系统边界模板：

- 内部对象；
- 外部环境；
- 输入；
- 输出；
- 约束；
- 资源；
- 时间尺度；
- 空间尺度；
- 观察者位置。

### 当前状态

pending
