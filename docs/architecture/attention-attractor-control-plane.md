# Attention And Attractor Control Plane

Status: `121Q13_CONTROL_OVERLAY`

This control plane decides whether another iteration is adding information or only circling an attractor. It does not decide truth, proof, value, or final project identity.

## IterationDelta

Every repeated loop should record whether the new pass changed at least one of:

- evidence;
- discriminating test;
- mechanism map;
- boundary;
- capability;
- action;
- option space;
- unresolved residue.

If all of these remain unchanged, the loop is not deeper by repetition alone.

## No-Information-Gain States

Use these states when a loop repeats without real delta:

- `NO_INFORMATION_GAIN`: same input, path, conclusion, and claim ceiling.
- `ATTRACTOR_LOOP`: the project pulls diverse material into the same favored frame.
- `RUMINATION_RISK`: additional thinking increases confidence or phrasing without changing evidence or tests.

Allowed responses:

- stop;
- branch the question;
- seek external evidence;
- run a discriminating test;
- preserve residue as outside current frame;
- downgrade claim ceiling.

## Project-Level Attractors

The project must explicitly check whether it is forcing material into these attractors:

- all material returns to Ψ0;
- all similarity becomes isomorphism;
- every gap becomes a new layer or interface;
- CI success becomes theory success;
- value conflict becomes Charter vocabulary without mechanism analysis;
- same-source AI outputs become independent evidence;
- words such as emergence, convergence, meta-protocol, structure, or mechanism become stopping labels.

Valid outcomes include:

- not suitable for absorption;
- cannot be mapped;
- frame-external residue;
- requires external discipline;
- no current information gain.

## Relationship To 121Q12

121Q12 asks what to try and how to interpret results. 121Q13 asks whether continuing the loop adds anything, and whether the project frame itself is shaping attention too strongly.

This plane can stop or redirect an effectual action loop even when the proposed next action is cheap.
