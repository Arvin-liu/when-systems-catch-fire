# Multiscale Causal Fabric / 多尺度因果织体

Status: candidate derived representation.

The Multiscale Causal Fabric (MCF) is a versioned modeling and navigation structure across the existing L0-L6 architecture. It is not L7, not a new truth layer, not a replacement for Foundation, and not proof that the universe is literally a graph or network.

MCF exists because the repository already has local causal components but lacks a shared object model for time, scale, propagation, feedback, entropy, irreversibility, projection, diff, and residue.

## Placement

- Charter Gate decides whether an action or publication remains normatively allowed.
- Foundation remains authoritative for objects, evidence, status, and claim ceilings.
- Function OS can execute specified MCF analysis steps and leave traces.
- Q12 selects state-changing actions and adjudicates mechanisms.
- Q13 controls attractors, distribution collapse, narrative provenance, and compression.
- Q14 Atlas can project MCF views, but map position is not causal proof.
- MCF derives navigable causal representations from these layers without replacing them.

## Core Boundary Rules

1. Light-cone reachability means possible reachability under declared assumptions. It does not prove an actual causal mechanism.
2. Entropy arrow and causal arrow are separate fields. Thermodynamic direction is not automatically a causal edge.
3. Quantum entanglement can show nonclassical correlation. It is not a controllable superluminal signal and must not be projected into social or AI systems except as `analogy_only`.
4. Feedback loops at state or control-system scale must be expandable into time-indexed event paths.
5. Statistical causality, physical propagation, mechanism hypothesis, intervention support, correlation, analogy, and unknown relation are different relation classes.
6. Scale transitions are not automatically faithful. They need bridge mechanisms, evidence, or explicit residue.
7. A map, network path, centrality score, dependency edge, or visual position is not proof.

## Objects

### CausalEvent

An event is a localized or bounded occurrence under an observer frame.

Required fields: `event_id`, `event_type`, `temporal_support`, `spatial_support`, `scale_domain`, `observer_frame`, `provenance`, `uncertainty`, `claim_ceiling`.

### CausalState

A state persists after one or more events and has maintenance, decay, and termination conditions.

Required fields: `state_id`, `activation_event`, `persistence_interval`, `maintenance_conditions`, `decay_or_termination_conditions`, `state_variables`, `scale_domain`.

### CausalRelation

A relation connects events or states under a declared class and evidence boundary.

Required fields: `source`, `target`, `relation_class`, `mechanism_status`, `temporal_order`, `delay`, `propagation_speed_or_bound`, `mediator_chain`, `intervention_status`, `counterfactual_status`, `evidence_refs`, `uncertainty`, `claim_ceiling`.

Allowed relation classes:

- `physical_propagation`
- `experimentally_identified_causal`
- `intervention_supported`
- `mechanism_hypothesis`
- `structural_causal_model_edge`
- `dynamical_feedback`
- `enabling_condition`
- `constraint`
- `correlation_only`
- `analogy_only`
- `unknown_relation`

### PropagationChannel

Records carrier, speed bound, attenuation, amplification, transformation, capacity/resource limits, noise, and failure conditions.

### CausalConeOrHorizon

Records origin event, spacetime scope, reachability semantics, horizon/boundary, coordinate/frame assumptions, and source of bound. A cone is a reachability boundary, not a causal proof.

### ScaleDomain

Allowed examples include `quantum`, `atomic`, `molecular`, `cellular`, `organism`, `interpersonal`, `organizational`, `societal`, `ecological`, `planetary`, `stellar`, `galactic`, `cosmological`, and `unmapped`. The list is not ontologically complete.

### BranchMergeStructure

Records branching, convergence, common causes, common effects, competing paths, redundant paths, and bottlenecks.

### FeedbackDynamics

Records loop id, whether it is state-level or event-level, sign, delay, gain, stability, and open-loop expansion. A feedback claim is invalid if it cannot be expanded into time-indexed semantics.

### EntropyAndIrreversibilityRecord

Records thermodynamic scope, open/closed system assumption, entropy measure, entropy production or export, irreversibility status, relation to causal order, evidence, and uncertainty.

### CausalProjection

Derived views can include spacetime reachability, mechanism path, intervention path, resource/energy flow, entropy/dissipation, responsibility/burden, information flow, and historical lineage. Every projection records omitted dimensions and unmapped residue.

### CausalFabricDiff

Compares versions for event changes, relation changes, relation class changes, claim-ceiling movement, time/space boundary changes, mediator additions, and new residue.

### UnmappedCausalResidue

Allowed residue includes unknown causal status, unresolved scale transition, unresolved quantum/classical boundary, missing mediator, conflicting causal models, insufficient counterfactual evidence, and narrative-only association.

## Claim Ceiling

MCF can say: "this representation organizes candidate causal structure under declared evidence, uncertainty, and residue."

MCF cannot say: "this proves actual causality," "this proves the universe is a network," "this unifies physics and society," or "this exhausts the causal field."
