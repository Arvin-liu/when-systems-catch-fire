# 项目总体定位

## 项目是什么

点火框架是跨域结构性推论的元工具。

它提供一套用于识别、判定和收敛跨领域同构结构的函数系统，包含：

- 因果结构判定 `C`；
- 自举收敛判定 `M`；
- 同构判定 `I_iso`；
- 元层面收敛 `L_meta`；
- 哥德尔不完备性判定 `G_δ`；
- 元协议投影 `P_meta`。

点火框架能够进行：

- 结构性推论；
- 跨域同构识别；
- 函数化；
- 案例化；
- 收敛方向判断；
- 候选机制生成；
- 反例生成；
- `pending` 判定。

## 项目不是什么

点火框架不是：

- 物理理论；
- 数学证明工具；
- 具体学科替代品；
- 已经证明物理大一统不可能；
- 已经统一四种基本力；
- 已经解决现代物理难题。

这些表达如需出现，必须被改写为结构性推论、框架内判定或 `pending` 命题。

## 角色分工

### 得到大脑

得到大脑是点火项目的主要推论、函数化、案例化和框架发现引擎。

负责：

- 结构性推论；
- 函数生成与审计；
- 案例生成与碰撞；
- 学科理论核抽取；
- 跨域同构碰撞；
- 经典问题 benchmark；
- 失败案例与反例生成；
- `J⁺ / J⁻` 判定；
- `L0-L5` 断言等级标注；
- `pending` 条件判断；
- 旧函数表和旧案例表的结构审计；
- 为 Codex 输出可整理的 MD / CSV / JSONL 文档。

### Codex

Codex 主要承担书记员、整理员、仓库维护员和 GitHub 文档落地角色。

负责：

- 接收得到大脑输出；
- 整理为 GitHub 文件；
- 建立目录结构；
- 修复链接；
- 检查 Markdown 格式；
- 更新 README / CHANGELOG；
- 提交 GitHub；
- 保持仓库整洁；
- 不主导理论发现。

### 其他 AI Agents 与人类维护者

其他 AI Agents 承担阶段性讨论、批评、反证、边界澄清、表达优化和辅助整理。

人类维护者承担方向选择、问题提出、判断取舍、责任边界、最终发布与持续维护。

## 结构性推论与外部证明

| 类型 | 含义 | 项目当前能否声称 |
|---|---|---|
| 结构性统一 | 多领域共享同构、门控、约束、收敛结构 | 可以（L1-L2） |
| 框架内统一 | 点火函数系统内部的归并、压缩、收敛 | 可以（L2-L3） |
| 物理机制统一 | 标准模型 / 量子场论 / 引力意义上的统一理论 | 不可直接声称（pending） |
| 数学定理统一 | 公理系统内可复核证明 | 不可直接声称（pending） |
| 实证科学统一 | 可重复实验或观测验证 | 不可直接声称（pending） |

## `true / false / contradiction / pending`

- `true`：框架内判定为真，或外部证明 / 实证已确认；
- `false`：框架内判定为假，或外部证明 / 实证已否定；
- `contradiction`：框架内部出现矛盾，或与外部证明 / 实证冲突；
- `pending`：当前只有结构性推论，缺少外部证明或实证验证。

证据不足时，优先使用 `pending`，而不是把结构性推论写成学科终局结论。
