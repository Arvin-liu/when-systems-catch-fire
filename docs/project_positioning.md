# Deprecated Compatibility Entry: Project Positioning

This path is kept only so older links do not break.

The term “项目定位 / project positioning” is deprecated for the current repository. It suggested a top-down, fixed identity: first define what the project is, then measure everything against that definition. That is not how 点火 has actually grown.

The canonical current page is now:

- [Project Current State / 项目现状](./project-current-state.md)

Use that page to describe what the repository has currently become, what it can currently do, what remains missing, and which claims are verified, downgraded, or pending at the relevant commit.

Do not treat this compatibility page as a current authority. Historical Git records preserve the old wording for audit purposes; the current documentation should use versioned current-state language instead of fixed positioning language.
