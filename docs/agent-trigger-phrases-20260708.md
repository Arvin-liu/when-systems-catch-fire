# Agent 触发词与低消耗执行约定

## 目的

本文件用于固化点火项目常用任务触发词，减少后续每轮重复解释背景、路径、边界和汇报格式的消耗。

## 原则

- 触发词不是新功能，只是既有流程的简称；
- 如果触发词与用户明确指令冲突，以用户当轮明确指令为准；
- 所有涉及回填、删除、发布、打 tag 的动作，仍必须得到明确指令；
- 默认不得越权处理未指定候选。

## 触发词 1：跑 P1 校验

**含义：** 进入点火主仓库，执行：
```
git status
git pull --ff-only
python3 tools/validate_data.py
```

**通过条件：**
- git status 干净；
- 校验器输出 `ALL_P1_DATA_VALID`。

**禁止事项：**
- 不修改 data；
- 不修改 schema；
- 不修改两张表；
- 不启动其他任务。

## 触发词 2：查两张表

**含义：** 只查点火主仓库内正式目录：
- `统一函数总表/`
- `统一案例总表/`

不得把 LIANGZHANGBIAO / Unified-* 临时仓库当作主线。

**用途：**
- 查重；
- 定位编号；
- 检查索引；
- 判断函数或案例是否真新增。

## 触发词 3：跑 Ψ₀ 新增判定

**含义：** 对候选函数、案例、注释或扩展注释使用 Ψ₀ 元函数做新增判定：
```
Ψ₀ := C(x,y) × M(B_n) × I_iso(A,B) × L_meta × G_δ × P_meta
```

**六维判定：**
- `C(x,y)`：是否有新增因果结构。
- `M(B_n)`：是否能与现有系统自举收敛。
- `I_iso(A,B)`：是否与现有条目同构。
- `L_meta`：是否污染元层级或越权泛化。
- `G_δ`：是否存在当前材料无法闭合的证明缺口。
- `P_meta`：应投影为新增函数、案例、注释、扩展注释、pending 或不采纳。

## 触发词 4：做回填复核

**含义：** 只做查重、Ψ₀ 判定、评级、排序、批次建议。

**禁止事项：**
- 不修改正式函数表；
- 不修改正式案例表；
- 不新增正式条目；
- 不直接回填。

**输出：**
- 回填复核审计报告；
- 建议入表、建议注释、建议扩展注释、不采纳项；
- 第一批优先候选；
- 第二批暂缓候选。

## 触发词 5：小批量回填

**含义：** 只处理 GPT 当轮明确指定的 1 到 3 个候选。

**必须动作：**
- 跑 P1 校验；
- 查两张表；
- 跑 Ψ₀ 新增判定；
- 保留来源回指；
- 标注 pending；
- 更新必要索引；
- 生成回填审计；
- 提交并推送。

**禁止事项：**
- 不顺手处理未指定候选；
- 不大规模重写两张表；
- 不修改 data；
- 不修改 schema；
- 不启动大任务。

## 触发词 6：索引可见性验证

**含义：** 检查新增条目是否能被后续流程检索到。

**必须检查：**
- 文件存在性；
- INDEX / 总览可见性；
- 编号可检索；
- 标题可检索；
- 语义关键词可召回；
- 来源回指；
- 审计记录；
- 相关案例或函数关联闭环。

**输出：** 索引可见性验证报告。

**禁止事项：**
- 不新增函数；
- 不新增案例；
- 不处理其他候选。

## 触发词 7：得到大脑材料碰撞

**含义：** 使用本地正文、Markdown、DOCX、JSON 或 CSV 做材料碰撞。

**默认假设：** 得到大脑不能稳定读取网页链接。不得只给 URL。必须使用本地正文或快照。

**标准输出目录：** `outputs/collisions/YYYYMMDD-task-name/`

**标准输出文件：**
- `collision-report.md`
- `new-functions.md`
- `new-cases.md`
- `notes.md`
- `expanded-notes.md`
- `rejected.md`
- `backfill-plan.md`
- `source-snapshot.md`

**禁止事项：**
- 不直接回填；
- 不根据网页标题猜内容；
- 不启动大规模任务，除非用户明确要求。

## 触发词 8：任务完成固定汇报

每次任务完成，最后一句必须写成：
```
XXX 指令已执行完成，待 GPT 给下一步指令。
```
其中 XXX 替换为本轮任务名称。

**禁止使用以下模糊结尾：**
- 要我继续吗？
- 是否启动下一步？
- 需要我现在做什么？
- 下一步要不要我来跑？
- 待用户确认。

可以在正文写下一步建议，但最后一句必须是固定格式。

## 触发词 9：只审计不执行

**含义：** 只生成审计报告或复核报告，不修改正式资产。

**适用场景：**
- 边界不清；
- 查重不充分；
- 可能与旧条目重复；
- 需要 GPT 决策。

## 触发词 10：不碰第二批

**含义：** 只处理 GPT 指定候选，不处理其余暂缓项。

**当前赛课机制第二批暂缓项包括：**
- NF-003
- NC-001
- NC-002
- N1N3
- E1E2

如果 GPT 未明确指定，不得处理。
