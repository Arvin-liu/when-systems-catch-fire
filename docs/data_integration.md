# 数据接入指南

点火可以和真实数据一起用，这样函数不是只停留在语言上，而是可以被验证或推翻。

## 适合接入的数据

- CSV、TSV、JSON 等表格数据
- 公共数据集或公开统计数据
- 你自己整理的案例表、事件表、观察日志

## 基本原则

- 数据的作用是验证或反驳 `Ψ₀` 及其组成函数的输出。
- 如果数据支持，记录“为什么支持”。
- 如果数据不支持，记录“哪里失败”。
- 如果证据还不够，结论就保留 `pending`。

## 推荐工作流

1. 先定义问题和假说。
2. 再找能回答这个问题的数据。
3. 用 Python notebook 或脚本清洗、对齐和检查数据。
4. 把分析脚本放在新的 `data/` 目录下，方便复现。
5. 将结果写回到反证模板或失败案例库。

## 小提示

- 数据不需要很大，但要和问题相关。
- 数据源越清楚，结论越稳。
- 如果一个函数总是需要额外解释才能成立，先把它标成 `pending` 再继续。
