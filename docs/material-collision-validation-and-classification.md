# 材料碰撞验证与分类规则（含「无配额」硬规则）

> 固化自 IGNITION-20260709-056（独立复核 + 无配额碰撞规则固化）。本文件为点火项目材料碰撞的**权威规则**，覆盖：候选穷尽、无数量配额、独立反事实判同构、分类口径、外部报告读取规范。
> 本规则不修改 canonical、不修改生命共同体价值宪章、不修改 12 元协议治理记录；仅约束「碰撞工作流」本身。

## 0. 适用范围

- 任何对 `统一函数总表/`、`统一案例总表/` 的 Get 笔记 / 得到大脑 / 外部材料碰撞。
- 适用于单文件（`agent-commands/IGNITION-<ID>.md`）与批量（UNESCO/学科）碰撞。

## 1. 无数量配额（硬规则，优先级最高）

- **禁止**设置任何「本轮最多新增 N 个函数 / N 个案例」的配额（如旧规 `≤5`）。
- 流程：**先穷尽所有候选机制 → 逐项独立判定 → 实际新增数可为 0 或任意自然数**。
- 配额导致的「进 candidates 暂缓」「不抢名额」等表述一律废止；原 collision 产物中的「≤5 数量约束核对」字样视为历史残留，不再作为合规门槛。
- 数量唯一约束仅剩：`每个新函数来源锚点 ≥ 2`、`每个新案例来源可回指`（来自材料内 A 层事件），此为非配额硬性证据门槛。

## 2. 候选穷尽与分类口径

每条候选必须落到且仅落到一个 primary classification：

| classification | 含义 | 是否新增编号 |
|---|---|---|
| NEW_FUNCTION | 独立反事实判别证明不可约原语 | 是（用实时 next-free D 编号） |
| BOUNDARY_EXTENSION | 与现有函数实质同构，仅补反向边/轴实例 | 否 |
| ALREADY_COVERED | 被现有函数族覆盖，仅作跨域补强证据 | 否 |
| PENDING_EVIDENCE | 与现有相邻但缺一层，需外部材料定 NEW 或 EXTENDED | 否（登记缺口） |
| REJECTED | 证据不足或纯建议/上位概念 | 否 |

- 每个候选必须保留：正向通道 / 反向通道 / 反例 / pending / 退出条件。
- 禁止把 `J⁺=1` 写成数学证明或外部事实证明。

## 3. 独立反事实同构判别（不可依赖 grep 零命中）

- 判「与现有函数不同构」时，**必须**：
  1. 读出最近邻 1–3 个现有函数正文；
  2. 构造一个反事实场景使候选触发而最近邻不触发（或反之）；
  3. 记录该场景与预测差异。
- 仅「grep 全表零命中关键词」**不足以**证成 NEW_FUNCTION；零命中仅作初筛，最终以反事实判别为准。
- 计数口径强制分离：文件总数 ≠ D 唯一数 ≠ C 唯一数 ≠ MF/A-T 条目数；报告不得混称。

## 4. 外部验证报告读取规范

- 外部报告（如 0000 Get 笔记《……增量记录》）**只读**获取，凭证零进入日志/progress/result/commit/PR。
- 报告中出现的任何百分比/计数（如 `f₁=15%`、同构度、锚点复用率、编号增量）**均不可直接采信为事实**；必须回读报告原文核对，核对不到即标 `UNREPRODUCIBLE`，不得写入函数/案例正文或结论。
- 外部报告对「未入表」的解释若写「名额有限/配额」，与本规则冲突时以本规则（无配额）为准，并在审计中纠正。

## 5. 治理层冻结

- canonical/、生命共同体价值宪章、12 元协议治理记录：材料碰撞**不得**修改其语义。
- 材料碰撞只产生：D 条目（NEW_FUNCTION/EXTENSION）、C 条目、候选登记（PENDING_EVIDENCE）、审计/决策产物（outputs/collisions、data/collisions）。
- 价值宪章/元协议仅作投影与规范边界检查，不作经验事实来源。

## 6. 产物归档

- 主审计：`outputs/collisions/<YYYYMMDD>-<name>/independent-second-angle-audit-<task>.md`
- 决策账本（机器可读）：`data/collisions/<YYYYMMDD>-<name>-<task>.json`，含每个候选 primary_classification、锚点、最近邻差异、corrections、summary。
- 承接任务必须能在全新对话中凭本文件 + 产物独立复现结论。

## 7. 废止项

- 「本轮新增上限有限 / 不抢新增名额」作为未入表理由 —— 废止。
- 「≤5 数量约束核对」作为合规门槛 —— 废止（仅保留来源锚点 ≥2 / 案例可回指证据门槛）。
- 任何对外部报告百分比/计数的无回读采信 —— 废止。
