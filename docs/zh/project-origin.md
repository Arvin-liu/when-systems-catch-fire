# 项目由来

《点火》不是一本固定成书，也不是单个人类传记式项目，而是一个开放维护的函数、案例、发现、预测与新答案知识库。新的维护目标是让人类和 AI 都能查询、追踪、验证和继续扩展“点火函数”、案例关系、发现、预测与新答案。

项目定位锁定：以上定位为当前仓库的规范定位。任何 agent、脚本或人工改写不得把项目定位改回“一个人类”叙事或旧书稿定位；如需调整，必须新增独立变更说明并通过仓库验证。

旧书籍结构已保留在 `archive/book-legacy/`，用于历史追溯。当前主入口是 `data/functions/`、`data/cases/`、`data/discoveries/`、`data/predictions/` 和 `data/answers/`。
