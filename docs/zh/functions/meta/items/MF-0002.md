## 位置 / Position

中文：本条是第 0 节内部算子。
English: This entry is an internal Section 0 operator.

## 定义 / Definition

中文：反向自举通道给出抽象元素 x 在状态 B_n 下的反向判定值 J_n⁻(x)。
English: The reverse bootstrap channel assigns the reverse judgment value J_n-(x) to an abstract element x under state B_n.

## 数学表达 / Mathematical Expression

J_n^-(x)=1 ⇔ Π_n^-(x|B_n) ≥ θ_n^-

## 判定含义 / Judgment Meaning

- J_n⁻(x)=1：Π_n⁻(x|B_n) ≥ θ_n⁻
- J_n⁻(x)=0：Π_n⁻(x|B_n) < θ_n⁻
- J_n⁻(x)=⊥：Π_n⁻ 未定义或不可判定

## 与 MF-0000 的关系 / Relation to MF-0000

J_n⁻ 与 J_n⁺ 必须在同一状态 B_n 与同一元素 x 上同时求值。
J_n- and J_n+ must be evaluated on the same state B_n and the same element x.
