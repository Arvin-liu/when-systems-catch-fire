## 位置 / Position

中文：本条是第 0 节内部算子。
English: This entry is an internal Section 0 operator.

## 定义 / Definition

中文：正向自举通道给出抽象元素 x 在状态 B_n 下的正向判定值 J_n⁺(x)。
English: The forward bootstrap channel assigns the forward judgment value J_n+(x) to an abstract element x under state B_n.

## 数学表达 / Mathematical Expression

J_n^+(x)=1 ⇔ Π_n^+(x|B_n) ≥ θ_n^+

## 判定含义 / Judgment Meaning

- J_n⁺(x)=1：Π_n⁺(x|B_n) ≥ θ_n⁺
- J_n⁺(x)=0：Π_n⁺(x|B_n) < θ_n⁺
- J_n⁺(x)=⊥：Π_n⁺ 未定义或不可判定

## 与 MF-0000 的关系 / Relation to MF-0000

J_n⁺ 与 J_n⁻ 共同构成有序判定对 (J_n⁺(x), J_n⁻(x))。
J_n+ and J_n- jointly form the ordered judgment pair (J_n+(x), J_n-(x)).
