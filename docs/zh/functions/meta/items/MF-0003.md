# MF-0003｜正反互斥判定器 / Forward-Reverse Exclusivity Judge

[返回仓库首页 / Back to Repository Home](../../../../../README.md)

## 位置 / Position

中文：本条是第 0 节内部算子。
English: This entry is an internal Section 0 operator.

## 定义 / Definition

中文：正反互斥判定器排除同一 x 在同一 B_n 下同时满足 J_n⁺(x)=1 与 J_n⁻(x)=1。
English: The forward-reverse exclusivity judge excludes the state where the same x under the same B_n satisfies both J_n+(x)=1 and J_n-(x)=1.

## 数学表达 / Mathematical Expression

∀x∈X_n, ¬(J_n^+(x)=1 ∧ J_n^-(x)=1)

## 判定含义 / Judgment Meaning

- `true`：∀x∈X_n, (J_n⁺(x),J_n⁻(x))≠(1,1)
- `contradiction`：∃x∈X_n, (J_n⁺(x),J_n⁻(x))=(1,1)
- `pending`：∃x∈X_n, J_n⁺(x)=⊥ ∨ J_n⁻(x)=⊥

## 与 [MF-0000](../MF-0000.md) 的关系 / Relation to [MF-0000](../MF-0000.md)

该算子保证判定对落在 { (1,0), (0,1), (0,0) } 或 pending，而不允许稳定停在 (1,1)。
This operator keeps judgment pairs in { (1,0), (0,1), (0,0) } or pending, and does not allow stable termination at (1,1).
