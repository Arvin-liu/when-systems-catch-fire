# 逻辑地基规则

1. **形式语言**：明确项、谓词、关系、量词、变量绑定和作用域。
2. **默认核心**：经典一阶逻辑只用于已声明的演绎核心，不扩张到不一致证据聚合。
3. **非经典声明**：构造、模态、时序、规范、概率、可废止逻辑必须显式选型。
4. **推理类型**：演绎、归纳、溯因、类比和因果推理分别记录，不把支持写成蕴涵。
5. **条件检查**：必要、充分、充要条件分别编码，禁止肯定后件。
6. **反模型**：无效演绎给出满足前提而使结论为假的具体模型与复现方式。
7. **错误分类**：循环、偷换概念、量词滑移、范畴错误、相关因果混淆、隐藏前提均独立标注。
8. **规范桥接**：描述事实不能在无规范前提时推出应当结论。
9. **冲突证据**：证据层保留冲突，不因局部矛盾爆炸式推出任意结论。
10. **有效与真实**：有效性只说明结论随前提；前提真实性和外部证据由其他状态轴负责。

非纯数学对象的最小结构为 `Premises + Declared Inference Rules -> Conclusion`。无法形成演绎时保留 DEFEASIBLE_SUPPORT、HIDDEN_PREMISE 或 PENDING。
