# 数学地基规则

1. **对象与类型**：先区分集合、关系、函数、谓词、算子、状态转移、概率模型和自然语言候选。
2. **集合与映射**：每个映射声明源集合、目标集合、全/偏、确定/随机、单值/多值。
3. **函数规则**：FUNCTION 只允许单值映射；未定义点必须以偏函数或失败类型显式表示。
4. **变量与量纲**：变量、参数、单位、量纲和无量纲化过程分字段记录；量纲错误阻断发布。
5. **命名层级**：公理只在声明系统中成立；定义不是真值；引理/命题/定理/猜想/反例各有不同门禁。
6. **方法边界**：数值实验、符号计算和有限验证可找错或提供支持，不能代替无限域普遍证明。
7. **证明义务**：记录目标、理论、依赖、后端、工件、复现命令、结果与审阅状态。
8. **外部结果**：外部定理标出准确版本、来源和适用假设；原创结果不得借外部名称升级。
9. **跨域数学化**：物理模型补量纲与实验路径；社会/历史/认知模型补可观测量、识别边界和失败条件。
10. **失败与降级**：缺定义、类型、范围或工件时，降为 FORMALIZATION_INCOMPLETE、MODEL_CLAIM、CONJECTURE 或 NATURAL_LANGUAGE_CANDIDATE。

特别规则：A 只表示声明理论内的假设/公理；T 只有链接可检查证明工件时才是 THEOREM。legacy ID 永久保留，但 legacy 标签不支配新类型。
