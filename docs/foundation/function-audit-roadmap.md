# 历史函数后续证明与实证路线图

任务 99 已完成第一轮全量身份卡与处置闭合。未定义、未证明或未建立现实映射的资产不再留在无状态队列，而是逐项进入 `unresolved-quarantine.jsonl`，并带 `resume_key`、失败/未决 gate、证明义务、实证义务和依赖影响。

后续工作按风险和依赖分批解除 quarantine：

1. 公共强断言及其 lineage；
2. theorem/law/proof/unified/solved/impossible 高风险命中；
3. 反向依赖数高的基础资产；
4. 物理、医学、金融、法律等现实高风险资产；
5. 有可执行表达但类型、量纲、奇点或反例未闭合的资产；
6. 其余身份未决候选。

每次解除只提升有新证据支持的轴。数学形式化不提升 E，数据拟合不自动补齐 M；公共叙述和依赖消费者必须同步。批次完成也不会自动把整个领域理论或点火项目宣布为已证明。
