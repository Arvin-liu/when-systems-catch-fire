# 跨学科 smoke test — 历史学材料

## 场景

某地方修志机构推行「数字化贡献积分」，将史料采集、考据、录入折算为积分，与职称评定、岗位晋升挂钩。运行数年后观察到：

- 考据人员偏好采集易数字化、易量化的碑刻与公文，口述史与民间佚闻因难量化而少人问津；
- 为冲积分，出现重复录入同名碑刻、拆分条目刷数的现象；
- 难以考据但价值高的孤本线索因不计入积分而被搁置；
- 修志内部形成「积分高低=贡献大小」的隐性层级，老匠人经验让位于可测产量。

## 机制链（候选）

- 可量化指标替代真实价值：积分只认可量化采集，考据深度与孤本价值被挤出。
- 隐性层级：积分与晋升挂钩，制造新内部分层。
- 刷分畸变：易量化项被拆分重复，真实考据萎缩。
- 量化盲区：口述史/民间佚闻等不可量化高价值史料系统性消失。
