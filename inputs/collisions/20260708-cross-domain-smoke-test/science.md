# 跨学科 smoke test — 自然科学材料

## 场景

某实验团队使用自动高通量筛选平台，每天产生数十万条化合物活性读数。为加快出成果，团队把「显著 p 值数量」作为成员考核与项目续资助的核心指标。运行两年后观察到：

- 实验设计朝容易出显著结果的方向倾斜，高风险但可能更关键的阴性对照被压缩；
- 部分子团队为维持显著结果数量，重复微小变体实验而非探索新机制；
- 不可量化但重要的机制解释性工作（构建理论模型、跨平台复现）被边缘化；
- 平台读数噪声被低估，假阳性在「数量指标」驱动下累积。

## 机制链（候选）

- 可量化指标替代真实价值：p 值数量成为显式评价入口，机制解释性工作被挤出。
- 指标驱动畸变：考核绑定可测项，探索方向朝易出数倾斜。
- 噪声累积：数量指标忽视读数不确定性，假阳性累积。
- 复现被边缘化：不可量化产出（理论/复现）在指标体系中失权重。
