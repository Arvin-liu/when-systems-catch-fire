# 跨学科 smoke test — 社会学材料

## 场景

某城市社区推行「邻里积分制」：居民参与志愿服务、垃圾分类、邻里互助可累积积分，积分与社区评优、公共空间使用权限、部分公共服务优先资格挂钩。运行一年后观察到：

- 居民把志愿服务拆成可被系统识别的最小动作（拍照打卡、短时扫楼），真实互助减少；
- 积分高者形成「荣誉阶层」，低分者被排除在公共议事之外；
- 部分互助行为因无法被量化（陪独居老人聊天、情绪支持）而消失；
- 社区内部出现为刷分而制造的「表演性互助」，真实邻里信任反而下降。

## 机制链（候选）

- 可量化指标替代真实价值：积分只认可量化动作，关系性/情感性互助被挤出。
- 荣誉阶层形成：积分与公共资格挂钩，制造新的社会分层。
- 表演性互助：指标化评价导致行为朝可测方向畸变，信任下降。
- 量化盲区：不可量化但高价值的互助（情绪支持）系统性消失。
