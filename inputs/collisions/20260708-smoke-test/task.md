# P1 接入烟雾测试
## 任务名称
P1 接入烟雾测试
## 碰撞对象
一个小型本地案例是否应该进入函数表或案例表。
## 输入材料
某个学习者把一个旧项目拆成三层：主线仓库、临时救援仓库、本地备份目录。后来发现真正有价值的新增内容只存在于临时仓库中的五个内部结构件，而案例材料只是主线旧子集。于是他没有直接合并临时仓库，而是先做差异审计，再把五个结构件补回主线仓库，最后删除临时环境并保留救援分支作为凭证。
